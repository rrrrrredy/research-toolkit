# 多轮接续改动审阅记录

[English](task-continuity-review.md) | [简体中文](task-continuity-review.zh-CN.md)

2026-10-21。经用户授权，用独立 Codex 执行上下文只读审阅本轮通用代码 diff，范围包括接续视图、记录保存、工作流、变更定位、观察统计、MCP、相关测试和接续指南。没有交付私人案例目录。审阅者做了静态检查；其复现脚本因该上下文未找到 Python 而没有执行，不能把审阅报告当作运行验证。

| 发现 | 修正 | 验证 |
| --- | --- | --- |
| P1：局部 brief 更新重建规格文件，可能丢掉手工补充章节 | 只替换已知字段，保留其余内容；直接编辑造成字段冲突时整批拒绝 | 自定义章节保留、字段冲突不覆盖、同批草稿与进度不部分写入 |
| P2：历史要求含非字符串状态时，接续查询可能在保存已提交后抛异常 | 保留原记录，作为未结事项返回并提示异常 | 只读查询无修改；无关草稿仍可成功保存并返回警告 |
| P2：新增阅读字段校验阻止维护已明确豁免的旧要求 | 范围决定保留旧阅读字段；重新开启要求时恢复严格校验 | 终止旧要求、更新其说明、重新开启时校验 |

三项均已修正，并在受影响测试中复验。独立审阅没有报告主稿与历史交付隔离、审阅绑定或导入统计的其他具体缺陷；这不是无缺陷保证。原始审阅意见保留在仓库外，没有以修正后的说明覆盖。

维护者另核对了生成插件、双语文档、旧接口、测试跳过原因及新增文件内容。新增要求没有成为语义质量门槛，旧任务没有被强制迁移，导入统计不改变独立审阅凭证要求。测试中的暂存比较错误一并修正，见[验证记录](task-continuity-validation.zh-CN.md)。

本轮没有再次调用模型审阅未变内容。修复采用原始发现、精确 diff 和针对性测试闭合；完整模型效果与长期维护收益仍属未验证项。

发布 CI 另外暴露了 Windows 非规范路径问题：统计扫描中的路径已解析，任务根目录仍可能是短路径别名，导致相对路径计算失败。现统一解析任务根目录；使用等价的 `..` 路径复现失败后验证修复。Windows 工作流也补回记录测试之后的立即退出检查，防止后续命令掩盖失败。这两项属于 CI 后续修复，不算前述独立审阅发现。
