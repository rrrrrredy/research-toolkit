## 一个入口，完整研究方法

提供问题、报告目标读者与所需深度。Agent 按当前工作读取完整方法，展开证据、比较、解释和综合判断。

可直接读取研究方法或提供仓库文件。新安装默认关闭基础使用记录，可以直接开始研究。想开启时再配置，已有设置继续生效。分享报告需另行同意。

```
本次使用 Research Toolkit：
https://github.com/rrrrrredy/research-toolkit
先阅读 SKILL.md，按当前工作读取完整研究方法。

研究问题：[填写问题、报告目标读者和用途。]
范围与篇幅：[填写研究范围、信息截止日、篇幅与所需深度。]
已有材料：[提供来源、文件或已有报告。]

结合上下文明确需求，只追问影响结果的关键缺项。
充分展开重要问题的证据、比较、机制解释、反证与综合判断。
复用已有研究，修订时保留有效分析并附简短变化说明。
使用 Agent 工具中的原生 Agent 承担实质研究和渐进写作，明确唯一统稿者。
自行完成独立审阅、审计、改稿和复查，保留原件供交接。复查通过后直接交付。
交付引用可用的完整报告。
```

将方括号内容替换为你的研究需求；已明确的报告目标读者、范围、篇幅、信息截止日或必需材料也可一并提供。

## 在你的 Agent 中使用

按当前界面支持的输入方式使用，插件和 MCP 工具可按需接入。

| 仓库链接 | 提供仓库链接和研究请求，要求 Agent 阅读 SKILL.md 与任务需要的参考文件。 | [仓库用法](https://github.com/rrrrrredy/research-toolkit/blob/main/agents/README.zh-CN.md#直接读取使用) |
| --- | --- | --- |
| 文件或附件 | 下载仓库，提供 SKILL.md 和参考文件，按研究阶段补充所需方法。 | [下载文件](https://github.com/rrrrrredy/research-toolkit/archive/refs/heads/main.zip) |
| 粘贴文本 | 粘贴完整入口指令与任务需要的参考章节。无法读取仓库时，仅发送网址不能提供研究方法。 | [纯聊天使用边界](https://github.com/rrrrrredy/research-toolkit/blob/main/agents/README.zh-CN.md#只能在聊天中使用时) |
| 原生 Skill | 需要重复使用时，通过 Agent 工具支持的技能机制安装完整工具箱。 | [Skill 接入](https://github.com/rrrrrredy/research-toolkit/blob/main/agents/README.zh-CN.md#安装后重复使用) |

**可选执行工具**

| Plugin | 将研究方法与本地 MCP 工具一起安装，要求 Agent 工具支持该软件包格式和本地执行。 | [插件安装指南](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/usage-modes.zh-CN.md#安装插件) |
| --- | --- | --- |
| MCP | 九个本地工具，用于任务记录、进度、阶段方法、已登记版本日志查询、稿件检查、审阅和交付检查。 | [接入 MCP](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/usage-modes.zh-CN.md#单独接入-mcp) |

读取或上传研究方法，不会自动启动 MCP 或执行独立审阅。执行工具需要本地 stdio MCP 支持；插件还需 Agent 工具支持其软件包格式。

使用 Agent 工具中的原生 Agent 完成独立内容审阅、审计和最终验收，无需另配 API；作者自检不能代替这些任务。
