## Test-time compute: where does more work help?

> The design recommendation is to locate the current bottleneck before adding work. Generate more when useful candidates are missing but accessible. Improve verification when those candidates exist but are poorly selected. Use trained repair or partial-state search when intermediate feedback identifies productive changes. Choose a stronger base model when repeated weak attempts share the same blind spot. Stop when the current result meets the requirement or when another increment has less expected value than its resource, delay and error cost. The worked example makes these choices explicit, including a case where the optimal constrained policy leaves budget unspent.

## Use with your agent

Choose the input your interface supports. Plugin and MCP tools are optional.

| Repository link | Provide the repository URL and research request. The agent needs to read SKILL.md and the required references. | [Repository use](https://github.com/rrrrrredy/research-toolkit/blob/main/agents/README.md#use-without-installation) |
| --- | --- | --- |
| Files or attachments | Provide SKILL.md and the reference files from the downloaded repository. Supply further methods when needed. | [Download files](https://github.com/rrrrrredy/research-toolkit/archive/refs/heads/main.zip) |
| Pasted text | Paste the full entry instructions and the reference sections needed for the task. A URL alone is insufficient without repository access. | [Chat-only use](https://github.com/rrrrrredy/research-toolkit/blob/main/agents/README.md#chat-only-use) |
| Native Skill | For repeated use, install the complete toolkit through the agent tool’s supported Skill mechanism. | [Skill setup](https://github.com/rrrrrredy/research-toolkit/blob/main/agents/README.md#install-for-repeated-use) |

**Optional workflow tools**

| Plugin | A bundle of the methods and local MCP tools for agent tools that support its package format and local execution. | [Installation guide](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/usage-modes.md#install-the-plugin) |
| --- | --- | --- |
| MCP | Nine local tools for task records, progress, guidance, registered release-log queries, draft checks, review calls, and delivery checks. | [Connect MCP](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/usage-modes.md#connect-mcp-separately) |

Reading or uploading the methods does not start MCP or run an independent review. The tools need local stdio MCP support; the plugin also requires its package format.

Use the agent tool’s native agents for independent content review, audit and final acceptance. No separate API setup is needed; author self-review cannot replace these assignments.
