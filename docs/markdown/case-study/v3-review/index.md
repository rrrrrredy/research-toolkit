# What changed when a Chinese GPAI report went through review?

On 19 November 2026, Codex reviewed a Chinese report about a general-purpose AI model provider entering the EU. The draft treated the EU representative requirement as generally applicable. After the auditor checked the conditions, the revised passage included the qualifying open-source exemption. Read the [initial draft](https://rrrrrredy.github.io/research-toolkit/case-study/v3-review/reports/initial.html) and [final report](https://rrrrrredy.github.io/research-toolkit/case-study/v3-review/reports/final.html) in Chinese.

## From review to delivery

Four content reviews raised 39 findings. The auditor recorded nine individual decisions and eight grouped decisions and required revisions. An independent agent rechecked the revised manuscript. The delivery receipt identifies the exact file that passed.
