# 国内办公 Agent：来源与证据说明

信息截止与本次读取日期均为 2026 年 11 月 5 日。日期明确的更新按对应版本使用；没有更新时间的帮助页只表示截止日可见说明，不倒推为产品首发能力。下列说明由研究作者自行归纳；厂商说明、公开使用记录与效果统计具有不同证明范围。本页不转载原文全文。

- [产品介绍](https://www.kimi.com/help/kimi-work/overview)：说明 Work 与 Code 的关系、本地执行、系统要求和 Beta 状态；“长时运行”等是厂商能力说明。
- [发布日志](https://www.kimi.com/help/kimi-work/release-notes)：本次页面最新条目为 2026-11-02，包含 9 月局部编辑、Office 历史版本、飞书／Notion 双写，以及 10–11 月恢复和状态提示修复。修复条目不提供故障率。
- [常见问题](https://www.kimi.com/help/kimi-work/kimi-work-faq)：权限模式与本地定时任务的设备条件，明确错过触发不会补跑。
- [K3.1 Pro 官方发布说明](https://www.kimi.com/en/blog/kimi-k3-1-pro)：确认模型可在 Work 3.1.0+ 使用；不把模型基准成绩当办公产品实测结果。
- [会员套餐](https://www.kimi.com/help/membership/membership-pricing)：国内新旧套餐并存、月度共享额度与用量规则；页面含 2026-10-19 国内价格截图说明。

## 扣子

- [了解扣子](https://docs.coze.cn/what_is_coze)：当前团队协作平台、项目、插件及多端入口。
- [Agent 类型](https://docs.coze.cn/cozespace_agent_overview)：原生、三方精选和本地接入的运行环境及工作台能力不同。
- [本地 Agent](https://docs.coze.cn/cozespace_local_agent)：实际仍在用户电脑运行，依赖桥接程序与设备在线，终端对话不同步，原服务方的账号和计费规则继续适用。
- [三方精选 Agent](https://docs.coze.cn/cozespace_cloud_agent)：扣子云电脑运行框架，不绑定框架原厂模型；含云设备变更使用者与恢复配置的边界。
- [套餐与定价](https://docs.coze.cn/cozespace_coze_billing_overview)：个人、团队、企业权益，以及模型用量和云设备在线消耗。积分不能换算成固定任务数。
- [旧低代码项目常见问题](https://docs.coze.cn/guides_FAQ)：扣子编程、旧低代码平台和开源 Coze Studio 的范围；不将开源引擎等同完整商业协作平台。
- [扣子 3.0 用户协议](https://lf3-cdn-tos.draftstatic.com/obj/ies-hotsoon-draft/policy/coze-app-term-of-usepolicy.html)：2026-06-03 更新，2026-06-10 生效，用于核对服务主体与产品范围。

## 飞书与豆包工作

- [豆包工作产品与关系说明](https://www.feishu.cn/content/article/7677519271848610746)：页面标注 2026-08-24，当前内容说明独立 PC、豆包、飞书三个入口，个人／企业身份以及任务、编辑、工具、定时重试。由于页面持续维护，不把全部当前内容都归为 8 月首发能力。
- [权限与数据说明](https://www.feishu.cn/content/article/7680042598047763739)：本人身份和对象权限、数据隔离、未经客户授权不用于基础模型训练，以及水印、DLP、审计的具体覆盖范围；这些是官方承诺，不是本研究安全实测。
- [豆包工作伙伴计费说明](https://aily.feishu.cn/hc/1u7kleqg_1cnvbb55)：明确 2026-08-14 aily 更名工作伙伴、9 月主动工作计费，以及个人、企业和历史会员权益，不能直接代表所有豆包工作入口权益相同。
