# 研究指南

[English](research-guide.md) | [简体中文](research-guide.zh-CN.md)

[项目介绍](../README.zh-CN.md) · [开始研究](quickstart.zh-CN.md) · [安装与工具](usage-modes.zh-CN.md)

Research Toolkit 供宿主中的 Agent 使用，面向具体读者形成充分、有依据的研究。需求决定要解释什么、展开到什么深度，方法与协作围绕这一成果组织。

## 研究请求示例

以下是可用题目，不表示每题都已经执行：

- **行业报告：** 为战略读者解释 2026 年 Agent 市场的重要变化、竞争和采用障碍，并给出范围与深度要求。
- **公司比较：** 按产品、模型、组织和战略比较指定国内外公司，保留发展时间线。
- **技术路线：** 在给定文档、权限和部署条件下比较 RAG、长上下文与混合路线。
- **投资研究：** 分析行业时机、壁垒、商业模式和反证，区分已发生事实与投资假设。
- **报告更新：** 用新材料或新要求修改已有报告，保留仍成立的分析，并解释判断变化。

单个事实查询、普通翻译或措辞修改通常不需要完整研究任务。长研究需要明确证据、逐步论证、实质协作与独立审阅；较短交付也可能建立在深入研究之上。

## 一条接通的研究路径

[快速开始](quickstart.zh-CN.md#从零研究的步骤)说明完整执行。四项职责组织已有能力，不对应四个固定 Agent 或四条独立流程。

| 职责 | 负责什么 | 交给下一项工作的内容 |
| --- | --- | --- |
| 任务与上下文 | 当前问题、读者、要求、提纲、主稿及依赖。 | 有效约束、具体问题、相关来源与分析引用。 |
| 证据与分析 | 原文阅读、主张依据、比较、计算、机制和竞争解释。 | 带来源、条件、反证及未决问题的完整推理。 |
| 成稿与修订 | 有意义的论证单元和明确负责人的一份主稿。 | 连贯当前正文、可定位引用及其背后的原始分析。 |
| 审阅与交付 | 独立内容视角、领域专审、审计及最终验收。 | 有定位的发现、独立核对过的修正，再交付完整报告。 |

主 Agent 保持整体问题并处理跨部分判断，研究子 Agent 承担真实生产工作，明确指定的统稿者整合主稿。每次交接保留完整成果和可访问原件；简短摘要说明下一位要读什么、接着做什么，不代替原始分析。

推进依据实际依赖。尚未解决的比较前提或计算会影响后续论证，应先审阅这些前提，再传播其结果；独立研究单元可以并行。提纲和正文随发现发展，不默认一次性成稿，也不规定每轮固定写几段。

## 审阅与验收

需求、证据、对抗推理、结构与深度、读者用途、过程语言、自然表达分别交给七个独立上下文，相关领域知识另行专审。独立审计者核对实质审阅、重要发现及已通过内容的样本；必要修正完成后，另一位独立 Agent 验收完整当前稿。

审计者从实际全文与原始输入选择样本。关键要求、决定性主张、数字、引用、反证及重要处置全部核查；其他抽查有原因和位置。发现问题，沿同源、同指标、同支线或同种改写继续查清。抽查属于审计和验收，不另设一层角色。

作者可以自改或回应争议，但不能代替独立审阅、关闭自己的必改项。保留负评并落实到实际报告。完整内容方法在[角色规范](../references/subagents-and-review-loop.zh-CN.md)，CLI／MCP 记录见[审阅完成](review-completion.zh-CN.md)。

## 任务记录与接续

纯 Skill 利用宿主已有文件或上下文保留原始要求、来源、分析、稿件和审阅结果，无需复刻固定 CLI／MCP 台账；实质独立职责仍然相同。

工具管理任务复用来源／主张记录、任务规格、要求台账、成果与审阅日志。`status` 提供共同输入，`save` 保存成果与依赖，`review` 连接宿主独立任务，`finish` 在当前验收完成后生成回执。具体字段和调用以[使用指南](usage-modes.zh-CN.md)为准。

已满足但仍适用的要求继续约束改稿。新指令更新受影响要求与工作，不抹去无冲突的原始目标。旧成果和回执保持原版本，接续研究形成新的当前成果。

## 成果应当回答什么

报告回应读者的实际疑问，提供依据、解释、有效比较和范围恰当的结论，保留必要条件、反证与不确定性。终稿是面向读者的研究文章；来源处理笔记和交接日志保留在后台材料中，除非用户需要，不挤入正文。

来源数量、完整提纲或记录通过都不能补上稿件缺失的解释。机械工具定位记录和版本问题，独立 Agent 阅读实际报告与证据；工具契约见[交付检查](delivery-verification.zh-CN.md)。

## 仓库与维护

`SKILL.md` 是统一入口，`references/` 保存方法原件，`scripts/` 提供 CLI／MCP 共同实现，`agents/` 说明宿主接入，`docs/` 承载使用与网站。`plugins/research-toolkit/` 从共同原件生成，`examples/` 展示接口，`evals/` 保留研究及相关检查。

维护和实验执行说明放在[贡献指南](../CONTRIBUTING.zh-CN.md)、[评测文档](../evals/README.zh-CN.md)与[网站维护](site-maintenance.md)，不是每次研究的额外步骤。[MIT 许可](../LICENSE)。
