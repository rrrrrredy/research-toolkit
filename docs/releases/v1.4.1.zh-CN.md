# Research Toolkit v1.4.1

[English](v1.4.1.md) | [简体中文](v1.4.1.zh-CN.md)

本补丁将 [PR #91](https://github.com/rrrrrredy/research-toolkit/pull/91) 的默认入口与按需加载方法调整分发给插件安装用户；v1.4.0 ZIP 仍包含此前的指导。公开工具、参数和已保存任务格式保持不变。

## 改动

- **从研究需求出发。** 默认 Skill 入口围绕需求理解、指令遵循和有价值的回答组织。ChatGPT 指南移除了让用户提醒、调度 Agent 的说明，由 Agent 在用户要求内组织方法、记录和执行。
- **按任务需要读取方法。** 复用需求、证据、分析、写作和接续方法入口。评审配置放入 `docs/review-completion.zh-CN.md`，记录细节放入 `docs/usage-modes.zh-CN.md`，完成细节放入 `docs/delivery-verification.zh-CN.md`；不新增流程、强制阅读顺序或固定报告结构。
- **同步发布内容。** 中英文 Skill、ChatGPT 指南、参考文档、Framework 页面和插件副本保持一致。现有文档契约检查改从迁移后的位置读取状态词汇，断言条件不变。

## 验证与限制

PR #91 已通过既有 CI，以及实现阶段的文档同步、静态构建、插件一致性和针对性文档契约检查。发布准备沿用这些结果，本地只校验变化的版本元数据与生成包，发布提交由仓库现有 CI 执行检查。不重跑研究任务、模型评测或已通过的本地实现检查。

Skill 专用 `quick_validate.py` 校验仍为**未完成**：此前执行因缺少 PyYAML，报错 `ModuleNotFoundError: No module named 'yaml'`。其他检查通过不替代这一项。后续如需补齐，可在已有 PyYAML 的环境中，用现有 Skill 校验脚本检查仓库根目录，预期返回 `Skill is valid!`；该操作检查 Skill 格式，不验证研究质量。

指令遵循、用户负担和研究质量方面的收益仍**未验证**。指导变短和文件同步说明文档改动已经落实，不代表研究结果已经改善。

## 升级

下载 [v1.4.1 插件 ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.1/research-toolkit-plugin-v1.4.1.zip) 和 [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.1/SHA256SUMS)，或将完整仓库更新到 `v1.4.1`。保留本地任务及有意修改的文件，替换插件安装包，并在宿主中重新加载更新后的 Skill。现有任务无需迁移。
