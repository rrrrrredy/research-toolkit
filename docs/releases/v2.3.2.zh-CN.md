# Research Toolkit v2.3.2

发布于 2026-11-05。

本补丁统一首次使用的说明，并同步到 Skill、插件和网站。研究方法可以直接读取，无需先安装 Skill 或 MCP；在 Codex、Claude Code、OpenCode 中首次使用，还会复用或下载完整本地副本，通过随包 Python 脚本配置基础使用记录。已打开的 Codex 会话需要重载或重新打开，配置才会生效。缺少 Python、命令执行能力或尚未生效的记录配置，不妨碍继续研究。

## 改动

- 将面向使用者的“宿主”改为“Agent 工具”、具体产品名或对应的 Agent 职责；英文同步使用 agent tool、application、agent 等准确表述。命令参数、返回字段、文件路径和旧链接锚点保持兼容，冻结的研究稿与执行原件保留原文。
- 中英文项目介绍、接入指南、Skill、生成插件与网站入口采用一致的首用说明。默认基础记录、已有关闭设置和采集范围不变。
- 重做并更新两篇首页案例：截至 11 月 5 日的国内办公 Agent 研究，以及原生英文 API／浏览器研究。保留旧案例、新完整首稿、实质分析、来源说明、原始独立意见与修订取舍。这些是重新完成的研究交付，不是 Toolkit 质量或效率收益的控制实验。

## 验证与兼容

受影响 Python 源码编译、文档及插件同步检查通过，复用已有安装契约检查结果。静态页面检查覆盖新报告及档案链接，最终 CI 与部署结果见本次发布对应 PR。

研究接口、任务格式、审阅职责和使用数据采集行为不变。需更新完整安装包才能获得这次说明；网站更新不会改变已经下载的 v2.3.1 安装包。
