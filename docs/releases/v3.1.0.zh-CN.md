# Research Toolkit v3.1.0

[English](v3.1.0.md) · [简体中文](v3.1.0.zh-CN.md)

这个版本把审计回复骨架和配置预览都装进了插件 ZIP。解压后，从 `research-toolkit` 目录就能运行下面两个命令。

## 让审计 Agent 直接开始核查

```sh
python scripts/research_workflow.py review --scaffold-audit --workspace WORKSPACE --task TASK_ID
```

选择一个已经收到评审、正等待独立审计的任务。工具自动列出稿件版本、派工版本、原意见、正文位置、可能重复的意见、来源和用户要求。判断、理由和证据留空。审计 Agent 对照原件填写，确认同一个问题时可以只裁定一次，再走原有的评审提交入口。独立复查通过就交付成稿。例如任务保存在 `work/tasks/gpai`，就传 `--workspace work/tasks --task gpai`。

## 先看配置会写什么

```sh
python scripts/research_workflow.py setup --host codex --project . --dry-run
```

输出会告诉你基础使用记录是否开启、配置文件会放在哪里、会配置哪些钩子。新安装默认关闭记录。直接预览不会写文件。已经明确开启记录时，`--apply` 才把钩子装到所选项目。`--no-telemetry` 跳过本次配置。分享报告正文仍然需要单独授权。Claude Code 和 OpenCode 也支持配置预览。

## 安装、案例与文档

快速安装到技能可加载或 MCP 能列出九个工具为止。17 个宿主的安装和能力说明来自同一份清单。研究案例可以从原稿一路查到审阅、修订和交付回执。GPAI 真稿在同时两个名额下完成交付，39 条意见归为 17 项裁定。另一次验证使用四份预设评审，同一条错误质疑被审计 Agent 查原文后一次驳回。两份记录分别公开，各自保留适用范围。[稿件和裁定](https://rrrrrredy.github.io/research-toolkit/case-study/v3-review/README.zh-CN.html) · [评测与证据](https://rrrrrredy.github.io/research-toolkit/evaluation-status.zh-CN.html)

Agent 索引列出各发布页面的 Markdown 原文，覆盖使用指南、历次发布说明和案例档案。每个 HTML 页面都提供人能点击、软件能识别的 Markdown 链接。精简手册收录完整的核心方法。[Agent 索引](https://rrrrrredy.github.io/research-toolkit/llms.txt) · [核心手册](https://rrrrrredy.github.io/research-toolkit/llms-full.txt)
