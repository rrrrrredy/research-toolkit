# Research Toolkit v1.4.3

[English](v1.4.3.md) | [简体中文](v1.4.3.zh-CN.md)

本补丁将 [PR #97](https://github.com/rrrrrredy/research-toolkit/pull/97) 的语言兼容与校验前置修复分发给插件安装用户。v1.4.2 ZIP 仍会拒绝 `zh-CN`，且可能先写入研究记录或推进阶段，再返回语言错误。更新安装包即可获得运行时修复，现有任务无需迁移。

## 改动

- **三个入口采用同一套语言处理。** `start`、`status`、`guide` 及其 MCP 工具均接受 `zh-CN`、`zh`，加载现有中文方法；`en` 继续选择英文，默认值不变。
- **先校验语言，再写入研究状态。** `start` 在写入任务记录前处理语言，`status` 在保存阶段变化前处理语言。不支持的值返回 `language must be "en" (English), "zh" or "zh-CN" (Chinese).`，阶段错误单独指出可用阶段。
- **同步安装后的接口说明。** MCP 工具说明、中英文使用文档和插件副本保持一致，不新增字段、调用或交付要求。

## 验证与限制

PR #97 通过共享 CLI 分发层，在临时任务目录核对压缩空气研究中已归档的 `zh-CN` 启动请求，首次调用成功并返回中文指导。两个针对性回归用例同时核对了 `en/zh` 兼容性、中文澄清指导，以及无效语言不会先改变研究记录或阶段。使用已有的可写临时目录配置后，两项通过，合计 1.499 秒；原始归档保留，没有重跑研究任务。

受影响代码编译通过，插件的 49 个共享文件同步检查通过，PR #97 的 Framework checks 和双语文档工作流均成功。发布准备沿用这些结果，本地只核对变化的版本元数据和生成包，发布提交由仓库现有 CI 执行检查。不重新进行模型对照或运行已通过的本地实现检查。

**整体研究提速收益仍未验证。** 已验证的是保存的请求可以直接成功，以及无效语言不会先改变研究记录；历史上的 10.812 秒纠错耗时不是本补丁已经实现的省时量。
