# Research Toolkit v1.4.0

[English](v1.4.0.md) | [简体中文](v1.4.0.zh-CN.md)

本版在现有保存与状态接口中加入可选接续能力：更新有效范围、明确当前主稿、找到未结事项，避免将旧交付回执当作修订稿批准。现有九个工具、必填参数、Python 3.10 支持和已保存任务格式保持兼容。

## 改动

- **局部更新需求，保留自定义说明。** `research_save.brief` 只更新提供的字段，规格与进度一起保存，手工补充章节保留。直接编辑造成字段冲突时，整批请求失败，不部分写入草稿或进度。
- **明确当前工作对象。** `draft.main=true` 选定主稿，可选 `draft.kind` 区分报告、比较和评阅。较晚保存的章节或参考稿不会替换主稿。`save/status.current_work` 返回当前观察状态和未结要求；status 单独保留历史交付引用。审阅和完成须使用登记的主稿路径。`complete=true` 仍只表示草稿完整，不代表交付通过。
- **显示实际实现身份。** start/status 返回本地实现与入口摘要，宿主实际加载的 Skill 明确标为未观察。这不自动升级安装，也不构成语义核验。
- **校验和统计与实际行为对应。** 保存时检查有效阅读要求，明确的范围决定可以终止旧要求；接续视图对异常历史状态给出警告。导入审阅与实际模型调用、自审、用量分开统计，导入耗时不计为模型耗时。
- **减少接续时的状态歧义。** 双语指南说明当前要求、实际正文比较、接受意见与落实修改的区别、有效基线上的增量复核、手工恢复及有依据的不修改。不新增平行台账、固定报告结构或语义质量门槛。

## 验证与限制

[验证记录](../task-continuity-validation.zh-CN.md)覆盖 14 项接续测试、12 项记录测试、79 项工作流测试、35 项档位与审阅后端测试，以及打包后的 MCP、既有语义诊断、插件和站点检查。本地跳过了 7 项 Windows 符号链接测试；受环境限制的检查已在适当的本地执行条件下复验。[独立审阅](../task-continuity-review.zh-CN.md)发现三项缺陷，均已修正并进行针对性测试。

新增的 12 个诊断案例独立构造，标签由作者提出，未作盲测。本轮验证其结构，没有将其称为已完成的模型质量评测。另行完成的三种使用方式、三个简短合成任务试跑未观察到回答质量优势。工具管理方式额外保存了任务状态，耗时与 token 更多；三组执行的持久化工作不同。长任务可靠性和减少用户重复提醒的效果仍未验证。

发布准备复用已完成的实现检查，同步元数据和生成文件，运行既有 CI，不增加模型运行或发布门槛。实现身份和接续引用不证明理解质量，也不能保证 Agent 按流程执行。

## 升级

下载 [v1.4.0 插件 ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.0/research-toolkit-plugin-v1.4.0.zip) 和 [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.0/SHA256SUMS)，或将完整仓库更新到 `v1.4.0`。保留本地任务及有意修改的文件，重新加载方法并重启本地 MCP 服务。现有任务无需迁移，显式登记主稿是可选能力。
