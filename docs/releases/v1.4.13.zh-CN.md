# Research Toolkit v1.4.13

[English](v1.4.13.md) | [简体中文](v1.4.13.zh-CN.md)

本补丁分发 [PR #119](https://github.com/rrrrrredy/research-toolkit/pull/119) 的纯 Skill 记录要求修正与入口说明，同时包含此前已合并、尚未发版的 [PR #118](https://github.com/rrrrrredy/research-toolkit/pull/118) 写作指导及局部修订。安装包中的方法也需要更新，因此发布新包。按[版本约定](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/compatibility.zh-CN.md)，本次属于兼容修复，版本递增为 **1.4.13**。

## 改动

- **纯 Skill：** 不再默认创建 `task_spec.md`、`progress.json`、CSV／JSONL 登记表或交付回执。复用现有对话、材料、引用和笔记，需要接续时保留有效要求、稿件、依据和未完成工作。默认交付用户要求的报告与引用，修订时附简短变化说明，不另设必填笔记模板。
- **入口与步骤：** README 开篇解释 Skill 提供方法、CLI 与 MCP 调用相同本地工具、插件打包 Skill 与 MCP；给出安装选择。现有快速开始串起从零研究、修订及更新的步骤与可选工具操作。适用范围按多来源分析、比较、解释和有依据建议的需要说明，不按篇幅划档。
- **写作指导：** 按句子是否提供事实、比较、解释或必要限定决定删改，不以特定词语或句式判定质量。保留有作用的来源说明、条件和论证；冷链构造任务的局部修订另存，原材料、输出及匿名审阅保留，原对照结论不变。没有引入外部项目的代码、提示词、文档、案例、数据或依赖。
- **同步与兼容：** 同步中英文、插件副本和网站方法页。产品运行代码、工具参数、记录格式、CLI／MCP 管理任务的完成契约及旧任务兼容不变；必要阅读、分析深度、指令遵循和约定评审仍须完成。无需迁移任务数据。

## 验证与效果范围

PR #119 的 Linux、最低 Python 版本、Windows 和静态网站 CI 已通过；没有评审意见或未解决的评审线程。已有本地结果包括中英文网页 Skill 一致性、49 个插件共享文件一致性、静态构建与页面检查、85 个新增或修改的本地 Markdown 链接及锚点核对，以及差异检查。

PR #118 的冷链稿修订基于已归档构造材料，纠正结论范围并明确待落实的交车日期和路线保障条件，保留有效比较与解释；它不是新任务或新增模型对照。研究原稿和历史结果保持不变。

本次确认的是要求冲突得到修正、使用说明得到补齐及具体稿件的局部修订，**不代表整体研究质量提升、操作成本下降或返工减少**。这些收益尚未测量。发布准备复用上述结果，仅核对变更的版本元数据、新安装包和现有 CI，不重跑研究或已通过的本地行为检查。
