# Research Toolkit v1.4.6

[English](v1.4.6.md) | [简体中文](v1.4.6.zh-CN.md)

This patch distributes [PR #103](https://github.com/rrrrrredy/research-toolkit/pull/103)'s depth-planning guidance and worked argument example to installed-plugin users. These instructions are part of the methods an Agent reads while researching; the v1.4.5 package does not include the changes.

## Changes

- **Plan the argument before allocating space.** Connect required questions, specific evidence and the reasoning needed to reach a judgment. Compress repeated reminders, retain the user's length and format requirements, and fit the work into existing outlines or notes.
- **Show the complete progression from a question to report prose.** Reuse the eight-company pipeline study's Serving question, Gemini 2.5 thinking-budget material, Seed2.0 model positioning and the May 2025 Codex container description. Show each source's role, the reasoning connecting them, and two example paragraphs. Keep source claims, historical scope and conditional analysis distinct.
- **Keep the method adaptable.** The example is not a required report structure, checklist or reusable industry conclusion. English, Chinese and plugin copies are synchronized; no tools, required records or checking steps are added. Original reports and historical results remain unchanged.

## Verification and limits

PR #103's Framework checks and bilingual documentation workflow passed. Completed local verification covered the example against saved source texts and finding F02, bilingual meaning, plugin synchronization across 49 shared files, five distinct repository link targets and anchors, and `git diff --check`.

Release preparation reuses those results and checks only changed version metadata and package generation locally. Existing repository CI checks the release commit. No research task, model comparison or previously passed local check is rerun for the unchanged method content.

**Research quality, instruction-following and reduced rework benefits remain unverified.** A clearer method and a complete example do not establish improved research outcomes.
