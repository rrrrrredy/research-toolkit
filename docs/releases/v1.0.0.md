# Research Toolkit v1.0.0

The first 1.x release establishes a documented compatibility baseline for the existing research Skill, Lite/Full workflow, seven CLI/MCP tools and bundled plugin. Runtime behavior is unchanged from v0.2.7.

- Publish the [English](../compatibility.md) and [Chinese](../compatibility.zh-CN.md) compatibility policy covering public interfaces, saved tasks, installation entry points and Python 3.10 support.
- Define patch, minor and major releases, deprecation support and migration notes for future incompatible changes.
- Include the policy in the plugin, link it from user and contributor guides, and synchronize version metadata and bilingual release documentation.

Upgrade the complete installation to tag `v1.0.0`; no task-data migration is needed from v0.2.7. Existing tasks retain their stored profile/review choices and versioned records. Historical evaluations and dataset releases retain their original versions. This release uses the existing offline release checks and CI; it adds no model evaluations or review prerequisites.

See the [installation guide](../installation-versioning.md) and [changelog](../../CHANGELOG.md).
