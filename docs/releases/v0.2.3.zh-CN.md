# Research Toolkit v0.2.3

研究工具箱提供更轻量的首次任务和可选本地执行工具，研究方法仍可通过仓库链接或文件使用。

自 v0.1.3 以来的变化：

- 用 Lite 开始小任务：明确需求、登记来源与判断、分节起草、完成六项 checklist，无需配置评审者。
- 按需选择 self、external 或 independent 评审。新 Full 任务未配置后端时使用明确标记降级的自评；已声明的独立评审要求继续有效。
- 通过可选插件使用六个共用 CLI/MCP 工具。外部评审可配置受支持的 CLI、兼容 HTTP 端点或可信自定义命令。
- 保留原始评审回复与失败，将评审绑定报告及证据版本，恢复缺失工作，并允许对误判作有据不改的处置。
- Full 完成前检查必读来源缺失、空判断、需求变化及过期交付记录。
- 提供双语接入卡、随附来源的 Lite 示例和中英文研究案例；无需改代码即可贡献失败案例。
- 以根目录 VERSION 为版本来源，检查插件清单、双语更新记录及发布说明是否一致。

这是软件正式版本，不是研究质量认证。公开档案仍只有两组开发对照，均先运行 Toolkit 组，未完成盲评效力研究。公开记录未完整证明模型与需求匹配，普遍质量优势尚未得到证明；历史样本、失败与冻结结果保持不变。

按该版本对应提交安装或更新，仅使用 MCP 时安装 `requirements-mcp.txt`，研究任务数据保存在安装目录之外。参见[安装与更新说明](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/installation-versioning.zh-CN.md)。
