# Research Toolkit v1.1.0

This minor release adds a compatible record-saving interface. Agents can now submit sources, claims, requirements and drafts through `research_save` / CLI `save`; the execution tool writes and updates the existing files. Users provide research decisions rather than maintaining CSV/JSONL.

- Merge partial updates by ID, preserve other records and extra columns, return assigned IDs, and locate format errors. Explicit replacement of a recovered collection retains an original-byte backup.
- Save drafts with automatic parent-directory creation, or register existing report paths without copying the text. Retain the first complete-draft observation with its timestamp and hash.
- Observe failed saves, actual review attempts/retries, invocation duration and provider-returned usage through `research_status.activity`. Reused reviews add no call; self-review submissions stay separate. Unknown author usage remains unknown, and cached input is not counted twice.
- Include the fixes since v1.0.0: plugin path protection and stale-file cleanup, citation export advisories, Windows UTF-8 CLI output, pending-length guidance, Lite actual-reply/current-completion checks, and aligned bilingual entry points.

Existing CLI/MCP calls, task formats, profile choices, reviewer requirements and delivery checks remain supported. The plugin now has eight MCP tools. No task migration or new evaluation/reviewer gate is required; read-only checks remain read-only. Observations do not certify research quality or measure earlier unobserved work.

The release is justified by new compatible functionality under the [1.x policy](../compatibility.md), not a model score increase. Targeted verification reuses an existing real long-report task and retained files, exercises save/update/error recovery, and runs the existing cross-platform checks. It does not regenerate reports or rerun the complete model evaluation. [Validation](../record-save-validation.md).

Update the complete installation to v1.1.0 and retain task data outside the installation directory. The packaged English/Chinese instructions and runtime are synchronized.
