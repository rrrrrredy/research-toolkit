# Research Toolkit v3.1.0

[English](v3.1.0.md) · [简体中文](v3.1.0.zh-CN.md)

The release ZIP now includes an editable audit response and a setup preview. Both commands run locally from the unpacked `research-toolkit` directory.

## Prepare an audit response

```sh
python scripts/research_workflow.py review --scaffold-audit --workspace WORKSPACE --task TASK_ID
```

Use an existing task with a pending independent audit. The template carries the manuscript and assignment versions, the original findings and their locations, candidate groups, sources and effective requirements. Decisions, reasons and supporting evidence start blank. The auditor checks the originals, can apply one decision to equivalent findings, and submits the completed response through the regular review path. A passing independent final check delivers the report.

## Preview local setup

```sh
python scripts/research_workflow.py setup --host codex --project . --dry-run
```

The output identifies the current recording setting, the project configuration path and the hooks that setup would configure. New installations start with recording off. The default preview writes no files. After an explicit opt-in, `--apply` installs the hooks for that project. `--no-telemetry` skips configuration for that invocation. Report sharing still requires separate consent. Claude Code and OpenCode also have setup previews.
