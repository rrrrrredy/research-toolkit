# Research Toolkit v0.2.5

[English](v0.2.5.md) | [简体中文](v0.2.5.zh-CN.md)

This patch completes the dedicated seven-case report rerun and fixes an execution path that still added an auditor automatically for evaluations. It includes the corrections merged after v0.2.4.

## What changed

- New evaluations use the configured independent reviewer; a second auditor is required only when explicitly configured. Saved audited plans retain their original requirements. Astra may author and review in separate fresh contexts.
- All seven dedicated case prompts use the current review and repair instructions. The pipeline case no longer requires three review rows. Bilingual instructions, case inventories, calibration status, web guidance and the packaged runtime are synchronized.
- The earlier completion statement is corrected: configuration and offline checks did not establish that all seven complete reports had been rerun. Actual report generation and review are now recorded separately.

## Actual seven-report rerun

There were **15 actual Astra calls**: seven report generations, seven first reviews and one review of a changed report. Six supplied-source reports passed their first review. The pipeline report initially exceeded its 6,000-character maximum at 6,020; a recorded 33-character deletion produced a 5,987-character revision accepted as a **stage report**. Its original research requirements R04/R05 remain open because the supplied pack does not contain the requested primary papers and corroboration. The review explicitly records `full_task_complete: false`.

The [evidence bundle](https://github.com/rrrrrredy/research-toolkit/blob/v0.2.5/evals/diagnostics/2026-10-13-dedicated-seven/README.md) retains the pre-call plan, complete requests, reports, raw calls, negative first review and exact repair. All accumulated pipeline requirements were provided together; this was not live 13-turn interaction or full MCP execution. These 15 calls are separate from the earlier four-task, 31-call recheck. CI verifies the saved evidence without calling models.

## Install or update

Use tag `v0.2.5` or its resolved commit. The source archive contains the self-contained plugin in `plugins/research-toolkit/`. Keep that directory intact and keep task data outside the installation. Python 3.10 or newer is required; install `requirements-mcp.txt` only for MCP. See the [installation guide](https://github.com/rrrrrredy/research-toolkit/blob/v0.2.5/docs/installation-versioning.md) and [changelog](https://github.com/rrrrrredy/research-toolkit/blob/v0.2.5/CHANGELOG.md).
