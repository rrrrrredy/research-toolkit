# Research Toolkit v1.4.13

[English](v1.4.13.md) | [简体中文](v1.4.13.zh-CN.md)

This patch distributes [PR #119](https://github.com/rrrrrredy/research-toolkit/pull/119), correcting Skill-only record requirements and explaining entry choices. It also includes previously merged, unreleased [PR #118](https://github.com/rrrrrredy/research-toolkit/pull/118), covering writing guidance and a local revision. A new package is needed to deliver the updated methods to installed users. Under the [version policy](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/compatibility.md), these are compatible fixes, advancing the version to **1.4.13**.

## Changes

- **Skill-only use:** no default requirement to create `task_spec.md`, `progress.json`, CSV/JSONL registries or a delivery receipt. Reuse conversations, material, citations and existing notes, preserving effective requirements, the draft, support and unfinished work for continuation. Deliver the requested report and citations, with a short change note for revisions, without introducing a mandatory notebook template.
- **Entries and steps:** the README explains that the Skill provides methods, CLI and MCP expose the same local tools, and the plugin bundles Skill with MCP, with installation choices. The existing quickstart connects new research, revision and update steps to optional tool operations. Scope follows the need for multi-source analysis, comparison, explanation and supported recommendations, not report length.
- **Writing guidance:** decide edits by a sentence's factual, comparative, explanatory or qualifying role rather than particular words or sentence patterns. Preserve useful attribution, conditions and reasoning. Save the synthetic cold-chain task's local revision separately, retaining original material, outputs, anonymous review and study conclusions. No external project's code, prompts, documentation, examples, data or dependencies were incorporated.
- **Synchronization and compatibility:** update English, Chinese, plugin copies and website method pages. Product runtime code, tool parameters, record formats, CLI/MCP-managed completion contracts and saved-task compatibility remain unchanged. Required reading, analytical depth, instruction following and agreed reviews still apply. No task-data migration is needed.

## Verification and observed scope

PR #119's Linux, minimum-Python, Windows and static-site CI passed, with no submitted reviews or unresolved review threads. Existing local results cover bilingual embedded-Skill synchronization, 49 shared plugin files, static builds and pages, 85 added or changed local Markdown links and anchors, and diff checks.

PR #118's cold-chain revision uses archived synthetic material. It corrects the scope of the recommendation and identifies outstanding delivery-date and route-support conditions while retaining valid comparisons and explanations. It is not a new task or model comparison. Original research and historical results remain unchanged.

These changes correct conflicting requirements, improve usage explanations and retain a specific local revision; **they do not establish better overall research quality, lower operating costs or less rework**. Those benefits have not been measured. Release preparation reuses the existing results, checking only changed version metadata, the new package and existing CI without rerunning research or already-passed local behavior checks.

## Upgrade

Download the [v1.4.13 plugin ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.13/research-toolkit-plugin-v1.4.13.zip) and [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.13/SHA256SUMS), or update the complete checkout to `v1.4.13`. Preserve local task data and intentional edits, replace the plugin package and reload it in the host. Existing managed tasks continue under their saved contracts, without repeating research or reconstructing historical records.
