# Research Toolkit v1.3.1

[English](v1.3.1.md) · [简体中文](v1.3.1.zh-CN.md)

本补丁交付公开版本日志地址过滤修复，以及 v1.3.0 之后已合并的报告上下文改进。不增加工具、必填输入或任务迁移。

## 改动

- **公开地址过滤覆盖实际连接。** 规范化主机名末尾的点，要求全部 DNS 结果均为公开地址，直接连接已校验的数字地址，不二次解析。Host、SNI 和证书校验仍使用规范化后的原主机名，继续禁止重定向。[PR #77](https://github.com/rrrrrredy/research-toolkit/pull/77)。
- **正文定位附带可用上下文。** `save`、`status` 和已登记版本日志查询返回命中段落及相邻原文，保留章节和行号。同次返回中，完全相同的上下文仅返回一次，后续位置通过 `context_ref` 引用首次出现的位置；判断、来源和命中原因仍保留在各自条目中，不同位置的相同文本不合并。[PR #75](https://github.com/rrrrrredy/research-toolkit/pull/75)、[PR #76](https://github.com/rrrrrredy/research-toolkit/pull/76)。
- 安装包还纳入此前已合并的模型评测用户视角与适度验证要求、公开材料集页面和入口移除，并同步九个工具的中英文说明。数据仓库继续使用各自的版本。

## 联网行为

已登记版本日志的读取改为直连，忽略环境变量和系统代理，确保实际连接的是本地已校验的目标。只能经代理联网的环境可能返回现有的 `failed` 结果及原因。其他操作和 TLS 校验不变。

## 验证

PR #77 的 Linux、Windows、最低 Python 版本和静态网站 CI 已通过。两项针对性离线检查覆盖本地及非公开地址拦截、单次 DNS 解析、连接已校验地址、按主机名验证 TLS，以及忽略代理配置；编译、插件和网站一致性检查也已通过。本次发布没有手动重跑这些实现检查，只核对变更后的版本元数据和生成安装包。

新连接实现尚未进行真实在线请求或代理专用网络验证。如需核对安装环境，重新加载更新后的 MCP 服务，查询一条已有且格式受支持的已登记日志：预期返回 `unchanged` 或 `changed`，直连不可用时明确返回 `failed`。保留已保存基准。本次发布不新增省时或研究质量普遍改善的结论。

## 升级

下载 [v1.3.1 插件 ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.3.1/research-toolkit-plugin-v1.3.1.zip)，或将完整仓库更新到 `v1.3.1`。ZIP 包含插件目录、两套清单、双语说明、共用运行代码及方法。按宿主已有插件安装方式使用，仍需 Python 3.10+ 和 MCP 依赖。保留本地任务及有意修改的文件，更新后重启本地 MCP 服务。
