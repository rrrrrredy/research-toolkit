# Research Toolkit v2.0.1

[English](v2.0.1.md) | [简体中文](v2.0.1.zh-CN.md)

Release date: 2026-10-30.

Fix the connection between research handoffs, review inputs and delivery bindings in v2.0.0.

- Changes to supplemental review evidence or retained responses invalidate the affected unit's readiness cache. Downstream work cannot use that stale approval to declare completion.
- One inspection reuses the complete results for shared upstream work instead of rereading it along each dependency branch. Every new call still checks original files, identities and results again.
- Independent review receives navigation to existing production history and retained drafts. Bindings follow actual draft versions, without becoming stale merely because an ordinary activity record is appended.
- Full-report review remains bound to the meaning and scope of current requirements. After the independent responsibilities finish, actual fulfilment can be recorded before delivery. Changes to requirement meaning still require the affected review work.
- Current evaluation prompts follow the existing independent responsibilities. Length measurement applies only when the task requests it. English and Chinese instructions and the plugin package are synchronized.

The observed results concern input, dependency and completion behavior; they do not establish improved research quality. Existing tasks, original drafts and reviews are retained.

Affected compilation, targeted checks on retained records and the plugin build are complete. A saved-state replay through the public review entry returned exactly the retained result without changing existing inputs. Linux, minimum-Python and Windows CI passed; Windows CI executed the symbolic-link and directory-junction checks previously blocked by local permissions. Original failures and recovery records remain, and no research task was rerun for these checks.

This patch repairs the v2.0.0 completion contract. Public interfaces and access to older materials remain unchanged.
