# Research Toolkit v1.3.0

[English](v1.3.0.md) · [简体中文](v1.3.0.zh-CN.md)

本次将补充要求传递修复，以及 v1.2.0 之后已合并的改动交付给按版本安装的用户。其中包含可选的公开版本日志查询功能，因此按 [1.x 兼容性约定](../compatibility.zh-CN.md)发布为次版本 v1.3.0。

## 安装用户能得到什么

- **分析、起草直接收到补充要求。** 显式调用 `research_status(task, stage="analyze")` 或 `stage="draft"` 时，返回非空的补充要求 JSONL，保留原文、状态和处理依据。Agent 无需再将台账复制进 brief。普通状态查询不附加全文，返回要求不等于要求已满足。[PR #68](https://github.com/rrrrrredy/research-toolkit/pull/68)。
- **查询已登记的公开版本日志。** CLI `check-updates` 和 MCP `research_check_updates(task, source_id)` 返回新增或修订条目、来源日期及现有报告的关联位置。无变化返回 `unchanged`；读取或比较失败返回 `failed` 和原因。不覆盖旧证据、不定时监控，也不据此判定报告结论失效。[PR #67](https://github.com/rrrrrredy/research-toolkit/pull/67)。
- **交付前发现同一类本地路径错误。** 稿件与交付检查共用来源 `url`、`read_evidence`、`evidence_path` 检查，报错指出具体字段和正确的任务内相对路径。[PR #65](https://github.com/rrrrrredy/research-toolkit/pull/65)。
- 本版还包含已合并的双语阅读页面、报告更新案例、外部运行记录，以及 Research Review 和 AI 行业材料集的可选入口。材料集仍独立交付，不增加核心依赖，也不计作已验证的 Toolkit 质量提升。

## 已有验证与剩余限制

实现 PR 的既有 CI 和针对性回归已通过。本次仅调整版本元数据、更新记录和发布说明，再生成现有插件；不新增运行代码或测试，不重跑已完成的本地回归和模型评测。

版本日志功能对千问办公的真实在线请求返回 `unchanged`；新增版本的结果来自实际取得网页与其中历史条目的材料回放，不是第二次在线变化观测。其他厂商日志及真实 MCP 客户端端到端调用仍未验证。最小客户端核查：重新加载更新后的 MCP 服务，对已有任务中已登记、格式受支持的日志调用 `research_check_updates`；预期返回 `unchanged`，公开页面确有变化时可返回 `changed`，读取失败须保留为 `failed`，不要覆盖已保存基准。具体任务、输入及限制见 PR #67。用户省时和研究质量改善尚未计量。

## 升级

将完整安装更新到 v1.3.0，保留本地任务数据和有意修改的文件；本地 MCP 服务正在运行时，更新后重启即可。无需迁移任务，也不新增必填配置。Review 和数据仓库继续使用各自的版本序列。
