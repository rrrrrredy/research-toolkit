# Research Toolkit v1.4.5

[English](v1.4.5.md) | [简体中文](v1.4.5.zh-CN.md)

本补丁将 [PR #101](https://github.com/rrrrrredy/research-toolkit/pull/101) 的方法与说明修正分发给插件安装用户。v1.4.4 安装包仍包含通用配额及部分过时的档位说明，更新安装包即可获得修正；已有任务无需迁移。

## 改动

- **补齐统一入口清理。** 当前启动示例不再选择 profile；调用说明与 `status`、`guide` 已返回的统一阶段方法一致。失败案例表单仅在复现旧任务需要时选填历史 profile。历史协议明确标为历史用途，原报告与结果保留。
- **覆盖和深度由任务决定。** 移除详写三至五个对象、最多两个辅助视角及预设章节字数等通用配额。保留比较、机制解释与反证方法，按用户需求、研究问题和可用证据选择并展开。
- **记录和修改对应实际工作。** 移除固定事实数量记账和固定搜索／审改轮次，相关记录可合并更新；围绕实际未决问题推进，修正后复核受影响内容。旧任务完成规则保持不变。
- **删冗余，保留理解所需关系。** 在 `writing-style` 中补充说明与中英文前后对照例子，保留读者理解论证所需的主体、动作、因果和条件。同步中英文、网页方法正文及插件，不新增工具或检查。

## 验证与限制

PR #101 的 Framework checks 和双语文档工作流通过。本地验证覆盖受影响 Python 编译、五份启动 JSON、失败案例 YAML、网站生成、中英文 Skill 同步、网站本地链接，以及插件 49 个共享文件同步。原研究报告、运行记录和评测结果保持原样。

发布准备复用这些结果，本地只核对变化的版本元数据和生成包，由仓库现有 CI 检查发布提交。不重跑研究任务或模型对照。

**研究质量、理解效率和减少返工的收益仍未验证。** 指导修正和分发同步不等于这些收益已经成立。

## 升级

下载 [v1.4.5 插件 ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.5/research-toolkit-plugin-v1.4.5.zip) 和 [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.5/SHA256SUMS)，或将完整仓库更新到 `v1.4.5`。保留本地任务及有意修改的文件，替换插件安装包并在宿主中重新加载。公开接口和旧任务完成规则保持兼容，无需迁移任务数据。
