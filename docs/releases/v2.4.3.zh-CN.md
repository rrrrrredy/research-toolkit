# Research Toolkit v2.4.3

CLI/MCP 共用的使用记录入口现在覆盖原先短异常列表以外的 Python 异常及中断退出，记录结束结果后原样抛出异常，不把失败变为成功。

分享所选文件时，在当前对话中取得用户明确同意。没有自动弹窗，`--confirm-content` 表示已取得同意。默认基础事件仍不包含报告和聊天正文。

一次 CLI／进程场景保留正常 start/save/status、损坏状态导致的失败及 Python 中断。修复前 5 次开始只有 3 条结束记录，修复后 5 次均有结束记录；正常 status 成功，错误仍失败，中断仍退出 130。没有重跑研究任务。插件副本与共享实现一致。

进程被强制终止时无法执行 Python 清理；本次没有补造任何历史调用返回。
