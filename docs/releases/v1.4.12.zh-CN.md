# Research Toolkit v1.4.12

[English](v1.4.12.md) | [简体中文](v1.4.12.zh-CN.md)

本补丁分发 [PR #116](https://github.com/rrrrrredy/research-toolkit/pull/116)。v1.4.11 的评审输入已纳入明确登记的反证来源，但更新提示仍可能遗漏来源关联仅出现在 `counter_evidence` 中的主张；更新安装包后，已安装用户才能获得这次修复。依据[版本约定](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/compatibility.zh-CN.md)，这是兼容的问题修复，因此递增为 **1.4.12**。无需迁移任务数据。

## 改动

- 评审输入与更新提示复用同一来源编号选择函数；`save`、`status` 和已登记版本日志查询继续共用现有 `impact_view` 路径，同时保留支持与反证关联。
- 保留主张／来源链接的字面定位、章节、行号、相邻原文和 `context_ref` 去重。反证继续支持自由文本，仅空白、分号、逗号或 `|` 分隔且与已登记编号完全匹配的内容形成反证来源关联。
- 同步中英文及插件，不新增工具、字段、调用、评审步骤或完成要求。保留原报告、请求、返回和历史记录。

## 已观察结果与验证

已有合成供应商任务的受控副本中，修复前仅返回支持关联 C4；修复后补回反证关联 C1、C2。三条关联均通过引用定位到改写稿第 7 行，并返回第 5—9 行原文上下文；相同上下文只返回一次。部分匹配或未登记编号没有造成误关联。删除字面线索后，相关主张保留为 `not_located`，不猜测正文位置。

**版本日志验证使用保存的合成材料回放，未在线读取。** 修复前后各执行 4 次 CLI 调用和 1 次离线版本日志调用，模型调用为零，原始记录保持不变。本轮验证的是关联能够返回，不是通用语义检索、研究质量提升、返工减少或省时；这些收益仍未验证。

受影响 Python 编译、插件同步和差异检查已通过，另有 18 项相关既有检查通过：12 项记录工作流、5 项版本日志、1 项反证原文与版本绑定检查。首次有 3 项因本机 SSL 日志／临时目录权限受阻；仅调整检查进程环境并重试这些未完成项，失败和成功重试记录均保留。PR #116 的 Linux、最低 Python 版本、Windows 和静态网站 CI 已通过。

发布准备复用这些结果，只核对变更的版本元数据和新安装包，由现有 CI 检查发布提交。不重跑研究任务或已通过的本地行为检查。
