# Research Toolkit v2.5.5

[English](v2.5.5.md) · [简体中文](v2.5.5.zh-CN.md)

This compatible patch fixes continuing report-sharing consent, the language of CLI usage notices, and a first-run failure in the MCP contract check.

- Older continuing grants have no record that the user confirmed the displayed directory scope. On their next use, delivery or `share-offer` shows the actual directory through the existing invitation and queues no new report until consent. An unanswered invitation is not repeated. Confirming continuing sharing records the scope confirmation; later reports use that grant and retain deduplication. One-time sharing does not approve future automatic sharing, and explicit child refusals or narrower grants remain effective.
- CLI requests pass `language` to the first usage notice: `zh` and `zh-CN` return Chinese; `en` returns English. Later calls do not repeat the notice.
- The existing MCP contract check explicitly disables usage recording for both CLI and MCP subprocesses. A fresh installation no longer fails the response comparison because only the CLI emitted its first notice. The comparison remains intact.

Verification used synthetic files and isolated local settings with automatic upload disabled. Public CLI scenarios covered old-scope confirmation, no-answer behavior, one-time sharing, confirmed sibling reports, deduplication, child choices, narrower authorization, and the three language values. The existing packaged MCP contract ran once with usage recording enabled in its parent environment and a fresh usage directory; it passed and created no usage events or content records. No research task or model run was repeated.

English/Chinese usage guidance and plugin copies are synchronized. Install the complete v2.5.5 package to receive the fixes. Existing research records, CLI/MCP operation names and independent review duties remain unchanged. The Release includes the plugin ZIP and `SHA256SUMS`.
