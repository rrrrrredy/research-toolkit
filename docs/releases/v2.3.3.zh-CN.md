# Research Toolkit v2.3.3

[English](v2.3.3.md) | [简体中文](v2.3.3.zh-CN.md)

发布于 2026-11-05。

本补丁修复完成结果的歧义：CLI `finish` 以前在返回 `completed: false` 且同时带有 `action_required` 时会退出 0，现在只有 `completed: true` 才退出 0，并保留 JSON 中的具体缺口和下一步信息。MCP 保留相同业务结果，通信成功不代表研究完成。CLI `review` 成功准备独立任务时仍退出 0。

## 复核已保存的完成状态

```bash
python scripts/check_delivery.py <task-directory> --require-complete --json
```

只读模式要求任务处于 `stage: final`、`status: complete`，且已有交付、要求、独立审阅、审计、验收和版本检查通过。它不调用 `finish`、不启动评审、不修改任务文件或生成回执。交付未完成或依据失效时退出 1，并返回具体 flags 和 findings。完成检查使用当前交付契约；不加此标记时仍可用 `--contract-version 1/2` 诊断历史记录。

默认一致性检查仍允许合法的进行中记录通过。首次交付复用成功 `finish` 的 `delivery_check`，无需立即重复相同检查。纯 Skill 不增加 CLI／MCP 记录要求。中英文说明和插件副本已同步；本版也分发已合并的研究示例中旧免审措辞修正（#137）。

## 验证与兼容

现有 CLI／打包后 MCP 端到端检查覆盖了合法进行中记录、未完成的 `finish`、准备待执行任务的 `review`、当前版本完整验收，以及交付后正文或反证来源变化。完成检查前后任务文件不变，修复后的 CLI 与 MCP 返回相同的未完成业务结果。

受影响 Python 编译、交付与审阅契约、工作流及兼容检查、文档同步和插件检查已在本地通过。既有插件检查中七项符号链接用例因本机 Windows 账户缺少权限而跳过；CI 核对支持的 Linux 与 Windows 环境，PR 保留具体检查结果。

本次修复的是完成状态与退出码，不代表研究质量已经提升。已保存任务、返回字段、独立审阅职责和默认检查保持兼容。更新完整安装包后获得修复，之前已下载的旧包不会自动改变。
