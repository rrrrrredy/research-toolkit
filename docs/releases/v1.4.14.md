# Research Toolkit v1.4.14

[English](v1.4.14.md) | [简体中文](v1.4.14.zh-CN.md)

This patch consolidates improvements to the existing research methods and user guidance, distributing them to installed Skill/plugin users. Public capabilities, interfaces, record formats and completion contracts are unchanged. Under the [version policy](https://github.com/rrrrrredy/research-toolkit/blob/v1.4.14/docs/compatibility.md), this is patch release **1.4.14**.

## Changes

- **Analysis:** explain how to choose meaningful comparisons, distinguish possible causes using evidence, synthesize sources and explain a recommendation. Retain domain lenses and the existing SaaS example, selecting approaches for the question.
- **Whole-report assembly:** explain how sections build on each other, company coverage connects with cross-object analysis, and synthesis advances the answer. Reuse the eight-company pipeline study's original report, revision and review records, with an explicitly labeled teaching transition. Original reports, sources and historical evaluations remain unchanged.
- **Execution:** replace blanket per-stage planning, drafting and review cycles with reading, analysis and writing organized around unresolved questions. Retain existing author checks, agreed reviews and tool-managed task contracts.
- **User guidance:** README and quickstart requests focus on the question, purpose, material and constraints, removing repeated internal execution instructions. The host agent interprets intent using the Skill; CLI/MCP stores the resulting requirements and reports missing fields. Complete fields do not establish correct understanding.
- **Synchronization:** update both languages, Skill entry links, plugin copies and website method pages without new tools, fields, calls or a separate intent-recognition module.

## Verification and effect boundaries

Completed checks cover bilingual Skill/web synchronization, 49 shared plugin files, static-site generation, existing checks of 28 pages and 663 local targets, Skill format, and 38 changed Markdown link occurrences and anchors. Trailing blank lines found by the diff check were corrected; only the affected plugin copies and diff were checked again.

Examples were checked against existing archives. No research reruns, new model comparisons or new test cases were added. This delivery establishes changes to method content and usage guidance; **improvements in research quality, intent interpretation, rework or user time have not been measured**. Release preparation reuses the existing results, adding only version metadata/package verification and the existing CI.

## Upgrade

Download the [plugin ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.14/research-toolkit-plugin-v1.4.14.zip) and [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.14/SHA256SUMS), or update the complete repository to `v1.4.14`. Preserve local task data and intentional customizations, then reload the Skill/plugin in the host. Saved tasks resume under their existing contracts without migration or repeating research.
