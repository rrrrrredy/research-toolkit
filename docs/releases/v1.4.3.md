# Research Toolkit v1.4.3

[English](v1.4.3.md) | [简体中文](v1.4.3.zh-CN.md)

This patch delivers [PR #97](https://github.com/rrrrrredy/research-toolkit/pull/97)'s language compatibility and early validation fix to installed-plugin users. The v1.4.2 ZIP still rejects `zh-CN` and can write research records or advance a stage before returning a language error. Updating the package supplies the runtime fix; existing tasks need no migration.

## Changes

- **Use the same language handling in all three entry points.** `start`, `status` and `guide`, including their MCP tools, accept `zh-CN` and `zh` for the existing Chinese methods. `en` still selects English, and defaults remain unchanged.
- **Validate before writing research state.** `start` handles language before writing task records; `status` handles it before saving stage changes. Unsupported values report `language must be "en" (English), "zh" or "zh-CN" (Chinese).` Stage errors separately identify the allowed stage values.
- **Keep the installed interface aligned.** MCP descriptions, English/Chinese usage docs and plugin copies are synchronized. No new fields, calls or delivery requirements are introduced.

## Validation and limits

PR #97 reused the archived `zh-CN` start request from the compressed-air study through the shared CLI dispatch layer in a temporary task directory. It succeeded on the first call and returned Chinese guidance. The two targeted regressions also checked `en/zh` compatibility, Chinese clarification guidance, and rejection of invalid languages before research records or stages change. Both passed in 1.499 seconds after using the existing writable temporary-directory setting; the original archive was preserved and the research task was not rerun.

Affected code compiled, plugin synchronization passed for 49 shared files, and PR #97's Framework checks and bilingual documentation workflow succeeded. Release preparation reuses those results and checks only the changed version metadata and generated package locally; the existing repository CI runs on the release commit. No model comparison or previously passed local implementation check is rerun.

**Overall research speedup remains unverified.** The saved request and state-preservation behavior are verified; the historical 10.812-second correction episode is not a measured time saving from this patch.
