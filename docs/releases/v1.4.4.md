# Research Toolkit v1.4.4

[English](v1.4.4.md) | [简体中文](v1.4.4.zh-CN.md)

This patch delivers [PR #99](https://github.com/rrrrrredy/research-toolkit/pull/99)'s unified research entry and method loading to installed-plugin users. The v1.4.3 package still offers Lite/Full selection and routes legacy Lite tasks to compact methods. Updating the package supplies the shared complete methods without migrating saved tasks.

## Changes

- **One research entry.** Default instructions, quickstarts, agent setup cards and website links no longer ask users or agents to choose Lite or Full. The request determines research scope, depth and length, including long-form and in-depth work.
- **One method set.** Stage guidance reuses the existing complete methods. Useful analysis guidance and examples from the former compact guide move into the shared analysis reference. Methods are loaded as needed; this does not impose one report structure or add a review step.
- **Saved work continues.** Historical `lite/full` arguments remain accepted for compatibility. Existing tasks retain their recorded completion rules and history while receiving the shared methods. For example, a saved checklist-only task can still finish using its checklist; the update does not suddenly require an additional review. New requests omit the legacy argument. Old quickstart URLs point to the unified guide.
- **Aligned distribution.** English and Chinese entry documents, CLI/MCP descriptions, website pages and plugin copies agree. Contribution guidance selects verification according to the affected behavior and existing coverage, without imposing a universal test type.

## Validation and limits

PR #99's Framework checks and bilingual documentation workflow passed. Completed local checks covered affected Python compilation, JavaScript syntax, generated website and bilingual Skill synchronization, and 49 shared plugin files. The existing MCP stdio end-to-end check passed in 13.721 seconds for the successful run, covering shared bilingual guidance and saved-task compatibility along with its existing review, revision and delivery scenarios. The run used simulated review processes; the time excludes earlier environment-related failed attempts.

Release preparation reuses those results and checks only the changed version metadata and generated package locally. Existing repository CI checks the release commit. No research task or model comparison is rerun.

**Research quality improvement remains unverified.** A unified entry and shared method loading do not establish better analysis, instruction following or faster research.

## Update

Download the [v1.4.4 plugin ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.4/research-toolkit-plugin-v1.4.4.zip) and [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.4/SHA256SUMS), or update the complete checkout to `v1.4.4`. Preserve local tasks and intentional edits, replace the plugin package and reload it in the host. No task-data migration is required.
