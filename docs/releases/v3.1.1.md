# Research Toolkit v3.1.1

[English](v3.1.1.md) · [简体中文](v3.1.1.zh-CN.md)

- When a source contains an exception that would change the reader's decision, the reviewer checks what the report would lead the reader to do in that situation.
- When an edit touches an issue that reviewers previously raised, the auditor answers the reader's original question from the current draft and checks that answer against the source and the edit. If a condition, responsible party or required step has been lost, the auditor returns the issue to the writer.

The release includes `research-toolkit-plugin-v3.1.1.zip` and `SHA256SUMS`. [Installation guide](https://rrrrrredy.github.io/research-toolkit/quickstart.html)
