# Research Toolkit v2.3.4

[English](v2.3.4.md) | [简体中文](v2.3.4.zh-CN.md)

发布于 2026-11-09。

本补丁修正机械评测判定，并澄清随 Skill 和插件分发的研究引导。

## 修改内容

- `scripts/run_evals.py` 不再因词汇、实体字符串命中或没有通用过程词而加分。通用过程词与强断言命中改为上下文核读提示，不自动确定缺陷、扣分或阻断完成。
- 必需和禁止的标题按实际 ATX／Setext Markdown 标题检查，排除代码与 HTML 注释。现有七题保留主题覆盖，不再强制题面未要求的字面标题。
- 双语引导区分工具箱用户、报告目标读者和独立评审 Agent。未被执行器消费的可选比较模板不再要求匹配资源上限；实际耗时、费用与调用量作为执行背景，不作为质量或停止标准，运行时限制和历史冻结协议不变。

分数按剩余机械项目重新归一化，不可跨检查器版本直接比较。历史报告、来源包及已归档评测输入与结果的哈希保留。

## 验证与兼容

修改前编写的 12 组定向 CLI 输入，在原实现和新实现各运行一次，保留请求、输出和日志。它们显示局部机械判定修正，不是研究质量提高：词汇齐全但捏造销售数字的稿件，两版仍机械通过。本次未运行新的研究任务；`research_quality_status` 仍为 `not_evaluated`，整体研究质量收益未测。

受影响 Python 编译、既有检查、网站／插件构建检查及同步已在本地通过。发布提交的 CI 由当前 PR 核验。

既有返回字段、研究完成契约和独立审阅职责不变；纯 Skill 使用不新增 CLI／MCP 记录要求。

## 获取更新

即使不发 Release，合并后也可从 `main` 获取修正；旧下载 ZIP 和固定 tag 不会改变。即使发布新版，已有安装仍须更新完整副本，并保留任务数据。

发布资产沿用 ZIP + `SHA256SUMS`。插件包含 Skill、`research_guidance` 等，不包含 `scripts/run_evals.py`；自动生成的整仓库源码包供 CLI／评测使用者和维护者使用。
