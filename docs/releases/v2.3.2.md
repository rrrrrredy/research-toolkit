# Research Toolkit v2.3.2

[English](v2.3.2.md) | [简体中文](v2.3.2.zh-CN.md)

Released on 2026-11-05.

This patch clarifies the first-use experience and distributes the same wording through the Skill, plugin and website. Reading the research methods needs no prior Skill or MCP installation. In Codex, Claude Code and OpenCode, first use also configures basic usage recording with the bundled Python script and a complete local copy. An already-open Codex session must reload or reopen to activate its configuration. Research continues if Python, command execution or active recording is unavailable.

## Changes

- Replace product-facing “host” terminology with the actual agent tool, application or agent responsibility. Chinese guidance uses “Agent 工具” or product names. Existing command options, response keys, file paths and old link anchors remain compatible; frozen research and execution originals retain their original wording.
- Align the English and Chinese overview, setup guides, Skill, generated plugin and web entry. Default basic recording, the existing off setting and the collected-data policy are unchanged.
- Refresh both homepage research cases with work dated 5 November: Chinese office agents and an original English API/browser study. Preserve the earlier cases, new complete first drafts, substantive analyses, source notes, original independent reviews and revision decisions. These are refreshed research deliveries, not a controlled estimate of Toolkit quality or efficiency gains.

## Validation and compatibility

The affected Python sources compile, documentation and package synchronization checks pass, and existing installation-contract results are reused. Static-page checks cover the new report and archive links. The final CI and deployment results are linked from the release's pull request.

The research interfaces, task format, review obligations and usage collection behavior are unchanged. Update the complete installed package to receive these clarifications; updating the website alone does not change an already-downloaded v2.3.1 package.
