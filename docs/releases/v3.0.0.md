# Research Toolkit v3.0.0

[English](v3.0.0.md) · [简体中文](v3.0.0.zh-CN.md)

Research Toolkit can now take a registered draft through independent review, revision, and final delivery. Agents handle the steps between draft and delivery.

## What changed

- **Two concurrent Agent slots are enough.** Three independent groups cover the seven content perspectives, with specialist review when needed. An independent auditor decides which findings are supported, and a separate Agent checks the final report. When both slots are busy, the remaining work waits in a queue. The next assignment starts as a slot opens. The host must be able to launch or resume later turns.
- **Check the same issue once.** Toolkit builds the audit checklist from the original reviewer replies. If four reviewers flag the same issue, the auditor checks the source once and applies one decision to all four findings while keeping each reply traceable. The source decides whether the report changes. An evidence-backed decision can overrule all four reviewers.
- **A passed final check delivers the report.** The Agent reads the current report and verifies the necessary fixes. If the draft needs work, Agents revise it and recheck it. Once it passes, Toolkit records completion, returns the final report and its delivery receipt, and ends the task.

Returning reviewers can reuse evidence they already read when it remains applicable and unchanged. They still check the current full draft and the sources affected by the changes. Toolkit also avoids repeatedly hashing the same inputs in one inspection of saved work.

For a compact submission acknowledgment, use `review --summary` in the CLI or `summary: true` with MCP `research_review`. It shows whether the reply was saved, how much work remains and what to do next. Request and handoff files and configured reviewer responses can include a UTF-8 byte order mark. CLI and MCP accept `delivery_message` alongside the existing `message` spelling. Basic usage recording is off on new installations and can be enabled explicitly. Sharing a report requires separate consent.

## What we verified

A real DeepSeek draft ran through to final delivery in Codex with at most two active native Agent turns. The first review produced 39 findings that were handled in 17 audit decisions. In a separate test on the same draft, four seeded review responses each contained a genuine defect and an incorrect objection. A fresh auditor made two group decisions against the official source. It confirmed the defect, rejected the incorrect objection, and kept the test task unfinished because the four responses were fixtures. The broader comparison of research quality, cost, and time is deferred.

## Update

Download `research-toolkit-plugin-v3.0.0.zip` and `SHA256SUMS` from the Release. Verify the ZIP checksum, unzip it, and replace the complete plugin. Existing tasks saved under review contract 2 can continue with their original assignments.
