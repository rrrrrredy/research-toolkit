# Research Toolkit v2.0.0

[English](v2.0.0.md) | [简体中文](v2.0.0.zh-CN.md)

Local release preparation; not published.

This version connects substantive research collaboration, progressive drafting and independent delivery into the existing Skill, CLI and MCP entry. The host runs agents; Toolkit supplies current requirements, originals, dependent research artifacts and version-bound assignments.

- Native host delegation is the default and needs no separate API setup. New work cannot finish through author self-review. Seven distinct content perspectives, applicable domain review, independent audit and separate final acceptance retain actual host identities and original replies.
- The existing work/save interfaces carry research units, actual dependencies, full analyses and concise handoffs. Completed requirements remain effective. A changed selected record affects its real dependents; unrelated registry additions do not invalidate every branch. One declared writer maintains the main manuscript, with explicit handoff to a successor.
- Important upstream work is independently reviewed before downstream work declares completion. The audit checks critical claims and requirements and selects passed/no-issue content from the full report, expanding checks by the observed cause. Fixed first/last/hash paragraph sampling is retired.
- Method originals own distinct responsibilities; stage guidance and host entry documents point to them. English, Chinese and plugin sources use the same contract. Default research runtime cutoffs and time/token summaries are removed; event timestamps, failure recovery, user cancellation and raw historical records remain.

The major version changes completion semantics: legacy parameters and saved materials remain readable, and historical receipts are not rewritten, but resumed work must complete the current independent responsibilities. Existing language, source/counter-evidence and file-protection fixes remain.

Affected code compilation and the existing mandatory checks runnable on this machine are complete; the packaged MCP control with synthetic role responses passed. With the implementation frozen, the retained RSI task completed native research handoffs, progressive assembly, seven independent content perspectives, domain review, independent audit, final acceptance and delivery. Four necessary findings from the first review were corrected locally and independently resolved by the auditor. The original report, negative first-review results and revision records remain available.

Seven ordinary symbolic-link checks could not run without Windows symlink creation privileges. The Linux/Python 3.10 matrix and live deployment were not run. One check's initial complete console output was overwritten by a retry-log naming error; its original exit code, failure account and targeted follow-up results remain. These observations support the exercised interface and collaboration behavior; no version-effect comparison of overall report quality, user effort or speed was performed.
