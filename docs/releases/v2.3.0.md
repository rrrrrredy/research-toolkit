# Research Toolkit v2.3.0

[English](v2.3.0.md) | [简体中文](v2.3.0.zh-CN.md)

Release date: 2026-11-04.

This release adds shared usage trajectories and distributes the common Agent execution interface. Existing research tasks, CLI/MCP calls and independent review requirements remain compatible. These additional capabilities use a minor version.

## Usage collection and private viewing

- CLI and MCP record allowlisted operation metadata through the same implementation: entry, version, installation channel when known, call order, result, timing and task/session relationships. Upload runs in the background through a local queue.
- Basic collection is on by default with a first-use notice. Prompts, conversations, research titles, reports, URLs, local paths and credentials are excluded. Users can turn collection off and delete their installation's uploaded data.
- Plugin hooks and the separately configured recording script connect operation events in Codex, Claude Code and OpenCode. Pasted instructions alone do not run that script in v2.3.0. Historical versions do not upload retrospectively.
- Research content is shared only through an explicit one-time command selecting files from a task. Events and selected content are read through a private GitHub report; aggregate statistics, task/session timelines and downloadable records have separate views.
- The receiver uses Cloudflare Workers and D1, with separate collection and administration credentials. Details: [usage data](../usage-data.md).

## Common Agent execution

- The execution adapter now selects an agent tool driver through a common session interface. Codex is one driver alongside Claude Code and OpenCode CLI drivers; shared execution no longer creates a Codex session directly or silently selects Codex.
- Input updates use steering when the agent tool supports it, otherwise continue the original session after the active invocation. Original results retain the versions of inputs actually delivered.
- Existing native-agent configuration and explicit legacy review formats continue to work. Bilingual methods, setup instructions and the plugin package share these changes.

## Execution observations

The retained local scenario exercised real CLI and packaged MCP calls against Worker/D1, covering failed calls, retries, private fields, sharing, opt-out and deletion. Native Codex and OpenCode runs captured child Agent relationships and continuation. Constructed hook inputs exercised event identity and the packaged Windows launcher. See [implementation observations](../usage-data-validation.md) for the actual commands, paths and results represented by these records.

The deployed receiver accepted five test events from two packaged CLI calls and one selected two-file packet. The private GitHub workflow produced the timeline and artifact. Deletion removed those events and files, and the next report cleared the earlier report copies. This online transport exercise ran on GitHub's Ubuntu runner.
