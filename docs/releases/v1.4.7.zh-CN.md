# Research Toolkit v1.4.7

[English](v1.4.7.md) | [简体中文](v1.4.7.zh-CN.md)

本补丁分发已合并的 [PR #105](https://github.com/rrrrrredy/research-toolkit/pull/105) 和 [PR #106](https://github.com/rrrrrredy/research-toolkit/pull/106)。v1.4.6 安装包尚不包含草稿文件保护修复，升级后安装用户即可获得该修复。

## 改动

- **保护草稿的实际写入位置。** 原保护逻辑检查输入路径，写入却使用解析链接后的目标。任务内预先存在的链接因此可能将草稿保存重定向到受保护的任务记录。本次复用现有路径解析，在暂存或整批写入前同时检查两个位置。错误指出 `draft.path`，说明链接目标也受保护，并提供 `reports/draft.md` 等正确路径示例。
- **整理需求时保留原意。** 保留需求用途、关键限制，以及影响理解的原话或背景。摘要或提纲若偏离原要求或后续有效补充，依据原输入修正规划。沿用现有任务规格，不新增字段或步骤。
- **修正 Cursor 配置入口。** 中英文快速开始均指向使用指南中实际包含虚拟环境安装和 MCP JSON 配置的章节。同步中英文及生成的插件副本。

## 验证与限制

PR #105、PR #106 的 Framework checks 和双语文档工作流通过。已完成的本地验证包括受影响代码编译、现有 12 项保存检查、49 个共享文件的插件同步、中英文内容与链接目标核对，以及 `git diff --check`。

使用真实 Windows 目录联接的合成 CLI 任务复现了缺陷：修复前，通过 `drafts → state` 保存会覆盖 `state/task_spec.md` 并返回成功；修复后拒绝保存，任务规范与同批提交的来源记录哈希均保持不变。普通报告及指向普通报告目录的联接保存成功。

**文件符号链接在本环境中仍未验证。** Windows 创建该链接时返回 `WinError 1314`，目录联接结果不能替代文件符号链接的实际执行结果。最小补验：在允许创建文件符号链接的环境中，新建合成任务，建立 `draft.md → state/task_spec.md`，再通过 CLI 保存到 `draft.md`。预期返回 `ok: false`、错误指出 `draft.path`，任务规范及同批记录哈希不变。仅使用合成文件。

发布准备复用上述结果，本地仅检查变化的版本元数据与安装包生成，由仓库现有 CI 检查发布提交。不重跑研究任务或针对未变行为已通过的本地检查。**规划指导减少需求遗漏、改善研究质量的实际收益仍未验证。**

## 升级

下载 [v1.4.7 插件 ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.7/research-toolkit-plugin-v1.4.7.zip) 和 [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.7/SHA256SUMS)，或将完整仓库更新到 `v1.4.7`。保留本地任务及有意修改的文件，替换插件安装包并在宿主中重新加载。公开接口及已有任务格式保持兼容，无需迁移任务数据；解析到受保护目录的草稿路径将按原有文档约定被拒绝。
