# Research Toolkit v2.4.0

[English](v2.4.0.md) | [简体中文](v2.4.0.zh-CN.md)

This release makes long-form research in English and Chinese across fields the active product and benchmark scope.

## Changes

- Replace the active seven Chinese questions and five short-task prompts with 13 independent long-research questions and 15 report assignments. The two additional assignments independently answer the microdrama and test-time-compute questions in the other language from the same frozen material. Historical task definitions and results retain their original identities.
- Keep execution and judgment in the existing `evals/` structure: original task and materials, complete first manuscripts, independent findings, revisions and actual completion results. The existing runner accepts repeated `--case` selections; unknown IDs fail before output is written, and omission still selects all active cases.
- Recognize a report's source URL or exact title as a citation to its registered material, including existing task-local IDs associated with that exact URL. The evaluator also distinguishes Markdown table separators and punctuation inside linked paper titles from repeated prose. These repairs address observed false flags without changing research acceptance.
- Reuse unchanged first-use configuration for Codex, Claude Code and OpenCode, including active plugin configuration and an existing off setting. Reload instructions apply when configuration actually changes. The methods remain directly readable.
- Restore saved research with binary source attachments and normalize empty CSV fields through the existing record reader. Full original files stay accessible, while unrelated blank columns do not change selected input meaning.
- Align current bilingual positioning and writing guidance with developed long research, remove repeated generic qualifications, and preserve conditions that change an argument. The website links to the new bilingual research and retains earlier cases. The existing office-agent report has a separately archived editorial revision.

## Results and validation

The [baseline study](../../evals/studies/2026-11-09-long-research/README.md) contains the reports, actual findings and preserved first outputs. Corrections are located in those manuscripts; the study is not a fixed-model version comparison. It began with Astra API execution and continued with the authorized Codex agents after an explicit exhausted-credit response.

Engineering evidence retains the first-use and selected-case CLI scenarios, binary-original recovery, CSV-input normalization and exact source-mapping observations. Existing mandatory checks, including their initial failures and targeted corrections, are recorded with the study. These outcomes describe software behavior and the individual report revisions.

## Compatibility and updating

This is a compatible minor release: it adds selectable long-research benchmark execution and replaces the active question bank. CLI/MCP operations, task formats, independent review duties and the completion contract are unchanged. Pure Skill use gains no required task registries.

Update the complete installed package while retaining task data. The plugin contains the shared methods, task tools and usage-configuration changes. The repository source archive contains the benchmark and evaluator; those files are not added to the default plugin installation.
