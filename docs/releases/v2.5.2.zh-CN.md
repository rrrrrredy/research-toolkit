# Research Toolkit v2.5.2

[English](v2.5.2.md) · [简体中文](v2.5.2.zh-CN.md)

这是一个兼容补丁，修复报告分享授权和可执行 MCP 示例。

- 收到报告分享邀请后，用户明确授权上层项目时，清除当前任务到所选项目之间的旧邀请标记，下一篇报告可以沿用该授权。保留明确的拒绝、单次分享和待处理的重新提示选择，复用现有设置与内容队列。
- README 示例通过 `research_save` 登记来源、主张及 `main=true` 主稿，由 `--host-task` 传入当前调用 Agent 的真实任务或会话 ID。新版输入不再被无须提交的历史自评哈希拦截。原始输入、哈希和回复一起保存在 `examples/mcp/history/`。
- 现有 MCP 契约检查直接执行 `examples/mcp/capture.py`，覆盖 README 命令及底层接口。示例首次命令负责准备独立任务；实际审阅、审计和验收仍须分别提交完成结果。
- 旧 Lite 教学输入明确归档，Grok 使用说明补充按当前 Toolkit 版本更新私人技能。旧记录、历史评测脚本及旧参数兼容保留；新任务使用统一研究入口。

离线分享核对复现了 v2.5.1 的失败，确认修复后的自然操作顺序、重复交付去重和明确选择保留。使用当前调用 Agent 的真实 ID 运行修正后的示例，五次 MCP 调用成功，并准备了八项独立内容审阅任务。以上验证使用虚构文件且关闭上传，没有执行模型审阅或重跑研究任务。另移除一处无用的 Lite 指导导入，同步中英文使用说明和插件副本。

请更新完整安装包至 v2.5.2，以取得分享修复。如果旧版已经留下遮住上层授权的邀请标记，在受影响任务上重新确认同一项目授权即可清除。旧任务数据、审阅职责和交付契约不变。Release 提供插件 ZIP 和 `SHA256SUMS`。
