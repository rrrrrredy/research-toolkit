# Research Toolkit v2.1.0

[English](v2.1.0.md) | [简体中文](v2.1.0.zh-CN.md)

发布日期：2026-11-02。

研究准备与独立任务现在直接提供完整输入的阅读入口。此前展开大份 JSON 时，可见输出可能被截断，执行者需要自行拆开字段、重新定位原件。

- `status(work=...)` 在原 `work_context` 之外返回 `reading_ref`。宿主原生内容审阅、审计和最终验收的待办，在冻结的 `assignment_ref` 之外提供同样的阅读入口。
- Markdown 目录沿用已有字段。长字符串以完整 UTF-8 文本打开，不再嵌在 JSON 转义字符串中；结构化记录保留字段、顺序、空值、布尔值和数值。原件路径、哈希和版本引用仍然可读。
- 相同内容共用 `logs/reading/` 下的文件，变化后保留另一份视图。这些派生文件不改变输入哈希、任务版本或完成条件。不带 `work` 的普通状态查询不生成阅读文件。
- 中英文和插件内容同步。没有新增工具、必填参数或调用步骤；原有接口、已保存任务和独立职责保持兼容。这次增加兼容能力，采用次版本升级。

使用同一项已完成研究保留的四份输入，分别覆盖生产、内容审阅、审计和验收。生成的完整长文本与保存输入逐字一致，原始记录未改变。新增入口用于导航，没有把材料摘要化。未重跑研究或调用模型。

受影响代码编译、插件与文档同步、现有工作流及续接检查、打包后的 MCP 端到端控制均通过。插件构建检查中可运行的控制通过，7 项文件符号链接控制因本地 Windows 权限跳过；Linux CI 运行这些现有控制。MCP 场景使用合成执行者验证接口行为，不评价研究质量。原始观察与执行记录单独保留，不混入发布包。

已经验证的是可用的完整输入阅读路径。宿主是否因此减少遗漏、返工或改善最终正文，尚未测量。
