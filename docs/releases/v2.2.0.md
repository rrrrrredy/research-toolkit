# Research Toolkit v2.2.0

[English](v2.2.0.md) | [简体中文](v2.2.0.zh-CN.md)

Release date: 2026-11-03.

An optional Codex execution adapter connects prepared research work to native persistent sessions and imports their original results into the same Toolkit task. It uses the installed Codex login and model settings; no separate API setup is required.

- `scripts/research_host.py` accepts selected existing `work`, `draft` and `review` arguments. Research planning, source acquisition and substantive decisions remain with the researchers. See the [usage example](../usage-modes.md#codex-host-execution).
- The adapter reads complete prepared inputs, waits for actual upstream readiness, saves original contributions against the inputs delivered, and routes changed requirements or material back to the recorded producer. Running turns receive updates through the host's steering interface.
- Independent review, audit and acceptance use separate native contexts. Revisions resume the recorded reviewers; original prompts, replies, execution events and failures remain available. Negative findings return to the coordinator without an automatic rewrite-to-pass loop.
- This release also distributes PR #129's already-merged review-continuation changes: the original independent context, prior inputs and concrete revision differences accompany current originals.
- Existing Skill, CLI and MCP interfaces, saved tasks and completion requirements remain compatible. This is an optional execution command, not a new research entry or persistent service. A batch ending does not finish the task; delivery still uses the existing `finish` contract. The additional compatible capability warrants a minor version.

## Observed execution and verification

One task used constructed equipment-selection materials with real `gpt-6-astra` sessions: three producers, two unit reviewers, eight full-report reviewers, one auditor and one final acceptance context. New requirements reached the original producers, an in-flight assembly received an additional instruction, and the final report reflected those changes. Independent findings led to three citation-link corrections and one sentence correction by the original authors. Final delivery returned `completed: true`.

The run also exposed integration and coordinator errors. They and the original outputs remain in the separate local run archive; no study data is included in the plugin. A premature downstream start was corrected after the native run and checked against its saved state, without another model run. The explicit partial-contribution stopping branch was inspected and compiled, not separately executed. This is execution evidence for the described path, not a measured gain in research quality, speed or reduced rework.

Affected compilation and plugin synchronization passed. The existing local plugin check passed ten controls and skipped seven file-symlink controls because Windows lacked the required privilege. Repository CI supplies the existing Linux and Windows checks. English, Chinese, package metadata and plugin payload are synchronized.
