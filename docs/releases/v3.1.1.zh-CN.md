# Research Toolkit v3.1.1

[English](v3.1.1.md) · [简体中文](v3.1.1.zh-CN.md)

- 原始资料里的例外会改变读者的决定时，评审要看读者照着报告会怎么做，并核对这一做法是否成立。
- 改稿碰到以前审过的问题时，审计 Agent 先用当前正文回答读者原来的问题，再核对原始资料和改动。如果重要条件、责任方或必做步骤丢了，就把这件事退给写稿 Agent。

本次发布附插件包 `research-toolkit-plugin-v3.1.1.zip` 和校验文件 `SHA256SUMS`。[快速安装](https://rrrrrredy.github.io/research-toolkit/quickstart.zh-CN.html)
