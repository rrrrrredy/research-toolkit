# Research Toolkit v1.4.10

[English](v1.4.10.md) | [简体中文](v1.4.10.zh-CN.md)

本补丁分发已合并的 [PR #112](https://github.com/rrrrrredy/research-toolkit/pull/112)。v1.4.9 安装包仍包含无条件篇幅统计、逐单元固定复审循环，以及整篇返回工作流或写作指导的旧行为；更新安装包后才能获得本次调整。公开接口及已有任务格式保持兼容，无需迁移任务数据。

## 改动

- **篇幅统计按任务需要执行。** 仅在任务有篇幅限制或交付需要统计时计数并记录口径，明确的篇幅要求继续有效。
- **取消逐单元固定复审循环。** 修正已确认的问题，核对受影响内容，并执行任务已声明的评审要求；保留必要修订及既有完成条件。
- **指导按阶段返回。** 规划保留需求、任务规格、分析单元及深度规划；收集保留来源处理和主张记录；起草、修订保留写作指导及示范入口。`start`、`status` 和 `guide` 共用现有逻辑，没有新增工具、必填字段或调用步骤。

完整的 Serving 论证示例、三组研究取舍示范及状态字段说明仍在原文中按需读取。中英文与插件同步，示范正文、原报告和历史记录保持不变。

## 已观察结果与验证

中英文四个受影响阶段的实际返回已核对，默认返回的参考内容有所减少。**这是加载内容量的变化，不是研究质量提升、返工减少或整体提速的证据；这些收益仍未验证。** 本轮不重跑研究任务或新增模型对照，也不改写此前对照的局部增量与遗漏。

PR #112 的 Linux、Python 3.10、Windows、插件同步及 MCP CI 已通过。CI 曾发现新增诊断日志在 Windows 默认控制台直接输出中文时发生编码错误，已仅将该行改为 JSON 默认字符转义，随后 Windows MCP 通过；产品返回内容不变。

PR 中保留首次本地受限的长路径、HTTP 和 MCP 验证记录，并补充相应脚本在 CI 通过的结果，没有将其改写为“本地全部通过”。发布准备复用这些结果，只核对变更的版本元数据和新安装包，由现有 CI 检查发布提交，不重复运行未变行为已通过的本地检查。
