# Research Toolkit v1.5.0

[English](v1.5.0.md) | [简体中文](v1.5.0.zh-CN.md)

本地准备，尚未发布。

本版以模块化研究执行与协作为目标：规范与方法按职责维护、按问题取得；有效要求和选定原文进入共同工作输入；分析成果通过现有保存与接续能力交接；评审依赖在需要评审时生效。

现有工具名称、调用方式、默认阶段指导和旧任务完成契约保留。新增输入均为可选：`guide/status.methods`、`status.work` 和分析稿的 `based_on`、`host_task`。详情与示例见[使用说明](../usage-modes.zh-CN.md#研究委派与成果交接)。

本版不内置新的调度平台，不新增必经评审。[验证原始记录](../../evals/diagnostics/2026-10-29-research-path/README.zh-CN.md)保留 1 项合成任务的 12 次 CLI 操作及既有检查结果；宿主多 Agent 协作尚未运行，研究质量、返工或用户耗时的变化尚未测量。发布前仍需按现有仓库流程处理提交与 CI。
