# Research Toolkit v1.5.0

[English](v1.5.0.md) | [简体中文](v1.5.0.zh-CN.md)

2026-10-29 · [实现 PR #122](https://github.com/rrrrrredy/research-toolkit/pull/122)

本版以模块化研究执行与协作为目标：规范与方法按职责维护、按问题取得；有效要求和选定原文进入共同工作输入；分析成果通过现有保存与接续能力交接；评审依赖在需要评审时生效。

现有工具名称、调用方式、默认阶段指导和旧任务完成契约保留。新增输入均为可选：`guide/status.methods`、`status.work` 和分析稿的 `based_on`、`host_task`。详情与示例见[使用说明](../usage-modes.zh-CN.md#研究委派与成果交接)。

本版不内置新的调度平台，不新增必经评审。宿主负责 Agent 启动、消息、等待和取消，主作者将实际分析整合进主稿。输入文件变化会被提示，但不会自动使结论失效；局部成果完成不等于整项任务完成。

[验证原始记录](../../evals/diagnostics/2026-10-29-research-path/README.zh-CN.md)保留 1 项合成任务的 12 次 CLI 操作，子进程墙钟合计 9.625 秒，以及既有检查结果和中途失败。正文、自检和宿主引用由脚本提供。PR #122 已通过 Linux、Windows、Python 3.10 和打包 MCP 检查。宿主多 Agent 协作尚未运行，研究质量、返工或用户耗时的变化尚未测量；上述耗时仅表示接口执行时间。

安装新版[插件包](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.5.0/research-toolkit-plugin-v1.5.0.zip)，可用随包发布的 [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.5.0/SHA256SUMS)核对。旧任务无需迁移；纯 Skill 用户更新 Skill 与参考文件即可，不需要补建工具管理记录。
