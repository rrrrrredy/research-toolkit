# Research Toolkit v2.4.1

[English](v2.4.1.md) | [简体中文](v2.4.1.zh-CN.md)

本补丁修复 Windows 任务保存和使用事件归属。既有任务记录、研究接口及独立审阅职责保持兼容。

- 工程契约检查明确关闭采集，包含插件 MCP 子进程。检查中故意触发的错误不再进入普通使用统计。
- 普通路径与 Windows 长路径写法关联到同一任务。上传事件没有增加报告正文或本地路径。
- 任务存储与锁复用 Windows 长路径处理，使有效稿件在历史备份目录和临时文件名变长后仍能保存。文件访问失败保留旧记录，并指出需要处理的文件，不再让 Agent 修改研究字段。
- 推理时计算、前置仓和端侧模型三份归档报告另存表达修订稿，保留原稿、中间修订及独立意见。来源核对还纠正了端侧稿对 ASR 实验 328 秒音频时长的错误描述。

[修订稿与独立记录](../../evals/repairs/2026-11-10-report-expression/README.zh-CN.md)。此次改稿没有重跑 benchmark，也不作为 Toolkit 研究质量增益的测量结果。

Skill、CLI、MCP 和插件沿用同一实现。安装 v2.4.1 安装包或更新仓库副本即可取得修复。

历史记录补充：本版本同时包含 #141，清除已公开来源记录中过期的授权参数并同步哈希记录；不改变原运行结果。
