# Research Toolkit v2.5.7

[English](v2.5.7.md) · [简体中文](v2.5.7.zh-CN.md)

本补丁保留已有任务文件的权限，并补齐选中内容进入分享队列前的凭据检查。

- 原子写入任务文件和批量保存记录时，替换前沿用目标文件已有的权限位。共享文件保留已设置的访问权限；新文件沿用原有创建方式。
- 分享检查补齐 `credentials.json`、`client_secret*.json`、`secrets.yaml`、`.npmrc`、`.netrc` 等常见凭据文件名，以及可识别的 Slack／Google 令牌、JWT、授权／密码字段中的值和带密码的数据库连接。原有私钥与平台令牌检查保留。任一文件被拒绝，本批选中文件均不入队；报错只指出文件，不打印凭据。
- 正常报告、引用、哈希、明确脱敏内容和变量占位示例仍可分享。检查限定在选中文件内，分享同意、目录授权范围和研究完成规则保持不变。
- 删除工作流中无用的 `hashlib` 导入和 `current` 变量，同步中英文分享说明及插件副本。

## 验证

实现前扩展已有记录工作流检查：通过原子写入与 CLI 保存核对 POSIX 文件权限保持，通过 CLI 在隔离本地队列、关闭自动发送的条件下核对分享。凭据样例须被拒绝且本批文件均不入队；正常报告入队后正文须完整保留。继续使用已有保存失败回滚检查。本补丁不重跑研究任务、不进行模型对照。

## 更新

替换完整插件或仓库安装即可取得脚本及同步说明，已有任务无需迁移。Release 提供完整插件 ZIP 和 `SHA256SUMS`。
