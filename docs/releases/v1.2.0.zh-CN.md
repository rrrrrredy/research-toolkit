# Research Toolkit v1.2.0

[English](v1.2.0.md) · [简体中文](v1.2.0.zh-CN.md)

本次兼容功能版本改善已有研究的接续：定位变化记录与相关正文，复用已保存材料，并减少自评完整输入在对话中的重复搬运。

- `research_save`／CLI `save` 和 `research_status`／CLI `status` 新增 `changes`：列出新增、更新、未变、删除或恢复的记录 ID，来源关联主张，以及最近登记稿件中的主张原文／来源链接位置。摘要覆盖最近一次成功保存记录的批次，用于缩小阅读范围，不自动判定结论失效。
- 保存来源 ID 时，比较本地证据文件与上次保存时的观察；首次观察明确标记。支持已有的锚点、Markdown 链接和行号定位，也保留 XML 等明确原件路径。工具不监控远端网页。
- 相同字节的文件不重复写入；稿件仍可按已有路径登记，未变记录无需重交。
- 本地自评可传 `include_assignment: false`，返回完整冻结输入的路径和哈希，避免在返回体中重复全文。默认全文返回、完整输入、版本绑定与时效检查均保持原有行为。

既有 CLI／MCP 调用、已保存任务、档位和评审／交付要求继续符合 [1.x 兼容性约定](../compatibility.zh-CN.md)，无需迁移任务。中英文说明、网站副本与自包含插件同步，插件仍提供八个 MCP 工具。

[真实长报告接续案例](../case-study/coding-benchmark-update/status-save-2026-10-15/README.zh-CN.md)保留完整稿件、来源核对、记录复用与实际 CLI 观察。[Astra 干净上下文复核](../case-study/coding-benchmark-update/status-save-2026-10-15/review/README.zh-CN.md)发现的两处路径兼容问题均已修复，最终针对性复验通过。实现经过 12 项记录回归、插件 MCP 检查及既有跨平台 CI。本次发版将已验证的兼容功能交给安装用户，不需要重跑完整模型评测，也不把个案结果解释为已测得的总体提效。

升级时替换完整安装包至 v1.2.0，任务数据保留在安装目录之外；若本地 MCP 服务正在运行，更新后重启即可。无需新增配置。
