# Research Toolkit v1.5.0

[English](v1.5.0.md) | [简体中文](v1.5.0.zh-CN.md)

2026-10-29 · [Implementation PR #122](https://github.com/rrrrrredy/research-toolkit/pull/122)

Modular research execution and collaboration: maintain methods by responsibility and select them by question; provide effective requirements and selected originals through shared work input; hand off analyses through existing save/resume capabilities; enforce review dependencies when review is invoked.

Existing tool names, calls, default stage guidance and legacy completion contracts remain. New inputs are optional: `guide/status.methods`, `status.work` and analysis `based_on`/`host_task`. See [usage and requests](../usage-modes.md#research-delegation-and-handoff).

No new scheduler or required review layer. The host handles agent startup, messaging, waiting and cancellation; the lead integrates actual analysis into the main report. Input-file changes are visible without automatically invalidating conclusions, and contribution completion does not complete the whole task.

[Raw validation records](../../evals/diagnostics/2026-10-29-research-path/README.md) preserve 12 CLI operations on one synthetic task, totaling 9.625 seconds of subprocess wall time, plus existing check results and intermediate failures. The prose, self-review and host reference were supplied by the driver. PR #122 passed Linux, Windows, Python 3.10 and packaged MCP checks. Host multi-agent collaboration has not been run; report quality, rework and user-time effects have not been measured. The elapsed time describes interface execution, not research speed.

Install the updated [plugin package](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.5.0/research-toolkit-plugin-v1.5.0.zip); [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.5.0/SHA256SUMS) accompanies it. Existing tasks need no migration. Skill-only users can update the Skill and references without creating tool-managed records.
