# Research Toolkit v1.4.8

[English](v1.4.8.md) | [简体中文](v1.4.8.zh-CN.md)

This patch distributes the writing guidance merged in [PR #108](https://github.com/rrrrrredy/research-toolkit/pull/108). The v1.4.7 plugin package does not contain this guidance or its worked example; upgrading makes both available in the research methods that agents read.

## Changes

- **Preserve key facts when shortening text.** Keep a fact's population, metric definition and relevant scope consistent across body text, tables, summaries and conclusions. A missing-record rate must not become a completeness rate, nor a sample proportion a proportion of all tasks. When a source's label can be misleading, use its full description.
- **Show the distinction with archived material.** The synthetic pilot source states that 62% of human edits lacked reason codes. The example contrasts the incorrect shortening, "reason-code completeness was 62%," with body and table wording that retains the missing-code meaning. The conclusion explains the records gap without deriving a share of all tasks requiring human edits or a workforce-replacement rate. These are wording alternatives, not a required report structure.
- **Synchronize the distributed methods.** English, Chinese and generated plugin copies include the same guidance. Original reports, sources and historical correction records remain unchanged. Public interfaces and saved-task formats are unchanged; no tools, required fields, checks or workflow steps are added.

## Verification and limits

PR #108's Framework checks and bilingual documentation workflow passed. Completed local verification covered the archived source and correction record, the example's meaning and links, English/Chinese consistency, plugin synchronization across 49 shared files, and `git diff --check`.

Release preparation reuses those results. Local release checks cover the changed version metadata and package generation; the existing repository CI checks the release commit. No research tasks or previously passed local checks for unchanged behavior are rerun. **Whether this guidance reduces metric misreading or improves research quality remains unverified.**
