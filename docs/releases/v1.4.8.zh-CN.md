# Research Toolkit v1.4.8

[English](v1.4.8.md) | [简体中文](v1.4.8.zh-CN.md)

本补丁分发已合并的 [PR #108](https://github.com/rrrrrredy/research-toolkit/pull/108) 写作指导。v1.4.7 插件安装包尚不包含这项说明及对照示例，升级后 Agent 读取研究方法时即可获得更新。

## 改动

- **简写时保留关键事实的含义。** 正文、表格、摘要和结论中的统计对象、指标定义及相关范围保持一致，不能把缺失率改成完整率，或把样本内比例变成全部任务的比例。来源栏目名容易误导时，依据完整说明转述。
- **用归档材料展示区别。** 合成试点来源写的是 62% 的人工修改缺少原因码。示例对比错误简写“原因码完整度为 62%”，以及正文、表格中保留缺失含义的写法；结论说明记录存在缺口，不据此推算人工修改占全部任务的比例或岗位替代率。这些是表述示范，不要求固定报告结构。
- **同步分发的方法。** 中英文及生成的插件副本包含相同指导。原报告、来源和历史修订记录保持不变。公开接口及已有任务格式不变，不新增工具、必填字段、检查或流程步骤。

## 验证与限制

PR #108 的 Framework checks 和双语文档工作流通过。已完成的本地验证包括归档来源与修订记录核对、示例含义及链接核对、中英文一致性、49 个共享文件的插件同步，以及 `git diff --check`。

发布准备复用上述结果。本地发布检查仅覆盖变化的版本元数据与安装包生成，由仓库现有 CI 检查发布提交。不重跑研究任务或针对未变行为已通过的本地检查。**这项指导能否减少此类指标误读、改善研究质量，仍未验证。**

## 升级

下载 [v1.4.8 插件 ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.8/research-toolkit-plugin-v1.4.8.zip) 和 [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.8/SHA256SUMS)，或将完整仓库更新到 `v1.4.8`。保留本地任务及有意修改的文件，替换插件安装包并在宿主中重新加载，无需迁移任务数据。
