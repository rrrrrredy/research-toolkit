# Research Toolkit v2.4.1

[English](v2.4.1.md) | [简体中文](v2.4.1.zh-CN.md)

This patch fixes Windows task saves and usage-event attribution. Existing task records, research interfaces and independent review responsibilities remain compatible.

- Engineering contract checks explicitly disable telemetry, including the packaged MCP child process. Their negative cases no longer enter ordinary usage as research failures.
- Ordinary and extended Windows paths identify the same task in usage events. No report text or local path is added to uploaded events.
- Task storage and locks reuse extended Windows paths so a valid draft remains writable when its historical backup and temporary filename exceed the ordinary path limit. A file-access failure preserves prior records and points to the affected file rather than asking the agent to change research fields.
- Three archived reports have separate editorial revisions: test-time compute, front warehouses and on-device models. Original reports, intermediate revisions and independent opinions remain available. Source checking also corrected the on-device report's statement about the ASR experiment's 328-second audio duration.

[Report revisions and independent records](../../evals/repairs/2026-11-10-report-expression/README.md). These report changes are not a new benchmark run or a measured Toolkit quality gain.

The Skill, CLI, MCP and plugin use the same implementation. Install the v2.4.1 package or update a repository installation to receive the fixes.
