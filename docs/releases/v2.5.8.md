# Research Toolkit v2.5.8

[English](v2.5.8.md) · [简体中文](v2.5.8.zh-CN.md)

This patch fixes the plugin's first-use instructions, evaluation completion, recovery after a host disconnects, and withdrawal of report-sharing permission.

- **Installation and first use.** The plugin entry now directs the agent to the repository's shared research instructions. Download the compact plugin ZIP or check out just the plugin directory at a pinned commit. The DeepSeek Harness, Hermes, and OpenClaw clone examples now enable Windows long-path support.
- **Evaluation and delivery.** In CLI or MCP, a valid assessment can finish with a verdict that the report needs revision. Delivering the report still requires independent acceptance. New review assignments share one saved copy of the input. Earlier inputs and receipts remain readable.
- **Resume after a disconnect.** Claude Code and OpenCode have up to 60 seconds to return a session ID. When the host exits or disconnects, Toolkit keeps completed work and any replies already received. Running the same request again reuses valid results and continues the remaining work.
- **Withdraw report sharing.** With explicit permission, Toolkit can send the full text of future final reports in the selected folder and its subfolders to the maintainer. An unanswered invitation grants no such permission. For example, withdrawing permission for a Client A folder cancels its reports still waiting to be sent. Client B can continue using the original permission. If an older report is waiting under the same parent folder's permission and cannot be traced to a subfolder, that upload is also canceled. Reports already sent can be deleted separately.
- **Disable usage recording.** With `RESEARCH_TOOLKIT_TELEMETRY=off`, delivery skips the local sharing queue setup.

## Verification

The packaged MCP passed checks for positive and negative evaluations, earlier inputs, and report delivery. Local simulated host processes covered startup timeout, exit, and continuation. An isolated receiver on the same machine exercised the notice, one-time sharing, and withdrawal. Repository checks passed on Windows and Linux, including with Python 3.10, the minimum supported version. The controlled comparison of research quality and cost is deferred. [Fix PR #154](https://github.com/rrrrrredy/research-toolkit/pull/154)

## Updating

Replace the complete plugin using `research-toolkit-plugin-v2.5.8.zip` from the Release. Use `SHA256SUMS` to verify the download before unpacking. Existing tasks can be resumed. [Installation guide](../installation-versioning.md#install-a-version-pinned-skill)
