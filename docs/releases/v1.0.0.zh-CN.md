# Research Toolkit v1.0.0

首个 1.x 版本为现有研究 Skill、Lite／Full 流程、七个 CLI／MCP 工具及打包插件确立明确的兼容性基线。运行行为与 v0.2.7 保持一致。

- 发布[英文](../compatibility.md)和[中文](../compatibility.zh-CN.md)兼容性约定，覆盖公开接口、已有任务、安装入口及 Python 3.10 支持。
- 明确补丁、次版本和主版本的适用变化，以及弃用接口支持和未来不兼容变更的迁移说明。
- 将约定随插件打包，在用户及贡献指南中提供入口，同步版本元数据和中英文发布文档。

将完整安装更新到 `v1.0.0` 标签；从 v0.2.7 升级无需迁移任务数据。已有任务保留已保存的档位／评审选择及带版本记录。历史评测和数据发布保留原来的版本号。本次执行已有离线发布检查和 CI，不新增模型评测或评审门槛。

参见[安装指南](../installation-versioning.zh-CN.md)和[更新记录](../../CHANGELOG.zh-CN.md)。
