# Research Toolkit v2.5.4

[English](v2.5.4.md) · [简体中文](v2.5.4.zh-CN.md)

This compatible patch fixes sharing consent, source replacement during research continuation, imported-check telemetry and configured acceptance readiness.

- Displaying a sharing invitation no longer overwrites an explicit choice. A child directory set to `ask` continues to block an ancestor report grant after the prompt has been shown. Re-requesting the invitation resets its display marker; explicit consent controls queueing. One-time sharing preserves `ask`, grants and refusals. Historical invitation markers remain readable.
- An explicit `work.source_ids` selection replaces that unit's old source selection. The original draft and provenance remain available, while retired source files recorded in the existing history are not bound as current evidence. Subsequent continuation restores the latest pending preparation. Sources required by selected claims, requirements and upstream work remain checked.
- Existing release-update checks disable usage collection in their setup and restore the calling environment afterward, including when loaded by unittest or an IDE.
- `check-reviewer` includes a separately configured final acceptance program in its existing executable checks. Independent roles and completion requirements are unchanged.
- The Chinese microdrama example's portfolio mean is corrected from 1,000,000 to 980,000 yuan, and creator contribution from −250,000 to −257,000 yuan. The corrected script calculates them from the stated inputs. A separate corrected report and the online page include this correction and the previously saved editorial changes. Original scripts, reports, results and acceptance records remain intact. [Correction and reproduction](../../evals/studies/2026-11-09-long-research/reports/microdrama_market_zh/analysis/2026-11-12-portfolio-correction/README.md).

Targeted verification used synthetic files, an isolated local database and disabled automatic upload. It exercised explicit child consent, source replacement and continuation in the same unit, retained snapshots, unresolved-source rejection, import-based execution of three existing checks, and missing/installed acceptance commands. The corrected arithmetic preserves the other 23 scenarios and seven CSV outputs. Research tasks and models were not rerun.

English/Chinese usage guidance and the plugin are synchronized. Install the complete v2.5.4 package to receive the runtime fixes. CLI/MCP names, saved tasks and the research completion contract remain compatible. The Release contains the plugin ZIP and `SHA256SUMS`.
