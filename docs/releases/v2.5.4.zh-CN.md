# Research Toolkit v2.5.4

[English](v2.5.4.md) · [简体中文](v2.5.4.zh-CN.md)

本次兼容性补丁修复分享授权、研究接续中的来源替换、导入运行检查时的使用采集，以及已配置验收程序的准备检查。

- 显示分享邀请不再覆盖用户明确选择。子目录设为 `ask` 后，提示过一次仍会阻止继承上层自动分享授权。重新请求邀请会重置提示记录，是否入队由明确授权决定。单次分享保留 `ask`、持续授权与拒绝选择，历史邀请标记仍可读取。
- 显式提供 `work.source_ids` 时，以本次选择替换该研究单元此前选定的来源。原稿与历史依据继续可查，已有历史记录中的退出来源原件不再绑定为当前证据。再次续接恢复最近一次准备结果；所选主张、要求及上游工作仍需使用的来源继续核对。
- 现有版本日志检查在初始化时关闭使用采集，结束后恢复调用环境，覆盖 unittest 与 IDE 导入运行方式。
- `check-reviewer` 将单独配置的最终验收程序纳入现有可执行文件检查。独立职责与完成要求不变。
- 中文微短剧案例的组合平均收入由100万元更正为98万元，片方期望贡献由−25万元更正为−25.7万元。更正脚本按给定参数计算；另存更正稿，在线正文同步这次算术更正及此前已保存的表达修订。原脚本、报告、结果和验收原件保留。[更正与复算记录](../../evals/studies/2026-11-09-long-research/reports/microdrama_market_zh/analysis/2026-11-12-portfolio-correction/README.md)。

针对性验证使用虚拟文件、隔离本地数据库并关闭自动上传，覆盖子目录明确授权、原研究单元更换来源及续接、旧稿快照保留、未解决来源的拒绝、三个现有检查的导入运行，以及缺失／已安装验收命令。更正计算的其他23组情景和七份CSV输出保持一致。没有重跑研究任务或调用模型。

中英文使用说明与插件同步。更新完整 v2.5.4 安装包即可取得运行时修复；CLI／MCP 名称、旧任务及研究完成契约保持兼容。Release 提供插件 ZIP 与 `SHA256SUMS`。
