# Research Toolkit v1.4.5

[English](v1.4.5.md) | [简体中文](v1.4.5.zh-CN.md)

This patch distributes [PR #101](https://github.com/rrrrrredy/research-toolkit/pull/101)'s method and instruction corrections to installed-plugin users. The v1.4.4 package still contains generic quotas and some outdated profile guidance. Update the package to receive these corrections; saved tasks need no migration.

## Changes

- **Finish the entry cleanup.** Current start examples omit profile selection. Usage guidance reflects the shared stage methods returned by `status` and `guide`; the failure-case form requests a legacy profile only when relevant to an older task. Historical protocols are identified as historical, with original reports and results preserved.
- **Let the task determine coverage and depth.** Remove generic limits such as detailing three to five objects, using at most two supporting lenses and preset section lengths. Retain comparison, mechanism explanation and counterevidence methods; select and develop them according to user requirements, the question and available evidence.
- **Keep records and revisions tied to the work.** Remove fixed fact-count bookkeeping and fixed search/revision round counts. Update related records together when useful, address actual unresolved questions and recheck affected content after corrections. Existing saved-task completion rules remain unchanged.
- **Cut redundancy while preserving meaning.** Add guidance and a bilingual before/after example in `writing-style`: retain the actors, actions, causal links and conditions readers need to understand the argument. Synchronize English, Chinese, web method text and the plugin without adding tools or checks.

## Verification and limits

PR #101's Framework checks and bilingual documentation workflow passed. Local verification covered affected Python compilation, five start-request JSON files, the issue-form YAML, generated site and bilingual Skill synchronization, local site links, and synchronization of 49 shared plugin files. Original research reports, runs and evaluation results remain unchanged.

Release preparation reuses those results and checks only the changed version metadata and generated package locally. Existing repository CI checks the release commit. No research task or model comparison is rerun.

**Research quality, comprehension efficiency and reduced rework remain unverified.** Corrected instructions and synchronized distribution do not establish those benefits.
