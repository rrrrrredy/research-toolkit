# Research Toolkit v0.2.3

Research Toolkit now offers a lighter first task and optional local workflow tools while keeping research methods usable through a repository link or files.

Changes since v0.1.3:

- Start small with Lite: clarify the brief, register sources and claims, draft by section, and finish a six-item checklist without reviewer setup.
- Choose self, external or independent review. New Full tasks without a configured backend use explicitly degraded self-review; declared independent requirements remain required.
- Use six shared CLI/MCP workflow tools through an optional plugin. Configure a supported CLI, compatible HTTP endpoint or trusted custom command for external review.
- Retain original review responses and failures, bind reviews to report/evidence versions, resume missing work and resolve mistaken findings with evidenced no-change decisions.
- Catch missing source readings, empty claims, changed requirements and stale delivery records before Full completion.
- Follow bilingual setup cards, a supplied Lite example and English/Chinese research cases; contribute a failure case without changing code.
- Follow copyable MCP configuration and a locally captured workflow example; use the recording guide to make a demo.
- Reproduce the existing calibration archive offline and prepare a seeded, blinded pairwise pilot. The new protocol includes no collected results.
- Keep package versions aligned from the root VERSION file, with checks for both changelogs and release notes.

This is a normal software release, not a research-quality certification. The public archive still contains only two development comparisons, run toolkit-first without blinded efficacy judging. Matching of model and brief is not fully established by the public records. General quality superiority remains unproven; historical samples, failures and frozen results are unchanged.

Install or update from this release's commit, install `requirements-mcp.txt` only when using MCP, and keep task data outside the installed package. See the [installation and update guide](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/installation-versioning.md).
