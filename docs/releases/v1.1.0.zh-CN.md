# Research Toolkit v1.1.0

本次次版本发布新增兼容的记录保存接口。Agent 通过 `research_save`／CLI `save` 提交来源、主张、要求和稿件，由执行工具写入、更新现有文件；用户作出研究决策，不维护 CSV／JSONL。

- 按 ID 合并局部更新，保留其他记录和额外字段，返回分配的 ID，定位格式错误。显式替换恢复后的集合时，自动保留原始字节备份。
- 保存稿件时自动创建父目录；也可直接登记已有稿件路径，不复制全文。首次完整稿观察保留时间与哈希。
- 通过 `research_status.activity` 汇总保存失败、实际评审尝试／重试、调用耗时及返回用量；复用评审不增加调用，作者上下文自评单独计数。未知作者用量保持未知，缓存输入不重复加总。
- 包含 v1.0.0 后的修复：插件写入边界与旧文件清理、引用导出提示、Windows CLI UTF-8、篇幅待核对提示、Lite 实际回复与当前完成状态检查，以及中英文入口同步。

既有 CLI／MCP 调用、任务格式、档位、评审要求和交付检查继续可用；插件现有八个 MCP 工具。无需迁移任务、不增加评测或评审门槛；只读检查仍只读。运行观察不认证研究质量，也不回填以前未观察到的时间。

发版依据是[1.x 约定](../compatibility.zh-CN.md)中的兼容性功能新增，不是模型评分上涨。针对性验证复用已有真实长任务及保留材料，实际走保存、更新和格式恢复，并运行现有跨平台检查；没有重新生成报告或重跑完整模型评测。见[验证说明](../record-save-validation.zh-CN.md)。

升级时替换完整安装包，任务数据仍放在安装目录外；中英文说明和打包运行核保持同步。
