# Research Toolkit v2.0.1

[English](v2.0.1.md) | [简体中文](v2.0.1.zh-CN.md)

发布日期：2026-10-30。

修复 v2.0.0 中研究交接、审阅输入与交付绑定的衔接问题。

- 补充审阅原件或原始回复变化后，关联研究单元不再沿用过期的就绪缓存，下游也不能据此标为完成。
- 同一次检查复用共同上游的完整检查结果，消除依赖分支上的重复读取；每次新调用仍重新校验原件、身份与结果。
- 独立审阅能够直接取得已有生产历史与保留稿件的导航；绑定实际稿件版本，不因新追加普通活动记录而自行失效。
- 全文审阅继续绑定当前要求的内容与范围。独立职责完成后，可以补记实际落实状态并交付；改变要求含义仍需处理受影响的审阅。
- 当前评测题目生成说明与现行独立职责一致，篇幅统计只用于题目明确提出的要求。中英文说明与插件安装包同步。

这次发布验证的是输入、依赖和完成行为，没有将这些修复表述为研究质量提升。保留的旧任务、原稿和审阅记录不改写。

受影响代码编译、已有记录的定向核对及插件构建已完成；公开 review 入口的保存状态回放返回与原记录完全一致，原有输入未改。Linux、最低 Python 版本和 Windows CI 通过；Windows CI 完成了本机权限曾阻止的符号链接与目录联接检查。原始失败和恢复记录保留，没有重复运行研究任务。

这是 v2.0.0 完成契约的修复，公开接口与旧材料读取方式不变，采用补丁版本。
