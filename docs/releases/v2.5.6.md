# Research Toolkit v2.5.6

[English](v2.5.6.md) · [简体中文](v2.5.6.zh-CN.md)

This release completes removal of the retired research-mode entry from the shared runtime and distributed plugin. New and continued research use the existing independent review, audit and acceptance path.

- Remove the hidden CLI `--profile` option, the `profile` input to start/guide in CLI JSON and MCP, and mode fields in new task records and responses. Old arguments now fail explicitly before task creation instead of being silently mapped to the shared workflow.
- Remove the checklist-only completion implementation, review-skipping branch, `profile_policy.py`, and the obsolete `checklist` input to finish. Original saved author-check files remain records, not a way to complete current work.
- Remove retired teaching inputs, method files and quickstart redirects. Disable the old single-response evaluation executor's prepare/run entry; retain only the helpers used to read and verify archived evidence. Original study files and historical results are unchanged.
- Keep MCP arguments aligned with the published tool signatures. Unknown fields are rejected instead of discarded by the SDK. Synchronize English/Chinese usage guidance and plugin files.

## Updating

Replace the complete plugin or Skill directory, including references and scripts. Cached private skills must be replaced too. Remove `--profile` or JSON/MCP `profile` from start/guide calls, and remove the old `checklist` argument from finish. These retired calls intentionally stop working in this patch. The normal shared entry, saved sources, requirements, manuscripts and independent responsibilities continue unchanged. Do not delete task data or rerun completed research to update the installation.

## Verification

Reused the completed local verification: affected Python compilation and 44 existing repository check commands covering CLI/MCP, saving, continuity, review/delivery, installation, plugin synchronization, historical evidence and the static site. Three checks depended on removed mode inputs or old exception behavior; after updating those existing controls, only the failed cases were rerun. No new unit-test suite, research rerun or model comparison was added.

The packaged MCP scenario rejected old mode arguments without creating a task, then completed the normal independent review/audit/acceptance path. A read-only check of the already-delivered organization-change task passed with 10/10 independent responsibilities and all 608 task files unchanged. This confirms the checked interface and record behavior; no research-quality gain is claimed.

The Release provides the complete plugin ZIP and `SHA256SUMS`.
