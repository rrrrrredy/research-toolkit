# Research Toolkit v1.4.14

[English](v1.4.14.md) | [简体中文](v1.4.14.zh-CN.md)

本补丁集中调整现有研究方法与用户引导，并将更新分发给已安装 Skill／插件的用户。公开功能、接口、记录格式和完成契约没有变化；按[版本约定](https://github.com/rrrrrredy/research-toolkit/blob/v1.4.14/docs/compatibility.zh-CN.md)，采用补丁版本 **1.4.14**。

## 改动

- **分析方法：** 具体说明怎样选择有意义的比较、用材料区分可能原因、综合多来源和解释选择理由。领域视角与已有 SaaS 示例保留，相关做法按问题选用。
- **整篇组稿：** 说明章节怎样承接、公司覆盖怎样与跨对象分析配合、综合结论怎样推进回答。复用八家公司管线研究的原稿、修订稿及审阅记录，提供明确标注的教学衔接；原报告、来源和历史评测不变。
- **执行方式：** 将每阶段重复规划、起草、评审的统一要求改为围绕未解决问题组织阅读、分析和写作。既有自检、约定评审和工具管理任务的契约保留。
- **用户引导：** README 与快速开始让用户表达问题、用途、材料和约束，删去请求中重复的内部执行指令。意图理解由宿主 Agent 按 Skill 完成；CLI／MCP 保存整理后的要求并提示缺项，字段齐全不等于理解正确。
- **同步：** 中英文、Skill 入口、插件副本与网站方法页同步；不新增工具、字段、调用步骤或独立意图识别模块。

## 验证与效果范围

已完成中英文 Skill／网页同步、49 个插件共享文件一致性、静态网站构建、28 个页面与 663 个本地目标的现有检查、Skill 格式检查，以及 38 处改动 Markdown 链接和锚点核对。差异检查发现的末尾空行已修正，仅重新核对受影响的插件副本与差异。

示范与已有归档内容核对，未重跑研究、增加模型对照或新增测试案例。本次交付确认方法内容与使用说明得到调整，**尚未测量研究质量、意图理解准确性、返工或用户耗时的改善**。发布准备复用已有结果，仅新增版本元数据与安装包核对，并采用现有 CI。
