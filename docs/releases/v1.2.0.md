# Research Toolkit v1.2.0

[English](v1.2.0.md) · [简体中文](v1.2.0.zh-CN.md)

This compatible feature release makes existing research easier to continue: identify changed records and related prose, reuse saved material, and avoid transporting complete self-review inputs through the conversation again.

- `research_save` / CLI `save` and `research_status` / CLI `status` now return `changes`: added, updated, unchanged, removed or recovered record IDs, source-linked claims, and literal claim/source-link locations in the latest registered draft. The view covers the latest successful record-save batch; it guides reading rather than deciding which conclusions are invalid.
- Saving a source ID compares its local evidence files with the previous save observation. First observations are explicit. Existing reading locators with anchors, Markdown links and line numbers work, and explicit original-file paths such as XML remain supported. Remote pages are not monitored.
- Byte-identical files are not rewritten. Drafts can still be registered by path; unchanged records need not be resubmitted.
- Local self-review callers can set `include_assignment: false` to receive the complete frozen assignment's path and hash instead of repeating its text in the response. The default inline response, complete inputs, version binding and freshness checks remain unchanged.

Existing CLI/MCP calls, saved tasks, profile choices and review/delivery requirements remain compatible under the [1.x policy](../compatibility.md). No task migration is needed. English/Chinese instructions, website copies and the self-contained plugin are synchronized; the plugin still exposes eight MCP tools.

The [real long-report continuation](../case-study/coding-benchmark-update/status-save-2026-10-15/README.md) preserves complete drafts, source checks, record reuse and actual CLI observations. [Fresh-context Astra review](../case-study/coding-benchmark-update/status-save-2026-10-15/review/README.md) found two path-compatibility issues; both were repaired and the final targeted recheck passed. Twelve record regressions, packaged MCP checks and the existing cross-platform CI cover the implementation. This release packages those verified compatible features; it does not require rerunning the full model evaluation or claim a measured overall productivity gain.

Update the complete installation to v1.2.0, retain task data outside the installation directory, and restart the local MCP server if it is running. No new configuration is required.
