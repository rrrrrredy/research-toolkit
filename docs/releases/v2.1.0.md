# Research Toolkit v2.1.0

[English](v2.1.0.md) | [简体中文](v2.1.0.zh-CN.md)

Release date: 2026-11-02.

Research preparation and independent assignments now provide a readable entry to their complete input. Previously, expanding large JSON inputs could truncate the visible output, requiring the worker to recover individual fields and originals manually.

- `status(work=...)` returns `reading_ref` alongside the existing `work_context`. Pending native-agent content review, audit and final acceptance return the same kind of entry alongside the frozen `assignment_ref`.
- Markdown navigation follows the existing fields. Long strings open as complete UTF-8 text, without JSON string escaping; structured records retain fields, order, empty values, booleans and numbers. Original paths, hashes and version references remain available.
- Identical content shares files under `logs/reading/`; changed content gets a separate view. These derived files do not change input hashes, assignment versions or completion conditions. Ordinary status without `work` does not generate them.
- English, Chinese and plugin content are synchronized. There are no new tools, required arguments or calls. Existing interfaces, saved tasks and independent responsibilities remain compatible. This compatible added capability uses a minor version.

Four retained inputs from one completed research task—production, content review, audit and acceptance—were rendered separately. Complete long text matched the saved input byte for byte, and original records remained unchanged. The new entry points are navigation, not summaries of the material. No research or model run was repeated.

Affected compilation, plugin/document synchronization, the existing workflow and continuity checks, and the packaged MCP end-to-end control passed. The plugin-build check passed its runnable controls; seven file-symlink controls were skipped locally because Windows lacked the required privilege. The Linux CI runs the existing controls. The MCP scenario uses synthetic workers to verify interface behavior, not research quality. Original observations and execution records remain separate from the release package.

The exercised result is a usable reading path to preserved full input. Whether agent tools use it to reduce omissions or rework, or improve final reports, has not been measured.
