# Research Toolkit v1.3.3

[English](v1.3.3.md) | [简体中文](v1.3.3.zh-CN.md)

This patch delivers the repeated-paragraph advisory from [PR #85](https://github.com/rrrrrredy/research-toolkit/pull/85) and the Lite analysis guidance from [PR #86](https://github.com/rrrrrredy/research-toolkit/pull/86). Both are merged, but neither is in the v1.3.2 installation package. The update preserves the existing nine tools, required fields, calls and saved tasks.

## Installed changes

- **Locate exact repeated paragraphs.** `check-draft` adds the original text, section headings and all inclusive line ranges to existing `warnings` when an ordinary prose paragraph of at least 24 non-whitespace characters appears identically at least twice. It reuses existing repetition grouping and paragraph location logic. Headings, code, tables, lists and block quotes are excluded. Warnings do not change `ok` or delivery eligibility and do not edit the report.
- **Choose analysis methods for the question.** Lite's `analyze` guidance explains when to compare objects, explain development or differences, and weigh choices. It reuses existing methods, consolidates evidence reminders and includes a short example from archived synthetic SaaS sources S2/S4. Methods are optional and do not impose report sections. English, Chinese and packaged guidance are synchronized.

## Evidence and validation

The archived four defective originals triggered repeated-paragraph warnings; their four separate repaired reports did not. Existing checks covered original text, headings and line ranges, multiline matching, excluded blocks and unchanged delivery behavior. The Lite example was checked against S2/S4, and its bilingual stage returns, links and plugin copies were checked. Both implementation PRs passed CI.

**Reduced false self-check passes and improved research quality remain unverified.** The separately archived [public-library comparison](https://github.com/rrrrrredy/research-toolkit/blob/v1.3.3/evals/studies/2026-10-19-library-self-check/README.md) found no false passes in either v1.3.1 or v1.3.2 and no incremental v1.3.2 benefit in that case; it did not test this patch. Original records and conclusions remain unchanged.

Release preparation reuses those completed results and checks the changed version metadata and plugin package through the existing release process and CI. It adds no model runs or tests and does not manually rerun passed implementation checks.
