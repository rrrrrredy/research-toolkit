# Research Toolkit v3.1.2

[English](v3.1.2.md) · [简体中文](v3.1.2.zh-CN.md)

- 普通 `status` 可以直接查看只读归档，无需创建锁文件。多人能同时查询同一任务。查询期间若遇写入，工具会报告冲突。
- 声明为 `gb2312` 的网页可能含有「镕」等 GBK 扩展字。现在可以提取这些网页，并记录原始编码声明与实际解码器。声明未知或原解码器无法读取字节时，提取器会尝试严格 UTF-8。
- 草稿检查能标出嵌套 Markdown 列表中私有聊天引用的原始行号，也能识别缩进或围栏中的代码示例。
- 版本日志比对会略过页面级导航和页脚。版本文章或章节内部的页脚若有改动，差异仍会显示。
- MCP 与 CLI 共用任务锁。Codex 适配器在进程清理失败时也会关闭日志，收到格式有误的回合完成事件时会报告原因。
- 可选的使用记录钩子在找不到插件目录时会安静退出，OpenCode 可通过所在平台的命令名找到 Python。使用记录按宿主区分子会话，分享检查能识别 Markdown 报告中明确标注的字段要求和工作目录。

### 升级插件

请在 Agent 工具使用的 Python 环境中安装包内的 `requirements-mcp.txt`。先前只装了基础 MCP SDK 的环境也需要执行这一步。插件通过该环境的 `mcp run` 启动，宿主的 PATH 需要能找到 `mcp`。SDK 版本仍固定为 2.2.0。已在客户端指定 Python 绝对路径的用户可以继续直接运行 `scripts/research_mcp.py`。[MCP 安装说明](../usage-modes.zh-CN.md)

发布页提供插件包 `research-toolkit-plugin-v3.1.2.zip` 和校验文件 `SHA256SUMS`。[快速安装](https://rrrrrredy.github.io/research-toolkit/quickstart.zh-CN.html)
