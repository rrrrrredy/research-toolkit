# Research Toolkit v2.5.0

[English](v2.5.0.md) · [简体中文](v2.5.0.zh-CN.md)

这是一个保持兼容的新功能版本：完整交付后提供明确的报告分享选择，并扩展现有 Agent 执行适配器的研究能力。

## 交付后的分享

项目首次完整交付后，Agent 在当前对话的报告链接后显示邀请，列明所选文件、维护者的私密仓库 `rrrrrredy/research-toolkit-usage`、用途和项目目录。用户可选择仅分享这次报告、允许该项目后续分享最终报告，或不分享并不再提示。未回复不将内容加入上传队列。聊天和原始材料另列文件、另行确认，报告授权不包含这些内容。

工具管理任务仅在 `completed=true` 后通过 `finish.content_sharing` 返回邀请。纯 Skill 使用同一套分享说明，有命令能力时调用 `share-offer`。拒绝会被记住，撤回会清除该项目尚未上传的内容；未改变的报告不重复入队，原有关闭设置继续生效。Windows 普通路径与长路径现在使用同一项目授权。复用现有队列、接收端、UTF-8 文件限制和基础事件设置。

## 使用已有 Agent 工具开展研究

执行适配器使用 Claude Code、OpenCode 或 Codex 已配置的工具与权限，获取来源、运行计算、保存研究文件。每次执行有独立目录，保留此前成果。通过 `records.json` 中已有的保存字段，将新来源、主张与完整正文一起回存，并把原件、提取文本、脚本和结果关联到下游实际使用的研究输入。

复用现有记录校验拒绝冲突写入；未完成的贡献和被拒收的保存保留原回复，供原执行者纠正。输入变化后可接续同一研究者，独立审阅者可在自己的目录中复算。适配器不添加跳过权限的参数，不改变账号或模型配置。研究入口、旧任务兼容以及必需的独立审阅、审计与验收保持不变。

## 验证与分发

保留的检查覆盖代码编译、工作流、保存与续接、交付与审阅契约、MCP、中英文页面和插件同步。本地分享场景覆盖确认、拒绝、未回复、项目授权、去重、撤回和关闭，并保留 Windows 路径问题的修复前后结果。一次原生 Codex 执行实际获取官方材料、运行计算、接续变化后的输入，并向统稿者交接完整产物；报告完成现有独立职责及 `finish`。原始失败和修正留在开发记录中。本轮没有另行启动 Claude Code、OpenCode 的模型运行。这些观察对应执行与分享行为，不是研究质量对照。

请将完整安装副本更新到 v2.5.0。Release 提供同步后的插件 ZIP 和 `SHA256SUMS`；Skill、CLI、MCP 文件也包含在该标签的仓库及源码压缩包中。已下载的旧包不会自行更新，无需重新部署接收端或迁移任务数据。开发者个人停止前检查及本地研究记录不随安装包分发。
