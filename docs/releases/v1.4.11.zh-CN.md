# Research Toolkit v1.4.11

[English](v1.4.11.md) | [简体中文](v1.4.11.zh-CN.md)

本补丁分发已合并的 [PR #114](https://github.com/rrrrrredy/research-toolkit/pull/114)。v1.4.10 安装包在反证来源编号仅出现在 `counter_evidence`、调用者没有另外传入对应文件时，可能遗漏其原文；更新安装包后，已安装用户才能获得修复。依据[版本约定](https://github.com/rrrrrredy/research-toolkit/blob/main/docs/compatibility.zh-CN.md)，这是兼容的问题修复，因此递增为 **1.4.11**，不升至 1.5.0。无需迁移任务数据。

## 改动

- 将明确引用的反证来源纳入现有评审输入与版本绑定，复用本地原文读取、去重和修订处理。
- `counter_evidence` 继续支持自由文本；仅识别以空白、分号、逗号或 `|` 分隔且与已登记编号完全匹配的来源，不从文字含义推断引用。原有本地证据要求继续适用。
- 同步中英文及插件，不新增字段、调用或评审步骤。保留原报告、请求、返回与历史输入；来源变化后沿用已有的显式修订方式，不静默复用旧输入。

## 已观察结果与验证

构造案例的修复前输入包含 `offer.md`，但遗漏反证来源 `schedule.md`；修复后两份原文均进入输入，反证正文逐字一致，输入版本随之改变。原冻结输入和报告保持不变，模型调用为零。

针对性的“保存 → 评审输入 → 来源修改后修订”检查修复前失败、修复后通过；六项相关既有检查、受影响 Python 编译、插件同步及双语文档检查均通过。PR #114 的 Linux、最低 Python 版本、Windows 和静态网站 CI 已通过。首次本地临时目录权限及长路径失败记录仍保留；调整环境后仅恢复此前失败的检查。

发布准备复用这些结果，只核对变更的版本元数据和新安装包，由现有 CI 检查发布提交。不重跑研究任务或已通过的本地行为检查。**已观察到的是材料传递和版本绑定得到修复；研究质量提升、报告错误减少、返工和耗时降低仍未验证。**
