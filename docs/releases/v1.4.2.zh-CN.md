# Research Toolkit v1.4.2

[English](v1.4.2.md) | [简体中文](v1.4.2.zh-CN.md)

本补丁将 [PR #94](https://github.com/rrrrrredy/research-toolkit/pull/94) 的保存参数说明和 collect 指导分发给插件安装用户；v1.4.1 ZIP 不包含这些补充。公开接口、可执行逻辑、校验规则和已保存任务格式保持不变。

## 改动

- **在调用入口说明必读要求。** `research_save`、CLI 保存说明和 collect 指导区分来源的 `read_scope` 与要求的 `reading_requirement`。仍需履行的必读要求使用 `full_text` 或 `relevant_sections`，配合非空、无重复的 `required_source_ids` 列表。字段配合按与已保存行合并后的结果判断；局部更新可省略未变字段，没有必读要求的行无需填写这两个字段。
- **分开文件路径和阅读说明。** 本地 `read_evidence` 推荐填写任务内现有非空文件的相对路径，页码、章节和说明放入已有 `locator`。已支持的网址、页码和本地引用形式继续有效；可选 `evidence_path` 不能修复无效的 `read_evidence`。`locator` 没有变成必填项。
- **同步分发内容。** 中英文保存示例、Lite collect 与 Full 指导、插件副本保持一致。不新增字段、调用、流程步骤或交付门槛，现有任务无需迁移。

## 验证与限制

已归档的 Codex 请求记录了这次说明针对的两类错误：R3 使用 `read_scope`，漏填 `reading_requirement`；六条来源将阅读说明拼在文件路径后。保存的修正请求补入 `reading_requirement: relevant_sections`，保留来源 ID，随后将纯路径与 `locator` 分开；两次修正后的保存均返回成功。原始记录保持不变，本次只阅读对照，没有重放请求。

PR #94 已通过 Framework checks 和中英文文档检查。实现阶段已完成编译、排除说明字符串后可执行 AST 不变、中英文示例、collect 返回及插件一致性核对。发布准备沿用这些结果，本地只校验变化的版本元数据与生成包，发布提交由仓库现有 CI 执行检查。不重跑研究任务、模型评测或已通过的本地实现检查。

**减少返工的收益仍未验证。** 已保存的修正记录体现的是已有接口的纠错能力，不是新说明已经产生收益。此前 v1.4.1 的 Skill 专用校验仍因缺少 PyYAML 未完成；本次不修改 Skill 入口，也不重跑该校验。其状态和补齐方式保留在 [v1.4.1 发布说明](v1.4.1.zh-CN.md)中。
