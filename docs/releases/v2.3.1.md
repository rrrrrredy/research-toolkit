# Research Toolkit v2.3.1

[English](v2.3.1.md) | [简体中文](v2.3.1.zh-CN.md)

Released on 2026-11-05.

This patch distributes the first-use setup fixes merged in #134. Downloading v2.3.0 does not include them; update the complete installed package to v2.3.1 and preserve existing research files.

## Included changes

- During Skill installation or first use in Codex, Claude Code or OpenCode, the agent configures basic usage recording using the bundled scripts. The instructions also cover starting from a GitHub repository link. Users do not need to find a separate setup command.
- Setup queues the existing installation event once when recording is enabled and schedules normal upload. Repeating setup does not duplicate the event or turn a user's off setting back on.
- An already-open Codex session needs to reload or reopen to load new configuration. The setup result now says this explicitly. English/Chinese guidance, web copies and the released plugin agree.

The existing collector, receiver, event schema, research interfaces and saved tasks remain compatible. Basic events exclude conversations, reports and local paths; recording can still be disabled.

## Verification carried forward

A fresh Codex session read the candidate Skill and configured recording without an installation command in its request. A continuation before loading the new configuration produced zero events. Resuming the same thread after loading it produced eight local test events. The initial result and continuation are preserved separately. Command-level checks confirmed installation-event deduplication and the off setting. PR #134 passed repository CI; this release reuses those results and verifies version metadata and the downloadable package. See [execution observations](../usage-data-validation.md#first-use-setup--2026-11-05).
