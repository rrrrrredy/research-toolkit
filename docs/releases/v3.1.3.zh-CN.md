# Research Toolkit v3.1.3

[English](v3.1.3.md) · [简体中文](v3.1.3.zh-CN.md)

- Markdown 报告可以用行内代码标注字段要求或工作目录。分享检查会匹配成对的反引号以及对应的中英文括号。缺少文档语境的口令赋值仍会阻止分享。
- 两份 Codex 清单都加载带 Windows 原生命令的 hooks 配置。Claude 默认读取的文件只含共用命令字段。包内 hooks 沿用现有的记录开关。
- 版本日志支持日期和版本同处一行，包括 Keep a Changelog 标题，也支持已有的两行格式。工具按日期和版本对比新增或修订内容，每条记录都须有正文。
- 离线评测按实际引用的网址计数，并标出报告中私有聊天引用的行号。
