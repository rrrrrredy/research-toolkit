# Research Toolkit v1.3.2

[English](v1.3.2.md) | [简体中文](v1.3.2.zh-CN.md)

本补丁分发 [PR #81](https://github.com/rrrrrredy/research-toolkit/pull/81) 的 Lite 自检提示修正，以及 [PR #82](https://github.com/rrrrrredy/research-toolkit/pull/82) 已合并的入口说明修正。v1.3.1 插件仍包含旧提示，已安装用户需要更新安装包才能获得修正。不增加工具、必填字段、调用步骤或任务迁移。

## 安装包改动

- 面向读者编辑的自检项要求通读当前完整报告，处理重复、离题段落，并指出实际发现或修正及具体正文／来源位置。
- 清单报错不再直接要求填写 `passed=true`，而是要求完成核对并解决正文问题。未检查或未解决时保持 false，不能只改通过标志。
- 中英文 Skill 入口、Lite 指南与生成的插件统一要求填写实际检查结果，入口不再要求逐项提交通过。现有六项清单与校验条件不变。
- 中英文工具说明与实际注册的九个 MCP 工具保持一致。相对 v1.3.1 数量不变；更正期间引入的八工具表述不代表新增功能。

## 报告更正与证据边界

仓库另存预测性维护订阅、引导基金返投与退出、Scope-3 RFQ 和信贷备忘录 LLM 四篇修订稿。[变化说明](https://github.com/rrrrrredy/research-toolkit/blob/v1.3.2/evals/repairs/2026-10-19-reader-edit/README.zh-CN.md)更正了原稿的质量达标表述，并列出逐篇修改。原稿、原自检、来源包、批次汇总及历史结果完整保留。稿件修订不增加评测运行次数，不算 Toolkit 核心能力升级；研究归档不加入插件安装包。

**自检提示能否减少错误自报通过，效果仍未验证。** 本补丁没有自动判断语义正确性的能力，修订稿也不能证明 Toolkit 研究质量或效率已普遍改善。

## 验证

PR #81 的 Linux、Windows、最低 Python 版本和静态网站 CI 已通过；编译、插件／网站一致性、原始归档完整性和本地链接检查也已完成。本次发布沿用这些结果，只核对变更后的版本元数据和生成安装包，并遵循仓库已有 CI；不增加模型运行或运行时测试，不手动重跑已完成的实现检查。

## 升级

下载 [v1.3.2 插件 ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.3.2/research-toolkit-plugin-v1.3.2.zip) 和 [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.3.2/SHA256SUMS)，或将完整仓库更新到 `v1.3.2`。按宿主已有方式安装完整插件，保留本地任务和有意修改的文件，再重新加载方法并重启本地 MCP 服务。仍需 Python 3.10+ 和现有 MCP 依赖。
