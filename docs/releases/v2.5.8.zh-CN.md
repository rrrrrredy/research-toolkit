# Research Toolkit v2.5.8

[English](v2.5.8.md) · [简体中文](v2.5.8.zh-CN.md)

本补丁修复插件首次使用指引、评测结项、宿主断线后的接续和报告分享撤回。

- **安装与首次使用。** 插件入口直接使用仓库的研究说明，去掉了旧的作者自评指引。可下载较小的插件 ZIP，或按提交号只取插件目录。补齐了 DeepSeek Harness、Hermes 和 OpenClaw 安装命令中的 Windows 长路径选项。
- **评测与交付。** 使用 CLI 或 MCP 评测报告时，评审确认报告需要修订，也可以结束这次评测并保留结果。交付报告仍须通过独立验收。新审阅任务共用一份记录下来的输入，旧输入和回执仍可读取。
- **断线后接着做。** Claude Code 和 OpenCode 最多等待 60 秒取得会话 ID。宿主退出或断线后，Toolkit 保留已完成的成果和已经收到的回复。再次运行同一请求时，复用有效成果并继续剩余工作。
- **撤回报告分享。** 使用者明确同意后，Toolkit 才能把指定目录及其子目录里以后完成的报告正文发给维护者。没回复邀请，就不会因此发送正文。比如，撤回“客户 A”目录的授权后，已排队但还没发出去的客户 A 报告会取消发送，客户 B 仍可沿用原授权。当初按同一上级目录授权排队的报告里，若有旧记录分不清属于 A 还是 B，也会取消这次发送。已经发出的报告需要另行删除。
- **关闭使用记录。** 设置 `RESEARCH_TOOLKIT_TELEMETRY=off` 后，交付时不会为了检查分享而新建本地队列。

## 验证

通过打包后的 MCP 验证了正负评测结果、旧输入读取和报告交付。用本地模拟进程验证了宿主启动超时、退出和接续。用同一台电脑上的模拟接收端走完了首次提示、单次分享和撤回流程。Windows、Linux 和最低支持版本 Python 3.10 的仓库检查通过。研究质量和成本对照留待后续。[修复 PR #154](https://github.com/rrrrrredy/research-toolkit/pull/154)
