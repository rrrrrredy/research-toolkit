# Research Toolkit v2.0.0

[English](v2.0.0.md) | [简体中文](v2.0.0.zh-CN.md)

发布日期：2026-10-30。

本版在现有 Skill、CLI 和 MCP 入口中接通实质研究协作、渐进成稿与独立交付。宿主运行 Agent，Toolkit 提供有效要求、原始材料、依赖成果和绑定版本的工作输入。

- 默认使用宿主原生子 Agent，无需另配 API。新工作不能通过作者自评完成交付；七个分离的内容视角、适用领域专审、独立审计和单独最终验收保留真实宿主身份与原始回复。
- 现有 work/save 接口承载研究单元、实际依赖、完整分析及简短交接。已满足的要求继续有效；具体记录变化影响真实下游，无关台账新增不让所有支线过期。主稿由明确的写入者维护，通过交接转移责任。
- 重要上游成果经独立核查后，下游才能登记完成。审计全核关键要求及判断，从完整报告自行选择已通过内容，并按发现的原因扩查；取消固定首尾／哈希段落抽样。
- 局部要求明确归属后仅绑定相关单元，全部有效要求仍可回读。修订审阅带回同视角的前次原始意见、冻结输入和变化定位。单元审计按具体争议启用，不让每个单元固定增加审计或验收；新单元也不再默认添加未指定的领域专审。主稿须登记真实宿主写入者才能进入独立审阅。
- 方法原件分别维护职责，阶段指导和宿主入口指向对应方法，中英文与插件采用同一契约。取消默认研究运行时限和耗时／token 汇总，保留事件时间、故障恢复、用户取消和历史原件。

升级主版本是因为完成语义改变：旧参数和保存材料仍可读取，历史回执不改写；继续研究须完成当前独立职责。语言兼容、来源／反证传递和文件保护等已有有效修复保留。

本地已完成受影响代码编译和本机可执行的既有强制检查；打包 MCP 的合成角色控制通过。固定实现后，RSI 真实任务完成了原生研究交接、分阶段统稿、七项独立内容审阅、领域专审、独立审计、最终验收与正式交付。首轮四项必要发现经局部修订后由独立审计确认解决，原稿、首轮负面意见和修订记录保留。

Linux、Python 3.10 和 Windows CI 已通过；Windows CI 也实际执行了本地受权限限制的符号链接检查。收尾修正使用已保存记录进行定向核对，没有重跑 RSI 研究。该次研究未实际经历主稿写入者跨 Agent 转移或宿主上下文压缩后的恢复。一次本地检查的首次完整控制台输出因重试日志命名错误被覆盖，原退出码、失败说明与后续定向核对结果保留。上述结果支持已执行的接口与协作行为，没有进行整体研究质量、用户精力或速度的版本效果对照。
