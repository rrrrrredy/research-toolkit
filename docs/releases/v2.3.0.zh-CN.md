# Research Toolkit v2.3.0

[English](v2.3.0.md) | [简体中文](v2.3.0.zh-CN.md)

发布日期：2026-11-04。

本版增加统一使用轨迹采集，并分发通用 Agent 执行接口。已有研究任务、CLI／MCP 调用和独立审阅要求保持兼容；新增能力采用次版本升级。

## 使用采集与私密查看

- CLI 和 MCP 通过同一实现记录白名单操作信息：入口、版本、可识别的安装渠道、调用顺序、结果、耗时及任务／会话关系。上传通过本地队列在后台进行。
- 基础采集默认开启，首次使用时提示；不包含提示词、对话、研究标题、报告、URL、本地路径和密钥。用户可以关闭采集，并删除本安装已上传的数据。
- 插件 hooks 和一次性安装的 Skill 观察器接入 Codex、Claude Code、OpenCode 原生宿主事件。纯粘贴说明没有可执行观察器；历史版本不会追溯上传。
- 研究内容通过明确授权的单次命令分享，范围由所选任务文件决定。开发者在私密 GitHub 报告中分别查看汇总、逐任务／会话顺序和可下载的记录。
- 接收服务使用 Cloudflare Workers 和 D1，采集凭据与管理读取凭据分开。具体用法见[使用数据说明](../usage-data.zh-CN.md)。

## 通用 Agent 执行

- 执行适配器通过统一会话接口选择宿主驱动。Codex 与 Claude Code、OpenCode CLI 驱动并列；共享执行层不再直接创建 Codex 会话，也不再缺省兜底到 Codex。
- 输入更新在支持追加消息的宿主中直接送达，其他宿主在当前调用结束后续接原会话；原始结果继续绑定实际送达的输入版本。
- 现有宿主配置和明确格式的旧评审配置继续可用，中英文方法、接入说明及插件保持同步。

## 实际运行记录

保留的本地场景通过真实 CLI、打包 MCP 与 Worker／D1，覆盖失败调用、重传、字段限制、分享、关闭和删除。Codex 与 OpenCode 原生运行记录了子 Agent 关系和任务接续；构造 hook 输入核对了事件标识及打包后的 Windows 启动命令。各条记录对应的路径、方法和结果见[实现观察](../usage-data-validation.md)。

线上接收服务收到打包 CLI 两次调用产生的五条测试事件和一个两文件分享包；私密 GitHub 工作流生成了使用顺序和下载附件。删除后事件和文件归零，下一次报告清除了旧报告副本。这次线上传输核对在 GitHub 的 Ubuntu runner 执行。
