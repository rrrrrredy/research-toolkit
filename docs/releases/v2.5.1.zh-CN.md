# Research Toolkit v2.5.1

[English](v2.5.1.md) · [简体中文](v2.5.1.zh-CN.md)

这是一个兼容补丁，修复 v2.5.0 引入的两处报告分享行为。

- 单次分享补充材料时，保留已有的项目报告授权或拒绝选择。此前 `once` 会覆盖 `reports`，导致下一篇最终报告没有按用户的持续授权进入队列。
- 正常交付、`share-offer` 和 `share` 共用最近的已保存分享范围。给 `project/` 授权后，`project/tasks/alpha/`、`project/tasks/beta/` 等任务可以直接沿用，不必重复传入 `--project-root`。更具体范围内已保存的拒绝或重新提示选择优先；没有已保存范围时，仍默认使用任务父目录。

修复复用现有设置、路径规范化、内容队列和上传服务，没有增加授权台账、上传服务或研究步骤。中英文使用说明及插件同步更新。

离线验证保留了修复前的失败记录，使用虚拟文件和隔离数据库核对 CLI 与正常交付路径。单次分享后持续授权保留，多层目录中的下一篇报告正确入队；拒绝、重新提示、撤回、去重及无关项目排除符合预期。验证时关闭自动上传，没有向生产接收端发送报告、聊天或原始材料；没有重跑已有研究任务。

请将完整安装副本更新到 v2.5.1。如果 v2.5.0 已经将持续授权覆盖为 `once`，需要明确重新授权持续分享报告；现存设置无法还原被覆盖的选择。已有任务数据、独立审阅职责和研究完成行为不变。Release 提供插件 ZIP 和 `SHA256SUMS`。
