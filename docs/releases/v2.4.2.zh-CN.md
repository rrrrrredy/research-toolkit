# Research Toolkit v2.4.2

[English](v2.4.2.md) | [简体中文](v2.4.2.zh-CN.md)

本补丁修复自动上传遗漏最后一批使用事件的问题。原实现收到首条事件就立即发送，随后 30 秒内的事件不会安排下一次发送；若任务在此时结束，这些事件会等到以后再次使用时才上传。

现在复用已有后台发送程序，等待约 30 秒后集中上传这段时间产生的事件。并发调用共用已安排的发送，剩余批次继续由同一程序处理。发送前关闭记录仍会生效。手动 `flush` 继续立即发送，网络失败保留既有队列和后续使用时重试的行为。

验证使用真实安装命令和 CLI。五条事件的本地复现中，原实现只发送一条、留下四条；修复后五条全部发送，队列清空。在 GitHub Actions Ubuntu 中，默认后台程序自动发送了 14 条事件，原始内容与私密仓库导出逐条一致；发送前关闭的对照批次没有进入导出。本次在线检查没有手动上传或管理接口写库。Agent 工具的事件使用受控输入传入已安装的 hook 命令，没有新跑模型任务。

更新完整安装副本或插件至 v2.4.2 即可取得修复。Codex、Claude Code、OpenCode 各自的配置加载和信任要求继续适用，配置生效后开始记录。本补丁不增加研究步骤、依赖或后台服务，使用事件字段和正文分享权限保持不变。
