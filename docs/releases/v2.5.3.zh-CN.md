# Research Toolkit v2.5.3

[English](v2.5.3.md) · [简体中文](v2.5.3.zh-CN.md)

这是一个兼容补丁，修复使用告知、报告分享范围和记录处理，并补齐可执行 MCP 示例的暂停与恢复行为。

- 任务和会话标识使用单独保存在本地的 HMAC 密钥，不发送给接收端；原上传凭证继续用于鉴权。旧队列保留原标识，按任务删除兼顾新旧两代标识。已有关闭设置保持关闭。
- 首次成功工具或安装返回包含 `usage_notice`，列出实际接收地址、记录字段和关闭命令；Skill 要求 Agent 在对话中展示。基础使用记录仍默认开启，报告、聊天和原始材料分享仍须用户同意。
- 未明确选择项目时，分享邀请只覆盖当前任务；持续授权明确展示目录及其子目录。保留上层授权、下层拒绝和单次分享的含义。所选凭证文件及明确的私钥、令牌格式在入队前拒绝，不回显敏感内容。
- Toolkit 换目录后重装，只替换它自身的旧启动命令。共享状态保存使用同目录临时文件及原子替换；损坏的进度或活动记录指出文件或行号，并保留原件。
- MCP 示例的 `--pause-before-review` 现在会在主稿登记后暂停，`--resume` 继续准备独立任务。主稿作者登记提示提前到审阅之前。显式配置的 generic HTTP 审阅后端校验凭证变量名，并处理可配置的连接无响应超时与响应大小限制；不增加研究任务总时限。
- Release 标签核对同一提交已经通过的 main 分支 Framework checks；双语提醒覆盖已有的顶层方法、用法和 Agent 指南配对。同步中英文说明、插件、历史案例导航和研究汇总。

本地验证使用隔离文件和数据库、实际 CLI/MCP 调用及本地 HTTP，检查了分享范围、拒绝、凭证筛查、安装迁移、原子替换失败、损坏记录、响应上限和标识迁移及删除。现有 MCP 契约检查执行 README 示例及独立审阅完成契约。一条旧检查对损坏日志的预期已纠正；另一次续接检查在临时任务初始化时失败，仅复跑该项并采集返回后通过，两次记录均保留。连接超时错误处理采用注入错误验证。

另以新的独立过程语言上下文复读中文微短剧全文，发现两处制作记录式表述；局部修订及独立确认另存，原报告和历史验收记录不变。研究仍为 13 个问题、15 份报告，不计为新增研究，也不将这两处修订写成整体研究质量提升。

请更新完整安装包至 v2.5.3。公开操作名称、旧任务、独立审阅职责和完成要求保持兼容。新标识从升级后开始使用，已排队和已上传数据不重写。Release 提供插件 ZIP 和 `SHA256SUMS`。
