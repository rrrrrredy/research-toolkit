# Research Toolkit v2.5.5

[English](v2.5.5.md) · [简体中文](v2.5.5.zh-CN.md)

本次兼容性补丁修复持续报告分享授权、CLI 使用提示语言，以及 MCP 契约检查首次运行的假失败。

- 旧持续授权没有记录用户是否确认过明确显示的目录范围。下一次交付或 `share-offer` 使用该授权时，沿用现有邀请显示实际目录；取得同意前不将新报告入队。未回答时不重复提示。确认持续分享后保存范围确认，后续报告沿用授权并保持去重。单次分享不会授权今后的自动分享，子目录明确拒绝和更窄范围的授权继续有效。
- CLI 请求将 `language` 传给首次使用提示：`zh` 和 `zh-CN` 返回中文，`en` 返回英文。后续调用不重复提示。
- 现有 MCP 契约检查对 CLI、MCP 两侧子进程都明确关闭使用记录。新安装不会再因为只有 CLI 返回首次提示而导致比较失败；完整返回值比较保持不变。

验证使用虚拟文件和隔离本地设置，并关闭自动上传。实际 CLI 场景覆盖旧范围确认、未回答、单次分享、确认后同项目其他报告、去重、子目录选择、缩小授权及三种语言值。现有插件 MCP 契约检查在外层使用记录开启、使用目录全新的条件下运行一次，通过且未生成使用事件或内容记录。没有重跑研究任务或调用模型。

中英文使用说明与插件副本同步。更新完整 v2.5.5 安装包即可取得修复；已有研究记录、CLI／MCP 操作名称和独立审阅职责保持不变。Release 提供插件 ZIP 与 `SHA256SUMS`。
