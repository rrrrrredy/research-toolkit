# Research Toolkit v3.1.3

[English](v3.1.3.md) · [简体中文](v3.1.3.zh-CN.md)

- Markdown reports can use inline code for a labelled field requirement or working directory. The sharing check matches paired backticks and the corresponding English or Chinese parentheses. Bare credential assignments continue to block sharing.
- Both Codex manifests load a hook file with the native Windows command. Claude's default hook file contains the shared command fields. The built-in hooks still use the existing opt-in recording setting.
- Registered release logs accept same-line dates and versions, including Keep a Changelog headings. The existing two-line format also works. New and revised entries are compared by date and version. Each entry needs a body.
- Offline evaluation counts the specific public URL cited and reports the line numbers of private chat citation markers.
