# Research Toolkit v2.5.6

[English](v2.5.6.md) · [简体中文](v2.5.6.zh-CN.md)

本次发布彻底移除共享实现和分发插件中残留的旧研究模式入口。新研究与接续研究统一使用现有独立审阅、审计和验收路径。

- 删除 CLI 隐藏的 `--profile`、start/guide 的 CLI JSON 与 MCP `profile` 参数，以及新任务记录和返回中的模式字段。旧参数在建立任务前明确报错，不再静默转换成统一流程。
- 删除仅靠作者清单完成的实现、跳过审阅分支、`profile_policy.py`，以及 finish 的旧 `checklist` 参数。已保存的作者清单仍是原始记录，不再构成当前任务的完成路径。
- 删除旧教学输入、方法文件和快速开始重定向页；撤掉旧单次回复评测执行器的 prepare/run 入口，只保留读取和核对历史证据所需的辅助能力。原始研究文件和历史结果没有改写。
- MCP 按公开工具签名拒绝未知字段，避免 SDK 静默丢弃旧参数。同步中英文使用说明和插件文件。

## 如何更新

替换完整插件或 Skill 目录，包括 references 和 scripts；已缓存的私人技能也应整体替换。start/guide 调用删除 `--profile` 或 JSON/MCP 的 `profile`，finish 调用删除旧 `checklist` 参数。这些旧调用在本补丁中明确停止支持。正常统一入口、已保存的来源、要求、稿件及独立职责保持原有用途；更新安装不需要删除任务数据或重跑已完成研究。

## 已完成验证

复用本轮已经完成的受影响 Python 编译及 44 项现有仓库检查命令，覆盖 CLI/MCP、保存、接续、审阅与交付、安装、插件同步、历史证据和静态网站。其中三项检查依赖已删除的模式输入或旧异常形式，调整既有检查后只复查失败案例。没有新增单元测试套件、重跑研究或增加模型对照。

打包 MCP 场景拒绝旧模式参数且不建立任务，随后正常完成独立审阅、审计和验收。只读核对已交付的组织变革研究，通过 10/10 独立职责检查，任务目录 608 个文件保持不变。这里验证的是对应接口和记录行为，不将清理旧入口写成研究质量提升。

Release 提供完整插件 ZIP 与 `SHA256SUMS`。
