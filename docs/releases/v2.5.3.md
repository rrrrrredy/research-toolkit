# Research Toolkit v2.5.3

[English](v2.5.3.md) · [简体中文](v2.5.3.zh-CN.md)

This compatible patch fixes usage notices, report-sharing scope and record handling, and completes the executable MCP example's pause/resume behavior.

- Task and session identifiers use a separate local HMAC key that is never sent to the receiver. The existing upload credential remains the authentication credential. Older queued events retain their original identifiers; task deletion covers both generations. Existing off settings remain off.
- The first successful tool or installation result includes `usage_notice`, with the actual receiver, recorded fields and disable command. The Skill asks the agent to display it in the conversation. Default basic-event recording remains enabled; report, chat and source-content sharing still requires user agreement.
- Without an explicitly selected project, a sharing invitation covers only its task. Continuing authorization displays the directory and its descendants. Parent grants, child refusals and one-time sharing retain their intended meanings. Selected credential files and recognizable private-key/token patterns are rejected before queueing without echoing the secret.
- Reinstallation after moving Toolkit replaces only Toolkit's own old launcher. Shared state writes use a same-directory temporary file and atomic replacement. Malformed progress and activity records identify their file or row and preserve the originals.
- The MCP example's `--pause-before-review` now pauses after manuscript registration; `--resume` prepares independent assignments. Main-manuscript producer guidance is shown before review. A configured generic HTTP reviewer validates the credential variable name and handles configurable socket inactivity and response-size limits; no research-wide duration limit is added.
- Release tags check that the exact commit already passed main-branch Framework checks. Translation reminders include existing top-level method, usage and agent-guide pairs. Bilingual instructions, the plugin, historical-case navigation and study summaries are synchronized.

Local verification used isolated files/databases, actual CLI/MCP calls and loopback HTTP. Sharing scope, refusal, credential filtering, installation relocation, atomic-write failure, malformed records, bounded responses and identifier migration/deletion were checked. The existing MCP contract exercised the README example and independent-review completion contract. An obsolete malformed-log expectation was corrected; a separate continuity fixture initially failed during setup and passed when only that case was rerun with diagnostic capture. Both records remain retained. Socket-timeout error handling used an injected error.

A separate independent process-language reread of the Chinese microdrama report found two production-record phrases. A two-location revision and the independent confirmation are saved alongside the originals; the historical report and acceptance records are unchanged. This remains 13 research questions and 15 report assignments, not a new study or a claim of overall quality improvement.

Install the complete v2.5.3 package. Public operation names, saved tasks, independent review duties and completion requirements remain compatible. New identifiers start at upgrade; previously queued and uploaded data are not rewritten. The Release includes the plugin ZIP and `SHA256SUMS`.
