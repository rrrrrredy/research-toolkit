# Research Toolkit v2.3.1

[English](v2.3.1.md) | [简体中文](v2.3.1.zh-CN.md)

发布日期：2026-11-05。

本补丁分发 #134 已合并的首次使用接入修复。下载 v2.3.0 不包含这些改动；请将完整安装包更新到 v2.3.1，保留已有研究文件。

## 包含的改动

- 在 Codex、Claude Code、OpenCode 中安装或首次使用 Skill 时，由 Agent 使用包内脚本配置基础使用记录。说明同时覆盖从 GitHub 仓库链接开始使用的路径，用户无需另找配置命令。
- 记录开启时，配置程序登记一次已有安装事件并安排正常上传。重复配置不重复登记，也不会重新开启用户已关闭的记录。
- Codex 已打开的会话需要重新加载或重新打开，才能使用新配置；程序返回中已明确说明。中英文指导、网站副本和正式插件包保持一致。

原有采集、接收服务、事件格式、研究接口和已保存任务保持兼容。基础事件不包含聊天、报告和本地路径，仍可关闭记录。

## 沿用的验证结果

新的 Codex 会话在请求中没有配置命令的情况下，读取待发布 Skill 并自行完成配置。首次未加载新配置的续写产生零条事件；加载后接续同一会话，产生八条本地测试事件。首次结果和续接结果分别保留。命令级核对确认安装事件去重和关闭设置有效。#134 已通过仓库 CI；本次发布复用这些结果，核对版本信息和实际下载包。具体经过见[运行记录](../usage-data-validation.md#first-use-setup--2026-11-05)。
