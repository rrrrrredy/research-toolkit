# Research Toolkit v1.4.4

[English](v1.4.4.md) | [简体中文](v1.4.4.zh-CN.md)

本补丁将 [PR #99](https://github.com/rrrrrredy/research-toolkit/pull/99) 的统一研究入口与方法加载分发给插件安装用户。v1.4.3 安装包仍提供 Lite／Full 选择，并为历史 Lite 任务加载精简方法。更新安装包即可获得统一的完整方法，无需迁移已有任务。

## 改动

- **一个研究入口。** 默认说明、快速开始、Agent 接入卡和网站入口不再要求用户或 Agent 选择 Lite 或 Full。由研究需求决定范围、深度与篇幅，支持长文和深度研究。
- **同一套研究方法。** 阶段指导复用已有完整方法；原精简指南中有用的分析说明和示例并入公共分析参考。按工作需要读取方法，不强套报告结构，也不新增评审步骤。
- **已有工作继续使用。** 历史 `lite/full` 参数继续接受，已有任务保留记载的完成规则和历史，同时读取统一方法。例如，过去已经建立的清单任务仍可按原清单完成，不会因为升级突然要求额外评审。新请求无需填写历史参数。旧快速开始链接指向统一指南。
- **分发内容同步。** 中英文入口文档、CLI／MCP 说明、网站页面与插件副本保持一致。贡献指南根据受影响行为和已有覆盖选择验证，不对所有贡献强制规定同一种测试方式。

## 验证与限制

PR #99 的 Framework checks 和双语文档工作流通过。本地已完成受影响 Python 代码编译、JavaScript 语法、网站生成与双语 Skill 同步、插件 49 个共享文件同步检查。已有 MCP stdio 端到端检查成功运行耗时 13.721 秒，覆盖双语统一方法及旧任务兼容，并沿用其中的评审、修订和交付场景。运行使用模拟评审进程；该耗时不包括此前因环境问题失败的尝试。

发布准备沿用这些结果，本地只核对变化的版本元数据和生成包，由仓库现有 CI 检查发布提交。不重跑研究任务或模型对照。

**研究质量提升仍未验证。** 入口统一和方法加载一致，不等于分析质量、指令遵循或研究速度已经改善。

## 升级

下载 [v1.4.4 插件 ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.4/research-toolkit-plugin-v1.4.4.zip) 和 [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.4.4/SHA256SUMS)，或将完整仓库更新到 `v1.4.4`。保留本地任务及有意修改的文件，替换插件安装包并在宿主中重新加载。无需迁移任务数据。
