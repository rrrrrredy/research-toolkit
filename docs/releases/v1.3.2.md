# Research Toolkit v1.3.2

[English](v1.3.2.md) | [简体中文](v1.3.2.zh-CN.md)

This patch distributes the Lite self-check wording already merged in [PR #81](https://github.com/rrrrrredy/research-toolkit/pull/81) and the entry-point clarification in [PR #82](https://github.com/rrrrrredy/research-toolkit/pull/82). The v1.3.1 plugin still contains the earlier instructions, so an installed user needs this package update to receive the correction. There are no new tools, required fields, calls or task migrations.

## Installed changes

- The reader-edit instruction asks the agent to read the complete current report, remove repeated or off-topic passages, and cite actual findings or corrections at concrete report/source locations.
- Checklist diagnostics replace the bare requirement to supply `passed=true` with an instruction to complete the check and resolve the report defect. Unchecked or unresolved work stays false; changing the flag alone does not fix the report.
- The bilingual Skill entry points, Lite guide and generated plugin consistently ask for actual check results; the entry points no longer tell the agent to submit every item as passed. The existing six checklist items and validation predicates are unchanged.
- Bilingual tool descriptions remain aligned with the nine MCP tools actually registered. The count is unchanged from v1.3.1; correcting the intervening eight-tool wording does not add functionality.

## Report corrections and evidence limits

The repository retains four separately revised reports on predictive-maintenance subscriptions, guide-fund investment and exits, Scope-3 RFQs, and LLM credit-memo drafting. The [change notes](https://github.com/rrrrrredy/research-toolkit/blob/v1.3.2/evals/repairs/2026-10-19-reader-edit/README.md) correct the originals' quality-pass descriptions and explain each revision. Original reports, self-checks, source packs, batch summaries and historical outcomes remain intact. The repairs add no evaluation runs and are not a Toolkit core-capability upgrade. Research archives are not added to the plugin payload.

**Whether the self-check wording reduces false self-reported passes remains unverified.** The patch does not automatically assess semantic correctness, and the revised reports do not establish a general improvement in Toolkit research quality or efficiency.

## Validation

PR #81 passed its Linux, Windows, minimum-Python and static-site CI checks. Compilation, plugin/site consistency, original-archive integrity and local link checks had already passed. Release preparation reuses those results, checks the changed version metadata and generated package, and follows existing repository CI; it adds no model runs or runtime tests and does not manually rerun the completed implementation checks.

## Update

Download the [v1.3.2 plugin ZIP](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.3.2/research-toolkit-plugin-v1.3.2.zip) and [SHA256SUMS](https://github.com/rrrrrredy/research-toolkit/releases/download/v1.3.2/SHA256SUMS), or update the complete checkout to `v1.3.2`. Install the complete plugin using the host's existing mechanism, preserve local tasks and intentional edits, then reload its methods and restart the local MCP service. Python 3.10+ and the existing MCP dependencies still apply.
