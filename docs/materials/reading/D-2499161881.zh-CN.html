深化AI技术应用 推出 Amazon SageMaker、Amazon Bedrock 等 AI 平台，满足企业多方面需求，帮助快速构建和部署 AI 应用。

随着AI技术的不断进步，预计AWS将继续推出更多专业且先进的AI产品和服务，加强与领先的AI企业合作、推动技术创新，以满足市场对智能化升级的需求。凭借强大的技术实力、丰富的产品和服务体系以及广泛的合作伙伴生态系统，相信亚马逊将继续引领人工智能技术的创新和发展，推动更多企业和组织加速迈入 AI 时代。

1.AI 基础服务

1.1.Amazon Transcribe

Amazon Transcribe 是 AWS 提供的自动语音识别（Automatic Speech Recognition, ASR）服务，它能够将语音转换成文本。这项服务背后的技术可以识别不同说话者的语音，并提供包括标点符号、格式化的文本、以及其他详细信息的转录结果。

__ 主要功能特性 __ 描述
音频格式支持 支持 WAV、MP3、OGG 和 FLAC 等多种音频格式。
语言支持 支持英语、法语、德语、西班牙语、中文、日语等多种语言。
自动识别说话者 能够自动识别说话者并生成单独的转录文本。
时间戳生成 可以生成时间戳，便于识别音频中的特定部分。
置信度分数 提供转录文本的置信度分数，评估转录准确性。
转录文本存储和访问 可以通过 Amazon S3 服务存储和访问转录文本。
__ 典型使用场景 __ 描述
--- ---
会议和讲座转录 将会议和讲座的录音转换为文本，便于记录和回顾。
客户服务电话转录 将客户服务电话录音转换为文本，用于服务质量分析。
视频内容字幕生成 将视频内容转换为字幕，提高可访问性。
可搜索音频档案创建 创建可搜索的音频档案，便于信息检索和管理。
语音分析 进行语音分析，包括情感分析、关键词提取等。

Amazon Transcribe 是一种易于使用且价格实惠的服务，可轻松将音频内容转换为文本。通过这项服务，开发者和企业能够快速构建起语音驱动的应用，提升用户体验，并优化业务流程。

1.2.Amazon Polly

Amazon Polly 是 AWS 提供的文本到语音（Text-to-Speech, TTS）服务，它能够将普通文本转换成听起来自然的人类语音。

__ 功能特性 __ 描述
文本格式支持 支持文本、HTML 和 SSML 格式
声音多样性 支持男女声、不同语调和不同音色
语言支持 支持英语、法语、德语、西班牙语、中文、日语等多种语言
语音调节 可以调整语音的速度和音调
SSML 语音效果 可以使用 SSML 添加暂停、强调和呼吸等语音效果
存储和访问 可以通过 Amazon S3 存储和访问生成的语音
__ 典型用例 __ 描述
--- ---
有声读物 创建有声读物和电子书
聊天机器人 构建聊天机器人和虚拟助手
播客和广播 生成播客和广播节目
视频旁白 将文本转换为视频中的语音旁白
教育和培训 创建可访问的教育和培训材料

Amazon Polly 使得开发者能够将文本内容转换为语音，增强应用程序的可访问性和用户体验。无论是创建自动化的新闻广播、音频内容，还是提供语言学习工具，Amazon Polly 都是一个强大的工具。

1.3.Amazon Textract

Amazon Textract 是 AWS 提供的机器学习服务，它能够自动从扫描的文档中提取文本、手写内容、布局元素和数据。

__ 功能特性 __ 描述
简单文本识别 识别段落、句子、单词和字符
表格数据识别 识别行、列、单元格和表格内容
表单数据识别 识别键、值、复选框和单选按钮
手写文本识别 识别签名、记号和批注
元数据识别 识别业务文件中的作者、日期、标题和主题
__ 典型使用场景 __ 应用描述
--- ---
文档处理 自动化文档处理流程，例如发票处理、索赔处理和客户支持
数据提取 从文档中提取数据以进行分析和报告
法律发现 查找和分析法律文件中包含的相关信息
历史档案管理 数字化和编制历史档案
客户体验 分析客户反馈和评论

Amazon Textract 基于先进的机器学习模型，帮助企业自动化和简化文档处理流程，提高业务效率并加快决策制定。

1.4.Amazon Translate

Amazon Translate 是 AWS 提供的机器翻译服务，旨在将文本从一种语言翻译成另一种语言。

__ 功能特性 __ 描述
支持多种语言 支持超过 200 种语言的翻译，包括英语、法语、德语、西班牙语、中文、日语、韩语等。
高精度翻译 使用最先进的神经网络机器翻译技术，提供高精度翻译。
低延迟 提供低延迟翻译，快速获得翻译结果。
易于使用 可通过 Amazon Translate API 或 AWS Management Console 进行访问。
__ 典型用例 __ 描述
--- ---
网站和应用程序本地化 将网站和应用程序翻译成多种语言，触达全球受众。
客户支持 为客户提供多语言支持。
文档翻译 将文档翻译成多种语言，与全球合作伙伴和客户共享。
市场营销和广告 创建针对不同语言受众的营销和广告材料。
研究和教育 翻译研究论文和教育材料。

Amazon Translate 适用于需要在不同语言之间进行文本翻译的各种应用场景，通过这项服务，企业可以更容易地扩展其全球业务，同时为用户提供母语化的内容体验。

1.5.Amazon Lex

Amazon Lex 是 AWS 提供的支持开发者构建和部署具有自然语言处理能力的对话式人工智能接口，它使用最先进的自然语言处理 (NLP) 技术，可理解用户的意图并以自然的方式响应。

__ 功能特性名称 __ 描述
构建聊天机器人 使用 Amazon Lex Studio 可视化界面或 Amazon Lex API 创建聊天机器人。
自然语言理解 可以理解用户的意图并从文本、语音和传感器数据等多种来源提取信息。
对话管理 管理对话流程，包括处理多个回合、跟踪上下文和处理错误。
集成 与其他 AWS 服务和第三方应用集成，如 Amazon S3、Amazon DynamoDB 和 Facebook Messenger 等。

典型用例

__ 典型用例 __ 应用描述
客户服务 提供 24/7 全天候客户支持，回答常见问题并解决问题。
销售和营销 了解客户需求、推荐产品和提供个性化优惠。
教育和培训 提供交互式学习体验并回答学生的问题。
内部工具 自动化员工任务，例如提交请求和获取信息。
娱乐和游戏 创建引人入胜的互动体验。

Amazon Lex 使构建智能聊天机器人变得简单，它可以自动回答用户问题、处理交易、提供个性化推荐，或者执行其他各种任务。
