      "content": "将大语言模型（LLMs）与复杂的人类价值观对齐，仍然是 AI 面临的一个核心挑战。当前主要的方法是基于人类反馈的强化学习（RLHF）。该流程依赖于一个通过人类偏好训练的奖励模型来对模型输出进行评分，最终对齐后的 LLM 的质量在根本上取决于该奖励模型的质量。\n\n因此，创建一个先进的奖励模型需要建立庞大且高质量的人类偏好数据集，而这一过程通常既缓慢、昂贵，又难以扩展。 \n\n这种对人类标注数据的依赖促使研究者探索其他对齐方法。一个重要的研究方向是基于 AI 反馈的强化学习（RLAIF）。该方法利用强大的专有大语言模型生成奖励信号或偏好标签，从而规避人类标注需求。虽然成本效益显著，但这些方法缺乏严谨的理论基础，且容易继承评判模型本身的风格偏差与固有偏见。这引发了一个关键问题：高质量奖励信号是否必须依赖外部来源？\n\n来自南京大学的研究者发现，一个强大的通用奖励模型并非需要构建，而是可以挖掘出来的， 因为它已经潜在地存在于通过标准的下一个 Token 预测训练的任何语言模型中，称之为「内源性奖励（endogenous reward）」。\n\n[本文](https://arxiv.org/abs/2506.23235)的核心贡献是为这一观点提供严格的理论基础。本文证明了可以从标准的下一个 Token 预测目标中恢复出一种特定形式的离线逆强化学习（IRL）奖励函数，该目标用于预训练和监督微调（SFT）。这一见解能够超越启发式方法，并建立一种原则性的方法，来引出语言模型在训练过程中隐式学习到的奖励函数。\n\n具体来说，本文展示了语言模型的 logits 可以直接解释为 soft Q 函数，通过逆 soft 贝尔曼算子可以从中恢复出奖励函数。 \n\n至关重要的是，这一理论联系不仅仅提供了一种奖励提取的方法。本文还证明了，使用模型自身的内源性奖励进行微调可以使策略在误差界限上优于基线模型。强化学习过程有效地修正了标准模仿学习（即下一个 Token 预测）中的累积误差，将性能差距从任务视野的二次依赖关系 O (H²) 降低到优越的线性关系 O (H)。\n\n据了解，这是首次理论证明强化学习在 LLM 中的有效性。广泛实验验证了这一理论，表明这种内源性奖励不仅优于现有的 LLM-as-a-judge 方法，而且可以超越那些通过昂贵的人类标注数据显式训练的奖励模型的表现。"

旧生成摘要（未重写，未核实）

本周论文推荐涵盖多项重要研究成果。周志华团队提出"内源性奖励"理论，发现奖励模型已隐式存在于语言模型内部，无需依赖外部人类标注数据。研究从理论上首次证明了强化学习在LLM中有效性的机制——语言模型的logits可直接解释为soft Q函数，并从中恢复奖励函数。关键发现表明，RL微调能将性能误差界限从二次依赖O(H²)降低至线性关系O(H)，实验结果显示内源性奖励不仅优于LLM-as-a-judge方法，甚至超越基于人类标注数据训练的奖励模型。

阿里巴巴达摩院推出WorldVLA（arXiv编号2506.21539），这是首个将世界模型与动作模型融合为统一架构的全自回归模型，能够同时支持文本、图片与动作的理解与生成，标志着具身智能领域的重要突破。此外，Virginia Tech在ICML 2025发表研究，深入探讨大语言模型在决策场景下的选择依据，为理解LLM决策行为提供了新视角。上海交大亦有多篇佳作入选本期推荐，Bengio和邢波团队同样贡献了新研究成果。本周推荐整体呈现出从理论基础到系统架构、从语言模型对齐到具身智能的宽广研究图景。
