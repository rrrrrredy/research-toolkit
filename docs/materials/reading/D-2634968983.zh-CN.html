国内大模型厂商商业化专家访谈及投放策略

一、专家访谈信息

1.六小虎目前集中的场景主要是医疗、教育、金融和零售等场景，个别会有侧重，比如百川的商业化主要集中在医疗和教育领域，也有像智谱、讯飞和百度等会做一些政务方面的应用。

2.阿里、百度、字节、讯飞等公司都有不同程度 to B 的创新应用。它们的应用场景更广泛，比如讯飞可能在智能客服场景这个领域里边是做得比较靠前的，阿里今年是“云 + AI”的战略，场景也是涉及比较广，像智能客服、智能管理，包括娱乐领域的应用。

3.在 to B 领域里，大模型产品主要是像在政府、教育行业里变现是最快的。在金融行业，因为金融行业的科技研发能力在国内来说相对比较强，所以企业自建的相对多一些。当然金融客户大模型关联的和一些算力或者一些应用这方面的变现可能会远高于模型本身的变现能力。

4.六小虎目前都可以拿到千万级的订单，讯飞因为和政府绑定比较深，之前也有很多做 To G 的经验，现在能拿到上亿的订单。

5.教育、医疗和娱乐等行业用 API 服务的多一些。因为用 API 服务的话可以用到最新的模型，性价比也高一些，而且选择性也更多，成本也更低。但是在政务、金融、法律行业里面，基本上都是禁止外发的数据，只能存在企业内部，这类的场景因为受限于数据的情况，因为数据要存在本地，不能通过云的方式进行交互所以对这三类的行业大模型优先会选择本地的私有化部署，这样能充分保证数据安全的问题，并且能最大化地降低企业安全风险。

6.目前还是以私有化定制为主的，尤其是在 to B 行业里面。大公司可能走得比较靠前，因为它们有多年的摸索，并且已经具备了产品的研发设计能力。目前来看，更多的中小型公司要快速去做应用落地，那就完全依赖它们自身的研发人员去做这样的工作。但像阿里这样的大公司，它们在内部的大模型应用，投入的人力、技术、算力等等这些综合情况，不是一般的中小型机构能承担的，在这种情况下，未来的很长一段时间之内，还是以定制化为主的方式去提供服务。

7.定制化项目的价格下降趋势是比较明显的，去年千万级的项目今年可能已经是百万级了。这个价格空间后面会根据这个场景的价值也会有相应的分层，比如高价值的场景可能像智能客服，如果某一家做得特别好，而且优先占领这个市场，那它的占比也会走这样一个上坡的趋势。所以目前来说，以定制化为主，价格目前阶段还主要靠人力，目前供应商做的调整其实都是通过挤压人力的方式去节约成本。接下来就会逐渐形成一些标准化的产品，价格也会趋向于稳定这样一个方式。

8.从算力的角度，大公司现阶段倾向于比较冷静地去看待。近期算力市场的价格是呈下跌趋势的，因为大家都会去做分阶段的规划，不会一次性去大规模地去采购卡，而会会根据自己实际的业务情况分级分层地去采集、去购买部署自己的算力。在这种情况下，那它的成本就大大降低了。

9.同样的，在模型产品这一块，主要原因首先是国内外的产品竞争确实越来越大；另外目前开源的模型产品效果也越来越好，包括 OpenAI 的价格区间也会越来越低。所以目前来说整体的情况是内外部的一些竞争，再加上一些开源的产品，就导致现在这个价格有大幅度的下降。

10.目前国内的大模型 To B 市场还处于市场教育阶段。比如像千问，因为它本身是开源的，但它又是在走商业化路线，所以在这种背景之下，其实价格一下子就被拉到低点了。在这样一个背景下，报价自然上不去，唯一能增加的就是它的附加能力。比如它们能帮助企业做一些产品，就是大模型产品的规划、场景化的建设或者模型微调这样的一个工作。基于这样的情况，就导致百度、其他的大模型厂家都会受到这样的波及，就导致价格下跌，利润成本也被无限压缩。为了占领市场，不只是 to B 端，其实 To C 端也是价格卷到无底线地往下降，比如 API 有一些免费的，有一些低价的，有一些 100 倍、100 倍地往下降的，整体这样一个情况。今年整体的价格战其实第一波已经打过去了，可能未来还会有更深层次的，比如结合大模型或结合其他的做一些绑定，未来可能会有这样的趋势发生。

11.MiniMax 今年的销售目标大概在 5 亿左右，虽然它在逐渐从 To B 转到 To C，但它在国内做 To B 是有一些存量的；实零一走的是开源加闭源的路线，在 to B 里面，它目前主要是去做高性价比的 API 以及一些附加的服务；百川在医疗目前在医疗方面是领先其他大模型厂商的，但是它今年的收入也是非常低的；阶跃星辰没有对外公布很详细的营业收入，但其实它在六小虎里面是发展相对比较晚的，而且产品也只是在部分的应用里面去用，做体验这样一个方式。

12.六小虎目前的劣势是市场、商业化和产品的技术成熟度；优势根据各自专注的场景也各异，比如有的专注海外，有的专注医疗，有的像像零一万物就是开源加闭源的这样一套组合，通过开源来吸引用户，以闭源的方式来做市场份额的占领；另外，六小虎在技术研发上的迭代速度目前还是很快的，而且相对大厂来说，它们的灵活性、多元化会更适合这个市场。当然，六小虎和几个大厂其实在业务上会有一些交叉，但随着现在的市场发展，还有每家的技术特点、模型产品的特点，明年这个界限可能会更清晰一些。今年大家在各种领域去试错、各种尝试，但是随着市场的变化，大家未来也都会更清晰、更明确。

13.在 To C 商业化层面，主要看 Kimi、豆包和文心一言三家。从场景上来看，Kimi 是以智能问答、智能搜索为主，投入了很多资源去做重体验和重交互的产品；豆包今年做了一些偏向儿童方面场景的对话，今年上半年它在儿童智能对话这个场景上占领了一些客户的心智；文心一言是市场里最先做收费的，也因为百度的背景，它的整个生态相对比较完整。

15.豆包的投入其实比 Kimi 的手笔更高一些，而且近几个月发力明显。今年 6 月份的时候豆包明显开始发力抢市场，6 月它一个月的投放量就 1.4 亿了，相当于每天都将近 500 万的投放费用。所以在这样一个情况下，豆包的月活一下子飙升到 2,500 万 - 3,000 万这样一个阶段。在 6 月底，豆包在国内的下载量已经都达到了 300 万这样的数量，在这样一个投放的情况下，它的优势就凸显出来了。截止搭配今年的 10 月，豆包的月活达到了 5,000 多万。下载量的话，豆包截止 10 月份是达到了一亿多，排第二、第三的就是百度和 Kimi。
