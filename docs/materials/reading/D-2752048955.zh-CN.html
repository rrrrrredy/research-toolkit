3月第3周：海外加速收敛编程工具与企业级服务战线，国内阵营饱和攻击Agent入口

一、周趋势总结

1.海外

1.1.英伟达 GTC：从算力供应商到 AI 工厂定义者

万亿营收预期与垂直整合战略。黄仁勋将 2027 年营收预期提升至 1 万亿美元，较此前预测翻倍延长，这不仅是财务指引，更是对全球 AI 基础设施投资节奏的重新定义。Vera Rubin 平台不再局限于 GPU 单芯片，而是由 7 种芯片 + 5 种机架系统构成的完整 AI 超级计算机，其中 Groq 3 LPX 机架（搭载 256 个 LPU 处理器）与 Vera CPU 机架的发布，标志着英伟达正在侵蚀传统 CPU 厂商的地盘，通过 "GPU+CPU+LPU" 的三位一体架构锁定数据中心升级周期。

太空计算与边缘推理的前沿卡位。Space-1 Vera Rubin 模块将数据中心级算力部署至卫星和轨道数据中心（ODC），配合 Jetson Orin、IGX Thor 形成 "边缘→地面→云端" 的完整算力架构。这表明英伟达已不满足于地面数据中心的存量市场，正在抢占太空计算与在轨推理的增量空间，为未来太空互联网与实时地理空间智能预埋基础设施。

NemoClaw 与 AI 智能体基础设施化。 通过 NemoClaw 进军 "龙虾产业"，英伟达将 AI 智能体基础设施视为继 CUDA 之后的下一代开发者绑定平台。其定位并非简单的运行环境，而是集成 Nemotron 模型、OpenShell 运行环境、安全沙箱的完整 "养虾" 基础设施，支持从 RTX PC 到 DGX Station 的全场景部署。这标志着智能体开发正从黑客式的开源折腾转向工业级的标准化生产。

图形技术的范式转移。DLSS 5 被定义为 "图形领域的 GPT 时刻"，通过将传统 3D 图形数据与生成式 AI 结合，实现预测性渲染而非逐帧计算。结合 Nemotron 3 系列（特别是 Cosmos 3 世界基础模型、Isaac GR00T N1.7 人形机器人模型、Alpamayo 1.5 自动驾驶模型）的发布，英伟达正在构建 "物理 AI"（Physical AI）的完整工具链，从虚拟训练场到实体机器人形成闭环。

1.2.智能体协议与开发工具

WebMCP 与 CLI 路线。 Google Chrome 团队推出的 WebMCP 协议具有标志性意义：AI 智能体可通过 API 直接调用网页底层功能，无需依赖截屏识图或模拟点击的低效方式。更关键的是，该协议由 Google 与 Microsoft 联合共建并已开源，这意味着MCP（Model Context Protocol）正从 Anthropic 的私有标准演变为行业通用协议。前端开发者的角色由此发生质变 —— 从 "绘制视觉界面" 升级为 "定义 AI 与世界的结构化接口"，网页将分化为面向人类视觉层与面向 AI 工具层的双轨架构。

Anthropic 的跨设备 Agent 操作系统。 Dispatch 功能实现手机远程指挥 Mac 上的 Claude，Channels 功能通过 Telegram/Discord 接入本地 Claude Code 会话，这代表了GUI 桌面与命令行两大场景的双线布局。Anthropic 正在将 Claude 从聊天机器人重构为 "跨设备、跨平台、持续运行" 的 Agent 操作系统，其技术路线强调本地执行不经过云端，与纯云端方案形成差异化。

1.3.大模型厂商的战略收缩与聚焦

OpenAI 的 "红色警报" 与战略大收缩。 面临 Anthropic 在企业市场的步步紧逼（首次采购 AI 产品的企业客户中选择 Anthropic 的比例已达 OpenAI 的三倍），OpenAI 启动成立以来最重大的战略转型：裁撤 Sora 等非核心业务，资源全面向 Codex 编程工具与企业级服务倾斜；计划收购 Astral 补强 Python 工具链，收购 Promptfoo 补强安全测试；筹备 2026 年 Q4 IPO。这种从 "内部投资一系列初创公司" 的多线作战转向单点突破，反映出大模型商业化进入深水区 —— 在算力成本与竞争加剧的挤压下，"做多" 不如 "做深"，编程与企业服务成为最先验证付费意愿的场景。

OpenAI 的产品矩阵整合。 计划将 ChatGPT、Codex 与浏览器整合为 "超级应用"，并推出 GPT-5.4 mini 与 nano 轻量模型（定价较旗舰模型降低 80% 以上），同时在美国免费版 ChatGPT 投放广告寻求收入多元化。这种 "高端订阅 + 轻量 API + 广告" 的三级变现体系，表明 OpenAI 正试图覆盖从开发者到企业再到大众市场的全谱系用户。

1.4.多模态与垂直领域

3D 重建与长上下文的几何智能。 Google DeepMind 联合伯克利提出的 LoGeR（长时上下文几何重建），通过参数化测试时训练（TTT）记忆模块与滑动窗口注意力（SWA）机制，解决了前馈 3D 重建模型在长序列视频中的上下文壁垒问题。这代表几何基础模型（如 DUSt3R、MonST3R、VGGT）正从短时上下文 "气泡" 扩展到城市级别的长时序重建，为自动驾驶、AR/VR 等需要大范围 3D 感知的场景奠定基础。

生物 AI 与内容生成的专业化。ElevenLabs 推出 AI 音乐交易市场，首创 "创作者分成" 商业模式，试图在版权法灰色地带建立 AI 内容的资产化闭环；Perplexity Health 接入 Apple Health 等数据源，提供个性化医疗建议，标志着 AI 健康助手从通用问答向循证医学与个性化数据结合演进；亚马逊收购 Rivr 配送机器人，推进 "最后一公里" 自动化，目标将 75% 运营流程实现完全自动化。

2.国内

2.1.组织架构深度重组

阿里 Token Hub：AI 商业化的组织范式革命。阿里成立 Alibaba Token Hub 事业群，由 CEO 吴泳铭亲自挂帅，整合通义实验室（Qwen 模型研发）、钉钉、夸克与悟空事业部，首次将 "Token" 作为商业计量单位写入组织架构名称（"创造 Token、交付 Token、应用 Token"）。这不仅是部门合并，而是将 AI 业务从技术支持部门重构为营收中心，试图通过组织扁平化打破研究、产品、设计间的协作壁垒。千问月活超 3 亿、平头哥自研 GPU 规模化量产、AI 收入连续十个季度三位数增长，显示其 "大模型 + 云 + 芯片" 全栈战略初步跑通。

腾讯 AI Lab 撤销与组织架构调整。腾讯撤销 AI Lab，部分人员并入混元团队，多模态部向 TEG 总裁卢山汇报。这种调整反映出大厂对 AI 研发效率的焦虑—— 从分散的实验室制转向集中的产品化作战，试图通过组织架构压缩技术转化的路径长度。

百度 MEG 人事换将。大模型算法负责人何径舟轮岗至移动生态事业群组（MEG），出任百度 APP 研发中心负责人，原搜索负责人赵世奇离职。这明确释放出 "用大模型重构搜索与推荐" 的信号，试图将前沿 AI 技术与核心商业场景（搜索、信息流）深度融合。

2.2.模型技术路线的差异化突围

月之暗面的架构级创新。发布 Attention Residuals（AttnRes）架构，用跨层 Softmax 注意力替代传统残差连接，让每层主动、有选择性地从前序层提取信息，在 48B 参数 / 3B 激活规模下 GPQA-Diamond 提升超 20%。Kimi K2.5 技术路线图（MuonClip 优化器、Kimi Linear 混合线性注意力）的公开，以及 "Cursor 套壳 Kimi K2.5" 事件的澄清（确认为授权商业合作），显示其坚持开源路径以构建开发者生态的战略定力。

阿里 Qwen3.5-Max-Preview 登顶。在 LM Arena 斩获 1464 分，跻身全球前五、中国第一，数学能力全球第五。配合预训练动态数据选择范式 OPUS（从中低质量数据动态挑选击败高质量优先策略）的开源，阿里正在通过数据工程创新而非单纯算力堆砌实现模型效能提升。

小米 MiMo-V2 系列的端侧布局。发布旗舰推理模型 Pro（1T 总参数 / 42B 激活参数、1M 上下文）、全模态 Omni（支持 10 小时连续音频理解）、语音合成 TTS 三件套，通过 OpenClaw 等平台接入。这代表端侧大模型正从 "能力可用" 向 "专业可用" 演进，在高强度 Agent 场景与长时音频理解等垂直领域形成差异化优势。

MiniMax M2.7 的自我进化能力。 MiniMax M2.7 宣称是首个 "深度参与自身迭代过程" 的模型，能自行构建 Agent Harness，在强化学习、代码优化等环节参与自身训练迭代，曾无人工干预执行超 100 轮 "分析→修改→评测→回退" 循环将评测集效果提升 30%。这预示着模型训练可能从 "人类设计算法" 转向 "模型自主进化"的新范式。

2.3.垂直场景渗透

吉利与阶跃星辰的车载智能体。极氪 8X 首发搭载阶跃星辰 Step 3.5 Flash，发布 "超级 Eva" 智能体，实现 "带我去接孩子放学，顺便找麦当劳，5 点前到学校" 的模糊指令自主规划与执行。这标志着车载 AI 从 "语音助手" 向 "任务规划智能体" 跃迁，车机系统开始具备跨应用、跨域（座舱 / 智驾 / 数字生态）的原生融合能力。

LiblibAI 的 Agent 化视频创作。 推出 LibTV 定位 "同时服务人类创作者与 Agent 的视频创作系统"，通过 Skill 接口向 OpenClaw 开放能力，支持一句话生成 5 分钟短剧、输入 URL 复刻风格等。这代表创意生产工具正从 "人主导、AI 辅助" 向 "Agent 主导、人监督"的工作流转变。

字节 Seedance2.0 的短剧工业化。上线首个搭载 Seedance2.0 的短剧 Agent，支持 10 万字剧本一键成片、2D/3D / 仿真人画风、统一角色形象，内测爆款《万兽独尊》4 天播放破亿，5 人 8 天完成 60 集制作。华策影视、柠萌影视的接入，显示影视工业化生产可能跳过传统工具阶段，直接进入 Agent 原生时代。

3.龙虾（OpenClaw）：Agent 入口争夺已升级为操作系统级别的生态战争

本周国内 AI 产业呈现 "万物皆可龙虾" 的饱和式攻击态势，Agent 入口争夺已升级为操作系统级别的生态战争。

3.1.产品矩阵全景：全场景、全终端覆盖

企业级办公入口：阿里悟空（钉钉团队打造，"AI 用钉钉来工作"，覆盖电商、法律、财税等十大行业 OPT 方案）、飞书 aily（"一次点击拥有专属 Agent"，深度嵌入文档 / 日程 / 消息上下文）、百度 DuMate（国内首个国产企业级满血版，支持本地部署与沙箱隔离）。

个人与家庭终端：腾讯 QClaw（微信入口升级为小程序，业内首创微信直连）、微信 ClawBot（官方插件，扫码绑定）、QQ 机器人（支持富媒体双向交互，内测频道 AI 开放计划）、百度 RedClaw（移动端零部署）、小度 "家用小龙虾"（全球首款家庭场景 Agent）。

云端与存储集成：百度网盘 GenFlow（一键部署云端小龙虾，直接调用网盘文件）、阿里云 Lighthouse、腾讯云 WorkBuddy。

硬件与边缘计算：面壁智能 EdgeClaw Box（内置 MiniCPM 端侧模型，S1/S2/S3 三级隐私路由）、智谱机械革命盒子（全球首款 GLM 模型 "龙虾盒子"）。

开发工具与平台：阿里秒哒 Skill（全球首个 OpenClaw 应用开发 Skill，"对话即应用"）、百度伐谋 Skill（科研与算法场景）、LiblibAI Skill 接口。

3.2.技术路线分化与生态绑定

路线一：深度集成办公上下文。钉钉、飞书、企微等平台利用既有工作流数据优势，让 Agent 天生理解企业组织架构与文档关系，强调 "零配置" 即开即用。

路线二：微信 / QQ 社交链渗透。腾讯系产品利用国民级社交入口，通过微信小程序、QQ 频道等降低 "养虾" 门槛，试图将 Agent 转化为社交关系链中的 "数字员工"。

路线三：硬件绑定与端侧隔离。面壁智能 EdgeClaw Box、阿里松果派等通过本地硬件实现隐私隔离，采用 "本地简单任务 + 云端复杂任务" 的分层策略，解决企业数据出域焦虑。

3.3.安全风险：从边缘议题上升为核心基础设施

国家部委的警示与行业响应。国家安全部罕见发布《"龙虾" 安全养殖手册》，将 OpenClaw 定位为 "数字员工" 并进行合规警示；微软电脑管家上线 "一键卸载 / 停止龙虾" 功能；腾讯 "龙虾管家" 提供沙箱隔离、文件保护、端口暴露检测；蚂蚁数科 "龙虾卫士" 针对权限越界、记忆污染、恶意诱导等风险提供全生命周期防护。

风险图谱具象化：根据字节跳动内部安全规范，OpenClaw 存在五类核心风险：访问控制设置不当（38 万个实例公网暴露）、提示词注入、敏感信息窃取、供应链漏洞（Skills 插件投毒）、恶意插件投毒。百度 DuMate、面壁 EdgeClaw Box 等均强调 "预装安全沙箱"" 强制用户明确授权 ""操作全程可审计" 等企业级安全能力。

安全正从 "可选项" 变为 Agent 商业化的 "前提条件"。当 Agent 获得本地文件操作、浏览器控制、跨应用权限时，其风险等级已从 "信息泄露" 升级为 "系统破坏"。缺乏安全护栏的龙虾部署可能面临政策红线与用户信任的双重危机，这也解释了为何微软、腾讯等巨头在推自身 Agent 产品的同时，反而提供 "一键卸载竞品" 的安全工具 —— 既是竞争手段，也是生态责任。
