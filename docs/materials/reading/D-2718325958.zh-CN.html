一、模型

**公司/院校/机构** **简介** **详情**
**芝加哥大学** 芝加哥大学开发了一种基于自然语言生成 GDC 队列过滤器的开源 LLM 模型，性能优于 GPT-4o

Steven Song, Anirudh Subramanyam, Zhenyu Zhang, Aarti Venkat, Robert L. Grossman."GDC Cohort Copilot: An AI Copilot for Curating Cohorts from the Genomic Data Commons."arXiv:2507.02221 [cs.CL]		 [论文](https://arxiv.org/abs/2507.02221)介绍了一种名为 GDC Cohort Copilot 的开源工具，允许用户通过自然语言描述生成 GDC 队列。该工具利用大型语言模型（LLM）将自然语言查询转换为结构化的 GDC 队列过滤器 JSON，并提供图形界面供用户进一步优化队列。研究比较了多种模型和数据组合，最终训练的小规模 GPT-2 模型在准确性和效率上显著优于 GPT-4o，且可本地部署。该工具为癌症研究人员提供了更便捷的数据筛选方式。
**普林斯顿大学** 普林斯顿大学发现狭窄微调会破坏 LLM 内部共享的安全机制，揭示了对齐脆弱性

Jeremiah Giordani."Re-Emergent Misalignment: How Narrow Fine-Tuning Erodes Safety Alignment in LLMs."arXiv:2507.03662 [cs.LG]		 [研究](https://arxiv.org/abs/2507.03662)分析了在不安全代码上微调如何导致 LLM 出现广泛的对齐退化现象，通过多层次实验揭示了对齐退化的内部机制，并指出未来需要更稳健的微调策略。
**新南威尔士大学** 新南威尔士大学对比分析 Transformer、Conformer、Mamba 和 xLSTM 在因果与非因果配置下的性能，发现 xLSTM 和 Mamba 优于传统方法

Qiquan Zhang, Moran Chen, Zeyang Song, Hexin Liu, Xiangyu Zhang, Haizhou Li."Long-Context Modeling Networks for Monaural Speech Enhancement: A Comparative Study."arXiv:2507.04368 [eess.AS]		 语音增强旨在从背景噪声中提取清晰语音，深度学习方法近年来占据主导地位。[本文](https://www.arxiv.org/abs/2507.04368)系统比较了 Transformer、Conformer、Mamba 和 xLSTM 四种长上下文建模骨干网络在统一框架下的性能，涵盖模型表现、大小、训练和推理速度。结果：xLSTM 和 Mamba 在性能上优于 Transformer 和 Conformer，Mamba 在长语音输入时表现出显著的效率优势。意义：为语音增强领域提供了全面的基准研究，并验证了 xLSTM 和 Mamba 的潜力。
**CMU** Mamba 作者新论文提出分层网络 H-Net

Sukjun Hwang, Brandon Wang, Albert Gu."Dynamic Chunking for End-to-End Hierarchical Sequence Modeling."arXiv:2507.07955 [cs.LG]		 最近，Mamba 作者之一 Albert Gu 又发新研究，他参与的一篇论文《[Dynamic Chunking for End-to-End Hierarchical Sequence Modeling](https://arxiv.org/pdf/2507.07955v1) 》提出了一个分层网络 H-Net，其用模型内部的动态分块过程取代 tokenization，从而自动发现和操作有意义的数据单元。
**德国马普所、香港中文大学** 比 Adam 更有效，POET 从谱不变原理出发，让 LLM 训练又稳又快

Zeju Qiu, Simon Buchholz, Tim Z. Xiao, Maximilian Dax, Bernhard Schölkopf, Weiyang Liu."Reparameterized LLM Training via Orthogonal Equivalence Transformation."arXiv:2506.08001 [cs.LG]		 随着大型语言模型（LLM）推动人工智能领域取得突破性进展，如何实现高效、稳定的超大规模模型训练，始终是该领域最富挑战性的核心议题之一。针对这一关键问题，研究者们提出了一种基于第一性原理的全新方法 ——[POET（Reparameterized Training via Orthogonal Equivalence Transformation）](https://www.arxiv.org/abs/2506.08001)，该方法通过重参数化优化策略，旨在从第一性原理出发提升训练效率与稳定性。
**加州大学圣地亚哥分校** M + 框架：增加 LLM 隐空间记忆，不再受上下文窗口限制

Yu Wang, Dmitry Krotov, Yuanzhe Hu, Yifan Gao, Wangchunshu Zhou, Julian McAuley, Dan Gutfreund, Rogerio Feris, Zexue He."M+: Extending MemoryLLM with Scalable Long-Term Memory."arXiv:2502.00592 [cs.CL]		 [M+](https://arxiv.org/abs/2502.00592)是在 MemoryLLM 之上提出的长期隐空间记忆扩展框架：通过把「过期」隐藏向量写入 CPU - 侧长期记忆池，再用协同检索器拉回最相关记忆，它将 8 B 级模型的有效记忆跨度从原本不到 20 k tokens 提升到 160 k tokens 以上，同时显存占用保持不变。

旧生成摘要（未重写，未核实）

本周论文推荐涵盖多个前沿研究方向。芝加哥大学开发的GDC Cohort Copilot工具，通过训练小规模GPT-2模型将自然语言查询转换为JSON队列过滤器，在准确性和效率上显著超越GPT-4o，并支持本地部署。普林斯顿大学研究揭示，在不安全代码上微调LLM会破坏模型内部共享安全机制，导致广泛的对齐退化现象，暴露出模型对齐的系统性脆弱性。

在骨干网络比较方面，新南威尔士大学系统对比了Transformer、Conformer、Mamba、xLSTM四种架构在语音增强任务中的表现，结果显示xLSTM和Mamba整体优于前两者，Mamba在处理长语音输入时推理效率优势尤为突出。Mamba作者Albert Gu发表新作，提出分层网络H-Net，以模型内部动态分块过程取代传统tokenization，能自动发现数据中有意义的语义单元。

优化器领域，德国马普所与香港中文大学联合提出POET（Reparameterized Training via Orthogonal Equivalence Transformation），从谱不变原理出发设计重参数化训练方法，声称效果优于Adam优化器。加州大学圣地亚哥分校提出M+框架，基于MemoryLLM构建长期隐空间记忆机制，通过将过期隐藏向量写入CPU侧记忆池并协同检索召回，可将8B级模型有效记忆跨度从不足20k tokens提升至160k tokens以上，且显存占用保持不变。

推理可靠性方面，港中文与华为诺亚实验室联合提出ReliableMath基准，专门评估大模型面对无解数学问题时的可靠性。研究发现DeepSeek-R1等推理模型面对无解问题时会虚构答案，产生大量无意义推理过程。该基准已开源，并持续更新Qwen3、豆包、Gemini等主流模型的测试结果。
