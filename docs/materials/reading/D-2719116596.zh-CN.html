七月第三周：“Agent 即产品”成为新共识

一、周趋势总结

  1. 海外：“钱、人、卡” 三线共振，AGI 军备竞赛进入 “千卡万卡+千亿美元” 阶段
    • 资本维度：Meta 的 1000 亿美元算力计划、Anthropic 的千亿美元估值、TML 20 亿美元 A 轮、Cognition 1 亿美元现金并购——都指向同一件事：模型层开始“货币化前置”，先锁定算力与人才，再谈商业模式；
    • 人才维度：Meta 两周内从 OpenAI、苹果连挖多位核心研究员，人才流动半径首次从“公司级”变成“集群级”——谁家 GPU 多，谁的猎头半径就长；
    • 技术维度：Google DeepMind 的 MoR 架构、NVIDIA 的 OpenReasoning-Nemotron、谷歌 Veo3 高帧实时视频生成，三条线都在做“效率换规模”——用更少的参数、更低的推理成本逼近大模型性能，为千卡集群提供可持续的 ROI。
  2. 国内：“应用落地+开源反击”双线加速，估值天花板重新松动
    • 应用落地：MiniMax 3 亿美元融资后立刻推出“全栈 Agent 开发平台”；美图 RoboNeo、爱诗 PixVerse、智谱清影集体强化“一句话生成商业交付物”；字节 TRAE 上线 Kimi-K2 模型服务；
    • 开源反击：Kimi-K2、智源 RoboBrain 2.0、昆仑万维 AgentOrchestra 在同一周开源，加上 B 站 IndexTTS2 等，国内正在用“开源节奏”对抗“资本节奏”；
    • 估值松动：MiniMax 40 亿美元、智谱 30 亿美元，标志着“中国模型溢价”重新出现——资本开始相信中国团队能在应用层做出 10 倍效率差。
  3. 上周行业重点：“Agent 即产品”成为新共识
    • OpenAI 的 Agent 模式、Anthropic 的一键 MCP 目录、MiniMax 的 Agent + MCP builder、亚马逊 Bedrock AgentCore 全家桶——所有主流平台在同一周把“Agent”从功能升级为独立 SKU；
    • 交互方式随之变化：Claude 的 MCP、小度的 MCP Server、Kimi Playground 的工具调用，都在把“写代码”变成“搭积木”；
    • 开发者门槛从“会调 API”降到“会说需求”，预计 2025 Q4 将出现第一批“零代码 Agent 商店”，流量入口重新洗牌。
  4. 其他层面：
    • 硬件出口：英伟达 H20、AMD MI308 同时获准对华销售，标志中美 AI 芯片管制进入“精准卡脖子”阶段——只卡最高算力，不卡商业场景。利好国内训练集群的“次旗舰”组合方案；
    • 流量焦虑：Google Discover AI 摘要导致出版商流量再掉 13%，搜索-内容利益分配模型面临重构；作为对冲，Google 推出 Offerwall 与小额度支付，预演“AI 时代的微支付”场景；
    • 语音交互：Mistral Voxtral、B 站 IndexTTS2、百度 AI 助手视频通话三线并进，语音-视觉-动作多模态实时融合成为产品标配，谁先做到 40 ms 以内端到端延迟，谁就拿到下一代硬件入口门票；
    • 数据合成：NVIDIA 用 NeMo Skills 流水线 500 万条数学/代码数据微调小模型，证明“合成数据+蒸馏”可以把 671 B 模型压到 32 B 仍保持金牌水平。预计 3 个月后所有国产大模型都会标配“合成数据工厂”；
    • 版权灰色地带：Grok 推出 NSFW 动漫伴侣，直接踩进内容合规与用户留存的钢丝线；国内尚未有同类产品公开上线，但技术储备已经完成，监管沙盒随时可能打开；
    • 算力电网化：Meta 多吉瓦集群逼近 90 万户家庭年耗电，倒逼“算力-电网”协同交易试点；中国西部风光电站+液冷集装箱的“算力电厂”模式有望在年内跑出商业化样本。

七月第三周，AI行业在资本、技术与产品三条战线同步提速。资本层面，Meta启动1000亿美元算力计划，Anthropic估值突破千亿美元，AI军备竞赛全面进入重资本阶段；与此同时，Meta两周内连续从OpenAI、苹果挖角多位核心研究员，人才争夺已升级为集群级竞争。融资方面，MiniMax完成3亿美元融资，估值达40亿美元，并推出全栈Agent开发平台。

技术架构上，Google DeepMind发布Mixture-of-Recursions（MoR）新架构，推理速度提升两倍，同时实现参数共享与自适应计算，被认为有潜力替代Transformer。NVIDIA则以500万条合成数据微调，将671B模型压缩至32B仍保持金牌性能，并发布OpenReasoning-Nemotron，与Google共同押注"效率换规模"路线。国内方面，Kimi-K2、智源RoboBrain 2.0、昆仑万维AgentOrchestra同周开源，以开源策略对抗资本优势。

产品定义层面，"Agent即产品"成为本周最显著共识——OpenAI、Anthropic、MiniMax、亚马逊Bedrock同周将Agent从功能升级为独立产品SKU。Google的动作尤为密集：将Gemini 2.5 Pro引入搜索AI模式强化复杂推理，推出可进行数百次搜索并生成完整引用报告的"深度搜索"功能，正式上线AI智能拨号（由AI代替用户致电商家询问价格与服务），以及面向开发者开放支持同步音频的视频生成模型Veo3。然而，AI摘要功能的普及也带来流量隐忧——无点击搜索比例已从56%升至近69%，全球新闻网站有机流量同比下降逾25%。芯片管制方面，英伟达H20与AMD MI308同时获准对华销售，标志着管制策略转向"只卡最高算力"。
