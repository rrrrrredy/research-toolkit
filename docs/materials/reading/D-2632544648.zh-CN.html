DeepMind 三篇研究瞩目；推理方向研究频出

一、英伟达提出全新 Star Attention，10 倍加速 LLM 推理

:[color]{}当下的手机及 AIPC 中都会安装本地大模型，然而上下文长度增加，推理时的计算成本也会显著增长。最明显的一个后果就是，用户输入问题后需要等待很久才能看到结果。为此，已有多种优化方案提出，例如 Flash Attention，而 11 月 26 日英伟达提出的 [/color]Star Attention:[color]{} 机制，可用于提升 Transformer 模型在处理长序列时的效率和准确性。值得一提的是，这篇文章受到了广泛的关注，登顶 Hugging Face 每日论文榜首。[/color]

:[color]{}二、[/color]清华团队提出HiAR-ICL：基于蒙特卡洛树搜索的全新上下文学习推理范式

HiAR-ICL:[color]{rgb(63, 63, 63)} 通过引入高级推理模式到上下文学习（In-context Learning, ICL）中，扩展了“上下文”概念，使大语言模型（LLMs）具备了真正的推理能力，而不仅仅是模仿示例。借助蒙特卡洛树搜索（MCTS），HiAR-ICL 大幅拓展了推理空间，捕获了丰富的思维模式，进而确保了推理的广泛性与深度。该方法也可以看作是将思维模式作为先验信息融入到 MCTS 中，形成高效的树形搜索。相比于传统方法，HiAR-ICL 不仅在复杂推理任务中表现优异，还有效减少了计算复杂度，为未来 ICL 领域及复杂推理任务的研究提供新的思路。[/color]

:[color]{rgb(63, 63, 63)}三、Google [/color]DeepMind 用语言游戏让大模型学 AlphaGo 自我博弈

近期，一篇 Google DeepMind 的论文引发了 AI 圈的关注。研究者引入了「苏格拉底式学习」，这是 AI 中递归自我完善的一种新方法。这种方法使系统能够自主增强其能力，超越初始训练数据的限制。通过利用结构化的「语言游戏」，该技术可以为实现通用人工智能提供了实用的路线图。

在该工作中，DeepMind 提出的框架围绕封闭、自给自足的环境，AI 系统无需外部数据即可运行。要实现目标，智能体必须满足三个关键条件：反馈与目标一致，广泛的数据覆盖范围，以及足够的计算资源。这种设计促进了独立学习，为通向 AGI 提供了一条可扩展的途径，同时解决了数据生成和反馈质量等挑战。

新方法的核心是进行「语言游戏」，即智能体之间结构化的交互、解决问题并以分数的形式接收反馈。这些游戏允许人工智能进行自我博弈，生成数据并完善技能，也无需人工输入。递归结构使系统能够自主创建和开局新游戏，解锁更抽象的解决问题的能力并扩展其能力。

最终的创新在于 AI 自我改造，智能体不仅可以从环境中学习，还可以重新配置其内部系统。这样可以消除固定架构带来的限制，为超过以往的性能改进奠定基础。总之，DeepMind 的研究强调了苏格拉底式学习作为创造真正自主、自我完善的人工智能的变革性步骤的潜力。

四、stream-x 算法：解决「流式障碍」，为实现持续学习提供可能

:[color]{}自然智能（Natural intelligence）过程就像一条连续的流，可以实时地感知、行动和学习。流式学习是 Q 学习和 TD 等经典强化学习 (RL) 算法的运作方式，它通过使用最新样本而不存储样本来模仿自然学习。这种方法也非常适合资源受限、通信受限和隐私敏感的应用程序。然而，在深度强化学习中，学习器（learners ）几乎总是使用批量更新和重放缓冲区，这种方式使得它们在计算上很昂贵，并且与流式学习不兼容。研究认为批量深度强化学习之所以普遍，是因为它的样本效率高。流式深度强化学习存在样本效率问题，经常出现不稳定和学习失败的情况。这一现象称为流式障碍。[/color]

为了解决流式障碍，本文来自阿尔伯塔大学等机构的研究者提出了 stream-x 算法，这是第一类深度强化学习算法，用于克服预测和控制流式障碍，并匹配批量强化学习的样本效率。论文作者还提供了 stream-x 算法的最小实现（大约 150 行代码），感兴趣的读者可以参考原项目。

五、IC-Light 扩散模型论文获 ICLR 2025 满分评价

ControlNet 的作者张吕敏团队的「IC-Light」论文近日在 AI 顶会 ICLR 2025 的评审中获得了四个 10 分评价（满分），引起极大关注。IC-Light 工作由张吕敏团队于半年前提出，并在 GitHub 上开源，目前已获得 5.8k 的星标。近期，团队推出了适配 flux 的 V2 版本。
IC-Light 是一种基于扩散模型的照明编辑模型，可以通过文本精准控制图像的光照效果。IC-Light 的核心思路是通过 AI 合成生成的数据加上一些人工处理，以达到精确控制图像光照效果的目的，同时不改变物体本身的材质。具体来说，
① 研究者通过施加一致光传输来扩展基于扩散的光照编辑模型训练的方法，确保在保留内在图像细节的同时进行精确的光照修改；
② 研究者利用多种数据源对照明效果的分布进行建模，包括任意图像、3D 数据和灯光舞台图像，用以捕捉现实世界中复杂的照明场景；
③ 通过一致光传输的方法可以在 1000 多万个不同样本上进行稳定、可扩展的训练，样本包括来自光照舞台的真实照片、渲染图像以及带有合成光照增强的野外图像。
在实验中，研究者验证了扩大训练规模和数据源多样化可以增强模型的鲁棒性，并能提高各种与光照相关的下游任务的性能。
① 消融实验证明，在训练过程中应用 IC-Light 方法可以提高光照编辑的准确性，从而保留反照率和图像细节等内在属性。
② 定量评估中，IC-Light 在峰值信噪比（PSNR）、结构相似性指数（SSIM）和学习感知图像补丁相似性（LPIPS）等指标上表现出色，特别是在 LPIPS 指标上优于其他方法，显示了其卓越的感知质量。

此外，该工作还展示了 IC-Light 的其他应用，例如通过对背景条件的额外通道进行训练，IC-Light 可以完全根据背景图像生成照明，而无须依赖环境映射。

六、微软和芝加哥大学提出 Droidspeak 智能体通信框架

在现有的多智能体系统中，不同的智能体往往源自同一个基础模型，参数差异不大。目前智能体间的通信依赖于人类可理解的自然语言，交流方式并不高效。
① 研究者先重用 KV cache 的连续层（直到最后一层），然后复用 E-cache。针对于 E cache 在 GPU 内存、传输和计算方面产生额外开销的问题，研究者考虑了发送方和接收方放置在两个 GPU 节点上的情况，并通过 Infiniband 链路互连，优化了 E cache 的存储、传输和转换过程。

七、哈佛和滨大研究者证明 LLM 存在「自主算法共谋」现象

哈佛大学和宾夕法尼亚州立大学的研究者近日发布论文，指出基于 LLM 的 Agent 存在「自主算法共谋」现象，即在未经人类给出指令的情况下，私自和其它 AI 模型串通，以类似合谋的方式提高商品价格，实现利润最大化。

以往，企业通常基于多种约束条件来利用经典算法进行产品定价，从而给出合理且能够实现预期盈利目标的价格。在 LLM 推出后，逐渐转向使用 LLM 来进行产品定价。哈佛和宾大的研究者针对 GPT-4 等大型语言模型（LLM）在经济交易中的定价行为进行了研究。
研究者将每个 LLM 定价智能体视作一家公司，在寡头垄断环境中形成竞争。在重复的寡头垄断环境实验中，每个实验包含 300 轮测试周期，在每个周期中，由 Agent 通过提示词信息设置价格，根据所有价格实现该周期的需求，并且在周期结束时，观察该周期内所有设置的价格以及其代表的公司产品的需求。
研究者进行了垄断实验和双头垄断两种实验，通过使用不同的提示词前缀来观察智能体的定价行为。实验结果发现，
① 在垄断实验中，GPT-4 表现出色，能够快速学习并接近最优定价，而其他 LLMs 表现较差。
② 在双头垄断实验中，研究者使用 GPT-4 比较了两种不同的提示前缀（P1，强调长期利润最大化的重要性；P2，强调压价和销量）。结果显示，两种提示都导致了超出竞争价格的价格设定，但 P1 提示通常导致更高的价格，有时甚至高于垄断水平。
③ 在奖惩策略实验中，通过回归分析，研究者发现 Agent 的价格设定与其竞争对手在前一周期的价格正相关。P1 提示下的 agent 表现出更持久的定价策略和更陡峭的奖励-惩罚方案。
④ 在拍卖环境中，LLM Agent 表现出与定价 agent 类似的共谋行为。特别是，强调较低出价会导致更高利润的提示前缀时会导致 agent 出价低于其价值，从而获得更高的利润。

八、Google DeepMind 提出视频分层编辑方法

Google DeepMind 近日发布论文，提出了 Generative OmniMatte 视频分解方法，可将视频分解成多个图层进行编辑。

Generative Omnimatte，能够将视频分解为包含单个对象及其相关效果（如阴影和反射）的语义有意义的层。
① 与传统的 omnimatte 方法不同，Generative Omnimatte 不假设背景静止或需要相机姿态或深度信息，能够产生干净、完整的层，包括对被遮挡动态区域的令人信服的完成。
Generative OmniMatte 的核心思路在于训练一个视频扩散模型，以识别并移除由特定对象引起的场景效果。技术实现上，Generative Omnimatte 采用了两步流程。
① 研究者首先使用 Lumiere 微调得到「Casper」视频对象效果移除模型，从输入视频中生成一个干净的背景层和一个包含单独对象及其背景的「Solo」视频。
② 其次，研究者通过测试时优化，从 solo 视频和干净背景视频的对中重建前景层。这种方法允许在不需要改变模型输出空间的情况下，从预训练模型的特征中提取对象与其效果之间的联系。
研究者们将 Generative OmniMatte 与现有的 omnimatte 方法进行了实验比较，实验结果显示，Generative OmniMatte 方法在处理相对静止的前景对象和严重遮挡的对象时表现更好。
① Generative Omnimatte 在 PSNR 和 LPIPS 两个指标上均取得了最佳的整体得分。具体来说，在 PSNR 指标上，Generative Omnimatte 的平均得分为 38.38，LPIPS 指标上的平均得分为 0.020。

九、清华刘知远团队提出 LLM 发展新思路

近期，关于 Scaling Law 能否持续的争论不断，有人认为 Scaling Law 可能将会“撞墙”；也有观点认为，Scaling Law 的潜力远未被充分挖掘，OpenAI CEO Sam Altman 更是以一句直白的“There is no wall”回应质疑，强调扩展模型规模依然是提升性能的有效路径。这场争论引发了人们对 AI 未来发展路径的深入思考。但除了单纯追求模型规模，AI 的发展或许还有其他度量与优化的空间。近期，来自清华大学与面壁智能刘知远教授所在团队的研究人员提出了一个全新的视角——“能力密度”（Capacity Density），为评估不同规模 LLM 的训练质量提供了新的统一度量框架，为解决当前困境提供了新的思路。

十、SwiftEdit：50 倍速文本引导图像编辑

:[color]{rgb(62, 62, 62)}文本引导图像编辑技术使用户能够通过简单的文本输入，利用基于多步扩散的文本到图像模型的广泛先验进行图像编辑。然而，这些方法往往无法满足现实世界和端侧应用对速度的要求，因为涉及到昂贵的多步反演和采样过程。[/color]

:[color]{rgb(62, 62, 62)}为此，VinAI Research 团队[/color]推出:[color]{rgb(62, 62, 62)}了[/color]SwiftEdit:[color]{rgb(62, 62, 62)}，这是一种简单而高效的编辑工具，可实现即时文本引导的图像编辑（0.23 秒）。SwiftEdit 的先进之处在于它的两个新贡献：一步反演框架，通过反演实现一步图像重建；掩码引导编辑技术，利用注意力重缩放机制执行局部图像编辑。[/color]

:[color]{rgb(62, 62, 62)}大量实验证明了 SwiftEdit 的有效性和效率。特别是，SwiftEdit 可实现即时文本引导的图像编辑，其速度比以往的多步骤方法至少快 50 倍，同时在编辑结果方面具有竞争力。[/color]

:[color]{rgb(62, 62, 62)}十一、[/color]Aguvis：首个完全自主的纯视觉 GUI agent

:[color]{rgb(62, 62, 62)}图形用户界面（GUI）对人机交互至关重要，但由于视觉环境的复杂性和多变性，GUI 任务的自动化仍具有挑战性。现有的方法通常依赖于 GUI 的文本表示，这在通用性、效率和可扩展性方面带来了限制。[/color]

:[color]{rgb(62, 62, 62)}在这项工作中，香港大学和 Salesforce 研究团队[/color]提出:[color]{rgb(62, 62, 62)}了一个可在各种平台上运行的基于纯视觉的统一自主 GUI agent 框架——[/color]Aguvis:[color]{rgb(62, 62, 62)}。这一方法利用了基于图像的观察和自然语言对视觉元素的基础指令，并采用了一致的行动空间来确保跨平台通用性。为了解决以往工作的局限性，他们在模型中集成了明确的规划和推理功能，增强了其自主导航和与复杂数字环境交互的能力。他们构建了一个大规模的 GUI agent 轨迹数据集，整合了多模态推理和接地（grounding），并采用了两阶段训练管道，首先侧重于一般的 GUI 接地，然后是规划和推理。[/color]

:[color]{rgb(62, 62, 62)}通过全面的实验，他们证明了 Aguvis 在离线和实际在线场景中都超越了之前的 SOTA 方法，据介绍，它是首个能够独立执行任务而无需与外部闭源模型协作的完全自主纯视觉 GUI agent。[/color]
