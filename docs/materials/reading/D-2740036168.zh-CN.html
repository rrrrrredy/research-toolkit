12月第2周：海外进入“智能体工程化与入口争夺”阶段，国内加速“AI能力在端侧与超级入口的产业化落地”

一、周趋势总结

1.海外：从“更强模型”转向“可落地智能体体系”，平台开始抢“操作入口”

本周海外的重点是 “智能体化（Agentic）进入工程化/产业化阶段”：标准、工具接入、评测、治理、安全一起补齐，说明行业已经默认“下一代 AI”要能自己查、自己做、自己对接系统。

  • 标准与生态正在合拢：Google 推托管 MCP 服务器、甚至把 Apigee 变成“把传统 API 转成 MCP 工具”的转换器，本质是在把企业既有 API 治理（配额、密钥、审计）迁移到智能体时代；同时还强调用 IAM/Model Armor 来应对提示注入、数据外泄等“智能体新威胁”。这意味着：谁能掌控“工具可用性 + 治理默认值”，谁就更可能成为企业 Agent 的底座。
  • “研究型智能体”开始商品化：Google 发布 Gemini Deep Research 并开放给开发者、同时开源 DeepSearchQA 评测，强调多步骤检索、反复规划与补洞（缺口识别再搜索），并把能力指向 Search/NotebookLM/Finance/Gemini App 等入口产品——这不是单点功能，而是把“研究”变成平台能力，直接改写知识工作流。
  • Agent 的“扩展规律”被显性化：Google 做了 180 组受控实验提“智能体 Scaling Law/定量扩展原则”，并声称能以任务属性预测最优架构（多智能体协作结构等）。行业从“炼金术式调参”走向“可复用方法论”，会加速企业落地。

与此同时，海外还出现一个很关键的“入口争夺战”：

  • 浏览器与 XR 成为新“操作系统层”：Google 用 Disco 让标签页变 Web App，把浏览器从展示窗口推向任务执行平台；Opera Neon 直接把 AI 代理嵌进浏览器并收费；Google XR 设备矩阵把 Gemini 与现实场景融合，强调“从工具到延伸感官”。这些都在争夺一个位置——AI 不再是 App，而是你“做事”的默认界面。

最后，海外在安全、内容与商业化也给出强信号：

  • 智能体安全成为显学：Perplexity 为浏览器代理推出 BrowseSafe，强调提示注入检测、并发布基准与论文；说明“能上网能操作”的 Agent 一旦规模化，安全将像传统 App 安全一样成为标配赛道。
  • 工作流竞争超过模型竞争：Anthropic 把 Claude Code 做进 Slack，让开发任务在聊天线程内完成（读上下文、改仓库、持续同步、发 PR），直指“沟通即指令、聊天即 IDE”的新范式。
  • 内容/IP 与合规边界被重新谈判：OpenAI 与迪士尼达成授权让 Sora 生成迪士尼角色内容、同时披露“成人模式”时间表；一边是 IP 商业化加速，一边是内容分级/年龄识别成为产品能力的一部分。
  • 商业化路径仍在试探：Google 否认 Gemini 引入广告（至少当前），但这件事本身说明市场在逼问“免费入口靠什么变现”。

2.国内：从“发布模型”进阶到“把 AI 做成入口与可操作的产品”，并显著强调端侧/开源

本周国内的共性是“把能力落在具体入口（手机、输入法、办公、健康、内容生产）上”，以及“用开源 + 端侧降低生态门槛”。

  • 智能体开始直接“接管操作”：智谱开源 AutoGLM（手机操作/多步任务），同时 GLM-4.6V 把 Function Call 原生融入视觉模型，打通“看见→调用工具→执行动作”。这两件事组合在一起，其实是在把“模型能力”转成“可执行系统”，并把手机生态的入口主动权向“Agent 层”上移。
  • 输入法/语音成为新入口：智谱发布并开源 ASR 与桌面 AI 输入法，强调端侧模型、低延迟、隐私与“人设风格”；这意味着国内厂商在抢一个非常现实的高频入口：文字生产/沟通的第一触点。
  • 阿里把“千问”升级为 C 端超级入口战役：成立千问 C 端事业群，目标明确是“超级 APP + 无处不在的 AI 助手”，并计划把地图/外卖/订票/办公/学习/购物等场景接入，强调“办事能力”。这比“做个聊天机器人”更激进：它是要把 AI 变成服务编排器。
  • 多模态/语音在国内进入“工程打磨周”：Qwen3-TTS（多方言多音色）、Qwen3-Omni-Flash（音视频实时流式、多语言、System Prompt 深度可控）集中释放，说明国内在冲一个关键指标：可交互、可控、可规模化的实时多模态体验。
  • 开源正在从“科研姿态”变成“产业策略”：智谱多项开源（GLM-4.6V/AutoGLM/ASR）、蚂蚁开源 100B 扩散语言模型 LLaDA2.0，面壁开源 TTS（VoxCPM），共同指向一个事实：在国内生态里，“开源”更像是争取开发者与硬件伙伴的市场动作，而不只是技术宣言。
  • 组织/品牌重构频繁”：华为成立基础大模型部；腾讯将 Hunyuan 更名为 HY 并强调全球化命名；腾讯在线视频新技术部“用 AI 驱动内容生产”；OPPO 统一“超级小布”入口并谈 Agent-to-Agent 互联——这些都是把 AI 从研发部门推到业务中枢。

3.上周行业重点：四条“结构性主线”

  • Agent 标准化与“工具可用性”成为平台战争核心
    海外 MCP 托管化 + AAIF 基金会化，本质是在避免 Agent 生态碎片化，抢“连接层”话语权；国内则以 AutoGLM/千问超级入口等方式，抢“执行层/入口层”。两边路径不同，但目标一致：把 AI 从回答者变成执行者。

  • 浏览器、聊天、输入法、XR——AI 正在接管“人机交互层”
    从 Claude Code 进 Slack、Disco/Neon 把浏览器变成 Agent 容器，到国内输入法/手机助手/办公软件的 AI 化，行业在争夺“默认交互界面”。谁拥有界面，谁就拥有分发、数据与习惯。

  • 多模态进入“实时、可控、可嵌入”的产品阶段
    微软实时 TTS、阿里全模态实时流式、面壁/阿里/智谱在语音上密集更新；同时 Apple 视频新路线（Normalizing Flow）、Runway 世界模型把视频/物理/机器人连起来。说明多模态不再只是“生成演示”，而是走向“实时交互 + 任务执行 + 物理世界建模”。

  • 安全、治理、内容边界成为“可规模化”的前置条件
    BrowseSafe 直指提示注入与高权限会话风险；Google 把 Model Armor/IAM/审计放到 MCP 体系里；OpenAI 成人模式与迪士尼授权说明内容分级与 IP 许可会成为 AI 平台的“基础设施”。Agent 要进企业/大众，必须先补齐这些“非模型能力”。

4.其他层面：资本与算力版图在为“机器人/世界模型/推理落地”重新排兵布阵

这一周资本与硬件动作，透露出行业对下一阶段形态的押注：

  • 机器人基础模型获得超大额融资预期：软银/英伟达拟投 Skild AI，把“机器人通用大脑”当成下一条大赛道（且 Skild 不做硬件，做通用软件/模型）。这与 Runway 强调“仅语言模型不够、需要在模拟环境体验世界”的逻辑互相印证：机器人与世界模型可能成为 LLM 后的第二增长曲线。
  • 芯片/数据中心格局继续重组：英特尔拟收购 SambaNova，强调推理路线与数据流架构；同时国内外多模态实时化会推高推理侧需求（低延迟、端云协同），会进一步放大“推理算力/带宽/成本”作为竞争要素。
  • “从数字到物理”的消费级闭环开始出现：腾讯混元 3D + 拓竹让“上传照片→生成 3D→直接打印手办”变成可用产品链路，提示 AI 应用正从内容生产走向“内容—商品—制造”的闭环。
