11月第4周：海外卖“可靠性”，国内收“场景税”

一、周趋势总结

1.海外：从 “Scaling Law” 到 “ROI Law”，技术红利进入兑现窗口

  • Google 的 “Gemini 3 Pro 系统指令” 把 5% 的 Agent 成功率提升包装成 “可复制的 JSON Schema”，实质是宣告大模型竞争从炼模型转向 “炼提示 + 炼工作流”。当提示模板成为可售卖的 API 资产，意味着模型能力开始商品化，先发者可将 Know-how 固化成 “指令即服务” 。
  • OpenAI 一周内连推购物研究、多模态语音、App Directory、数据驻留 ，表面看是功能堆砌，深层是把 ChatGPT 从 “对话框” 升级为 “AI 浏览器 + AI 应用商店 + AI 结账台”。当购物流量、开发者分成、企业合规三条收入曲线同时跑通，OpenAI 的商业模型已无限逼近 “苹果税”：硬件（Jony Ive 设备）+ OS（ChatGPT）+ 分发（App Directory）+ 支付（Instant Checkout）。
  • 亚马逊 500 亿美元政府订单 + Kiro 强制内部替代 ，把 “AI 基础设施” 和 “AI 开发工具” 同时锁进 AWS 飞轮：对外卖算力、对内卖效率。第三方 AI 编程工具被踢出，等于宣告云厂商进入 “AI 工具自营” 阶段 —— 外部 ISV 若不能提供 10 倍体验差异，将被迫退居 PaaS 层，云巨头拿走一切高毛利环节。
  • Meta 与 Google 就 TPU 外采谈判 ，标志着 “AI 算力第二选择” 从英伟达单选题变成英伟达 / Google 双选题；一旦 2027 年 Meta 自购 TPU 落地，将首次出现 “非 Google 云 + Google TPU” 的混合生态，芯片销售权从 GPU 独霸走向 “GPU+TPU” 寡头共治，训练成本曲线有望再下折 15-20%。

总结：海外 AI 正在穿越 “技术 - 产品 - 商业” 三段论中的拐点 —— 技术进入工程化封装期（可复制的 System Instructions）、产品进入平台化抽佣期（App Directory、Shopping）、商业进入合规溢价期（数据驻留、政府大单）。2026 年的竞争关键词可能会是 “AI 原生收入占比”，而非 “参数规模”。

2.国内：模型红利外溢到 “硬件 + 供应链 + 专业数据”，出现三道护城河

  • 阿里 “千问” 一周千万下载 + 夸克浏览器 1.1 亿装机 + AI 眼镜 3799 元现货 ，打出 “模型即入口、入口即硬件、硬件即生态” 的组合拳。阿里把大模型塞进眼镜、浏览器、1688 供应链，形成 “端 - 云 - 货” 一体飞轮：眼镜收割流量、浏览器沉淀数据、1688 返销供应链，模型训练成本被硬件毛利和供货返佣双向摊薄，把 AI 做成 “硬件 + 电商” 的现金闭环。
  • 通义千问 “门控注意力” 拿下 NeurIPS 最佳论文并同步开源 ，意味着国产模型开始输出 “可被引用的原创算法”，而非 “复现海外架构”。Head-specific sigmoid gate 把首 token 注意力占比从 46.7% 压到 4.8%，直接改善长文外推与推理成本，Qwen 系列有望在社区争夺 “算法标准制定权”。
  • 深度求索发布 “可自验证数学模型”、昆仑万维把 430 家权威机构数据装进 Skywork、腾讯混元 3D 模型社区下载量破 300 万，显示中国厂商在 “专业数据” 与 “垂直模型” 两条暗线同时发力：数学、金融、医疗、3D 资产等场景出现 “数据 - 模型 - 工具” 一站式平台。
  • 无问芯穹 5 亿元融资 + 月之暗面 Seer 引擎把 “训练加速” 做成可售卖的中间件，国产算力缺口正被 “软件层榨油” 方式弥补；当训练加速比最高 97%，相当于把万卡集群砍成五千卡，国内云厂商瞬间获得 “平价替代” A100/H100 的杠杆，为 2026 年模型军备竞赛续命。

总结：国内 AI 竞争主线已从 “做大参数” 升级为 “做深价值链”，形成 “模型 - 数据 - 算力 - 场景” 耦合护城河。海外厂商擅长把 AI 做成软件税，中国厂商则有机会把 AI 做成 “硬件税 + 供应链税 + 数据税”。

3.其他层面：AI 购物场景爆发，流量入口战争正式开打

  • OpenAI、Perplexity、微软 Edge、亚马逊 *在同一周上线 AI 购物助手，功能高度同质化（比价、折扣、即时结账），但流量入口各不相同：ChatGPT 是 8 亿周活 “AI 浏览器”，Perplexity 用 PayPal 闭环支付，Edge 捆绑 Windows 桌面，亚马逊掌握 Prime 2 亿会员。四方混战背后，争夺的是 “AI 时代默认搜索引擎” 席位 。

  • Character.AI 切掉 18 岁以下开放聊天、转向 “剧本杀” Stories，标志着 UGC 情感陪伴赛道正式让位于 PGC 内容安全模型；平台主动牺牲 DAU 换取合规溢价，预示 “未成年保护” 将成为欧美 AI 产品默认设计，后续所有面向 C 端的情感类 AI 都必须预留内容安全预算，行业门槛被政策瞬间抬高。

  • OpenAI&Jony Ive 硬件原型落地，意味着 “AI 原生设备” 进入两年倒计时；参考 iPhone 2007 年的节奏，2027 年发布的 AI 硬件将同时颠覆手机交互与 App Store 分成模式，苹果股价隐含的 “硬件替换周期” 预期或被重估。

  • 微软开源 Fara-7B，把 “鼠标 + 键盘” 的 GUI Agent 压缩到 70 亿参数且可本地运行，端侧 Agent 成本首次低于 10 美元；一旦与 Windows 11 NPU 捆绑，即可把 “RPA+Copilot” 下沉到每台 PC，传统 RPA 厂商面临模型级降维打击。
