2.一月行业趋势

2.1.海外：Agent 操作系统化与平台主权争夺白热化

本月海外产业的核心脉络，在于 AI Agent 正从 "对话层" 下沉为 "执行层"，并在这个过程中重构计算平台的控制权。Google Chrome 推出 "自动浏览" 功能、Anthropic 通过 MCP 协议将 Claude 深度集成至 Slack/Figma 等生产力工具、Meta 以 20 亿美元收购 Manus 并计划植入 Instagram/WhatsApp，这些动作共同揭示了一个深层趋势：下一代计算平台的争夺已从移动端转向 Agent 的调度中枢。 Whoever controls the agent, controls the workflow. 头部企业正试图将 AI 能力从 "功能插件" 转变为 "基础设施层"，通过控制跨应用的工作流接口来锁定生态位。

与此同时，算力自主化与商业化阵痛并行。Anthropic 绕过 Google 云直接采购百万颗 TPU v7、xAI 自建第三座超大规模数据中心并自供能源，标志着顶级玩家彻底摆脱云厂商依赖的决心，算力竞赛进入 "架构信仰" 阶段。然而 OpenAI Sora App 连续两月下载量环比下滑 45%、启动广告测试与低价订阅方案 Go 并存，暴露出纯生成式工具在消费级市场的留存瓶颈 —— 当 IP 限制收紧、缺乏网络效应时，"工具属性" 难以支撑长期用户粘性。这迫使海外巨头加速推进 "混合变现 + 协议控制" 策略，如 Google 联合 20 余家零售巨头开源 UCP 购物协议，实质是通过制定 Agent 支付标准来复制 Android 时代的生态控制力。

2.2.国内：开源集群反攻与端侧工业化并进

本月国内 AI 产业呈现出 "开源霸权 + 场景深潜" 的双重爆发。千问模型单月下载量超越全球第 2-9 名总和、Kimi K2.5 登顶全球开源榜单、智谱 GLM-Image 登顶 Hugging Face、蚂蚁灵波一周内连发三款具身智能开源模型、商汤 SenseNova-MARS 超越 Gemini-3-Pro—— 这一系列密集动作标志着中国厂商正通过 "开放权重 + 垂直场景深度优化" 的策略，系统性挑战海外闭源模型的技术霸权。开源不再仅是技术理想，而是演变为标准制定权的低成本路径，旨在构建 Llama 之外的第二极生态。

更具战略意义的是端侧 AI 与具身智能的工业化落地。阶跃星辰完成超 50 亿融资并宣布终端装机量突破 4200 万台，小米 AI 眼镜深度集成支付宝无感支付，阿里 "真武" 芯片实现万卡集群部署并对标 H20，标志着国内 AI 应用已完成从 "技术演示" 到 "规模变现" 的跨越。与海外押注人形机器人不同，国内更倾向 "轻量级、快渗透、强整合" 的路径，将多模态能力塞进眼镜、手机、汽车等终端，依托丰富的 IoT 生态构建场景闭环。特别是蚂蚁灵波开源 200 万组真实世界深度数据、宇树科技开源 VLA 模型，旨在通过 "模型 + 数据" 双开源建立具身智能时代的 Android 生态，抢占行业标准制定权。

2.3.行业重点方面：Agent 协议层战争与架构创新临界点

本月最显著的行业级事件，是 Agent 基础设施的标准化争夺。Google UCP 与支付宝 ACT 协议虽名称不同，但本质都是为 AI Agent 跨平台执行构建 "信任与授权" 基础设施，强调 "用户最终确认付款" 的防火墙机制。这标志着行业共识：Agent 的可靠性不取决于模型能力，而取决于协议对 "权责边界" 的定义。开源项目 Moltbot（Clawdbot）获得 GitHub 76.5k stars 的现象级关注，阿里云、火山引擎迅速推出全套云服务适配，预示着 AI Agent 正从单点工具向分布式操作系统演进，通过 IM 实现 "对话即服务"（CaaS）的新范式。

另一方面，大模型架构创新进入 "后 Transformer" 探索期。DeepSeek 发布的 Engram 架构通过 O (1) 查找式记忆解耦静态知识与动态推理，腾讯 WeDLM 用扩散模型改造自回归语言模型实现 3-10 倍速度提升，Liquid AI 的非 Transformer 推理模型在手机上跑通 —— 这些创新共同指向：未来模型将分裂为 "记忆密集型" 与 "推理密集型" 双轨，而非所有任务共享同一套参数。架构创新正成为打破算力封锁、实现 "以小博大" 的关键解。

2.4.其他补充层面

地缘政治与算力韧性：特朗普政府有条件放行英伟达 H200 对华出口（限 50% 销量 + 25% 附加费），策略从 "一刀切断供" 转向 "关税 + 配额" 组合拳，这反而倒逼中国 AI 企业加速 "国产替代"。智谱 GLM-Image 全栈国产训练成功、阿里 "真武" 芯片万卡部署，短期内是被动应对，长期看可能催生 "中美双生态"。企业需构建 "可切换" 的算力韧性以应对不稳定政策。

能耗与可持续：xAI Colossus 2 成为全球首个 GW 级超算集群导致 PJM 电网 6700 万居民面临停电风险，Meta 官宣能源使用将 "成倍增长"，揭示 AI 发展的物理极限已现。未来竞争不仅是芯片性能，更是每瓦特 Token 产出率。"东数西算" 与绿色算力将从 ESG 口号变为生存底线。

人才价值重估 ：OpenAI 核心人才（如 Jerry Tworek、Andrea Vallone）流向 Anthropic 或离职创业，清华陈立杰加盟 OpenAI，苹果 AI 团队向 Meta/Google 流失 —— 显示顶尖人才的选择已从 "去哪赚钱" 转向 "去哪实现技术理想"。当大模型能力趋同，拥有特定领域架构直觉和场景 know-how 的团队成为稀缺资产，"人才并购"（Acqui-hire）进入常态化。
