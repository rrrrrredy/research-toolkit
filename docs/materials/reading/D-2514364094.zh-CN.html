市场趋势内容参考-大模型

一、核心要点

1.整体来看，大模型行业处于加速发展阶段。从行业主线上来看，大模型成本下降、多模态交互能力提升和模型推理能力的增强是下一阶段各家关注的重点。

2.从模型能力上来看，无论开源还是闭源，各家大模型的整体能力都在提升。除了头部几家（OpenAI、Anthropic、Google）的领先，其他厂商的模型能力趋近一致且在缩短与头部的距离，整体行业发展的速度在提升；同时，在语言模型之外，多模态的发展也让模型解锁了更多的能力和场景。

3.从行业活跃度来看，每个月都有新的模型、产品和技术方法涌现，诞生了诸如可灵、Cursor 这样的明星产品，各厂商也逐步探索将模型能力融入到自身产品与业务体系（支小宝、腾讯元宝、豆包）；产业界、学界以及开发者社群跟随模型能力的渐进式解锁，将大模型的应用场景扩展到了更广泛的人群。

4.模型研发范式上来看，模型研发范式从预训练的 scaling 逐渐转为了后训练的算法优化及数据的优化，这些优化其实周期会更短，更短的优化周期也会导致整体的 AI 发展节奏进一步加快。

5.从基建角度来看，从万卡集群入场券过渡到加速建设十万卡集群。以 OpenAI、Anthropic、Google、xAI、Meta 为代表的头部厂商正在加速建设十万卡集群用于下一代模型研发（xAI 已建成），各类 infra 公司在融资额和客户订单上也迎来了增长高峰。

6.从各家进展的角度来看，各家最好模型在追上 GPT-4o，且开始卷性价比模型赛道，更便宜、更低延迟的模型供给增加，能力也变得更强。

7.目前大模型行业的瓶颈主要集中在算力和数据中心建设方面。即便拥有数万张 H100 高性能计算卡，也不一定能在三个月内投入实际使用。万卡集群的互联通信难度很大，对稳定性的要求极高，同时 GPU 数据中心的能耗问题和散热需求也不容忽视。接下来两年除了研究方面的问题，最头部的模型公司和大厂会花很多的精力去解决算力和互联的问题。

二、行业趋势

1.整体趋势

1.1.综述

整体来看,6 月之后无论国内还是国外，各家的进展都不大，只有到最近 OpenAI 才发了一波有些看点的功能，剩下大家大多是以降价为主。在通用场景下，Anthropic、OpenAI 和 Google 的模型仍然领先且彼此差异较小,其他模型在通用场景下的系统性差异已经非常小了。

国内的各家动静则比海外更小，虽然几家大厂都还在小步更新模型，但可能值得一提的只有 qwen 的闭源模型更新了，融合了 qwen 开源系列的能力，终止了自己的闭源模型落后于自己的开源模型的倒挂状态。

9 月 o1 系列模型的推出会让各家又开始新一波的复刻和追赶,但对于这条路线并未完全形成行业共识。从各方信息来看,各家还是会去跟进这条路线的,只是投入度高低的问题。

从行业主线上来看，第一条主线是大模型成本的下降。在 GPT-3.5 和 GPT-4 的模型定价上都体现得尤其明显。4o 的模型设计初衷除了大家熟知的多模态之外，就是为了推理成本优化而设计的。在这基础上，甚至 4o-mini 可以再下降 33 倍的成本，这个成本下降幅度是非常惊人的。相信未来随着时间推进和工程 infra 的优化，4o 模型可能还有 10 倍的成本下降空间，很多当前模型能力下的 use case 都能迎来 ROI 打正的时刻。

第二条主线是多模态交互能力提升。在理解侧，GPT-4o 模型的发布实现了端到端的多模态能力，在语音对话和多模态能力上有明显提升的同时，降低了成本且没有降低推理能力;在视觉理解侧,没有出现多模态 unify 带来的智能涌现。视频数据的信噪比太低，在当前架构下和文本数据放在一起，并没有带来显著的多模态智能，这是多模态理解领域上需要解决的问题。在生成侧,当前视频生成的技术路线里，扩散模型是背后最主流的思想,而 DiT 是把 Transformer 的能力引入到这个思想里，来更好完成模型对全局上下文信息的捕捉能力，本质上还是扩散的思路。但 Meta 提出的 Flow Matching 则不再从这个扩散过程入手做训练，而是更暴力，直接寻找更抽象的近路，而不是一步步寻找找路过程里的脚印。

第三条主线是模型推理能力的增强。2024 年上半年，Anthropic 在 Claude 模型系列上取得了显著进展。3 月 4 日，公司推出了 Claude 3 系列，包括 Opus、Sonnet 和 Haiku 三个版本，每个版本都针对不同的应用场景和需求进行了优化。而 OpenAI 也通过 o1 系列模型的推出让各家更加重视模型推理能力这条路线。

1.2.积极进展

整体来看，大模型行业处于加速发展阶段。

①从模型能力上来看，无论开源还是闭源，各家大模型的整体能力都在提升。除了头部几家（OpenAI、Anthropic、Google）的领先，其他厂商的模型能力趋近一致且在缩短与头部的距离，整体行业发展的速度在提升；同时，在语言模型之外，多模态的发展也让模型解锁了更多的能力和场景；此外，各家模型的上下文长度从去年的 4-8k 升级为了今年的 128k 标配，甚至有 1M 和 10M 的高配版；同时，在模型能力横向拓展的角度，OpenAI 在过去一年中已推出多款产品，例如 VL、DALL-E 3、Voice、Sora、实时语音交互等。

②从行业活跃度来看，每个月都有新的模型、产品和技术方法涌现，诞生了诸如可灵、Cursor 这样的明星产品，各厂商也逐步探索将模型能力融入到自身产品与业务体系（支小宝、腾讯元宝、豆包）；产业界、学界以及开发者社群跟随模型能力的渐进式解锁，将大模型的应用场景扩展到了更广泛的人群；

③从模型研发范式上来看，模型研发范式从预训练的 scaling 逐渐转为了后训练的算法优化及数据的优化，这些优化其实周期会更短，更短的优化周期也会导致整体的 AI 发展节奏进一步加快。

④从基建角度来看，从万卡集群入场券过渡到加速建设十万卡集群。以 OpenAI、Anthropic、Google、xAI、Meta 为代表的头部厂商正在加速建设十万卡集群用于下一代模型研发（xAI 已建成），各类 infra 公司在融资额和客户订单上也迎来了增长高峰。

⑤从各家进展的角度来看，各家最好模型在追上 GPT-4o，且开始卷性价比模型赛道，更便宜、更低延迟的模型供给增加，能力也变得更强；同时，long context 在普及，总体来讲第二梯队玩家已基本能实现 128k token；此外，语音输入与输出、VL 输入、tools、json mode、context prefix cache、微调服务等能力也都在持续补齐和打磨的过程中。这些方面各家都还有追赶的空间，研发风险也相对较小，整体来看会是从 60 分追赶到 80 分的过程；另一方面，各家的优化能力也在不断提升，同样效果的模型的使用成本可预见地会持续下降。

⑥从行业应用上来看，虽然训练、推出新一代 SOTA 模型的周期在拉长，但大企业采用 AI 并没有降速。2023 年是 AI 在企业端渗透率最快的一年。在麦肯锡的调研中，AI 在企业侧的渗透率从 55% 增长到 72%，增长了 17 个百分点，如果把 AI 缩小到 GenAI 的范围，则速度更加惊人，过去一年从 33% 增长到 65%，增长了一倍。

1.3.问题和挑战

①目前大模型行业的瓶颈主要集中在算力和数据中心建设方面。即便拥有数万张 H100 高性能计算卡，也不一定能在三个月内投入实际使用。万卡集群的互联通信难度很大，对稳定性的要求极高，同时 GPU 数据中心的能耗问题和散热需求也不容忽视。接下来两年除了研究方面的问题，最头部的模型公司和大厂会花很多的精力去解决算力和互联的问题。

②从数据上看，很多公司现在都可以达到 15-20T 高质量文本数据量，每个月也可以再增加约 2T 的新数据。但很难倍数级增加数据至 50-100T ，还是需要新的方法突破数据瓶颈。

③目前看来，增加数据量比增加参数的 ROI 明显要高，但高质量的数据似乎永远不够用，各家都面临数据墙的问题。尽管现在通过合成和改写可能扩大个小几倍，但要拿出 GPT-4 十倍的数据量是很难的；另一个难题是如何把多模态数据与文本数据一起拿来训练，这是研究的问题，很容易伤害到原来的模型。

④算力角度，英伟达的 H100 现在可以做到 3.2 万张卡、充分互联的单一集群，全球有 3-5 家公司都可以做到这一规模了。但在 B 系列 GPU 被规模化采用前，算力基本上不会有倍数级别提升。

⑤从参数上看，现在最好的模型是 600-700B 总参数的 MOE 模型，这也是单台 H100 server 可以放得下的参数量。今天，我们还没有看到向上再 scale 3-5 倍、达到 2-3T 总参数的模型，如何向上做 scaling 的规律目前大家也没有探索清楚。同时，模型 scale 到 2-3T 后， MOE 就更复杂了。有一个原因是因为对 MOE 的实验还不够充分，其中的 bug 也很多。还会有一个说法是，和 MOE 相比，做 dense model 更容易。但 dense mode 也有一个缺点：训练过程中 GPU 利用率不够高。

⑥目前看到的大模型公司商业模式，要明显比互联网广告和软件订阅的商业模式差很多。后两者最重要的特征是 Ⅰ.提供服务的边际成本几乎是零，或是持续显著下降。Ⅱ.黏性/用户留存极强。意味着企业只要投入建立平台/软件产品及获客，后续收入的利润率极高，且持续性很强。大模型无论是 API 还是订阅制，定价端很难提价，而随着模型能力增强，用户 query/任务会更加复杂，服务用户需求的成本还可能是上升的。

2.技术趋势

2.1.OpenAI o1 带来的范式变化

①新的技术范式：之前的 scaling law 受限于算力和数据，导致了模型能力在一定时期内提升有限。o1 的推出让大模型具备了「系统 2」的能力，也带来了 scaling law 的新范式，即 RL scaling，业界也开始研究强化学习如何泛化的问题。同时，新的范式也会改变训练和推理的算力占比，在二者同步提升的情况下，推理的算力会更快的提升，算力有限的公司也可以通过后训练的方式取得不错的模型效果，这也会解锁更多的技术和产品空间。

②o1 带来的模型新范：

·不把提高模型规模作为新的前沿模型的卖点或必要条件；

·模型供应商可以不再按用户获得的 token 数量收费，而是可以包括其内部的动态成本，并不必向用户证明该内部成本计费的准确性；

·模型和应用对用户都可以有一个较高的请求延迟时间；

·将前沿模型的推理成本标准线再拉高 1-2 个数量级；

·模型层公司可以不提供裸模型 API，而是包括上层一些 Agent 流程之后提供一个打包的 API。

③推理速度的提升

黄仁勋在 T-Mobile Capital Markets Day 2024 会上提到，“在 Blackwell 平台上，我们通过提高 50 倍的推理性能来提升推理速度。通过将推理性能提高 50 倍，这个推理引擎，即便现在处理某个提示可能需要几分钟，也能在几秒钟内给出回应。”

现在 o1-preview 模型的 token 生成速度大约是 100 tokens/s，o1-mini 大约是 200 tokens/s，提升 10 倍就到了 1k tokens/s。现在很多 prompt 回答在 1s 之内就能完成，内部推理 10k token 也只需要 10s，用 o1-mini 还可以更快。这对于未来上层模型 inference 范式和应用层的使用方式的影响是巨大的。所以 o1 会选择这个技术路线也是看到硬件层在 inference 速度上会有大幅提升的信息。推理阶段使用更长的思考，硬件可以大幅提升推理速度，而目前暂时看不到其他可以与之竞争的方案。这套软硬件一体的技术路线的相对优势已经很大了，英伟达又可以维持自己地位一段时间了，这种能够极速推理的计算卡将会成为新的“硬通货”。

④OpenAI o1 核心特点是能够在给出回复前用更多时间进行思考，模仿人类解决复杂问题的思考方式，并且思考越久，推理任务的表现就越好。简单的来说，OpenAI o1 系列模型，在复杂推理上的性能提升模式与传统 LLM 预训练式的性能提升不同，主要通过强化学习的方式，让模型不断完善思考过程，包括对不同策略进行尝试，认识到错误等。
