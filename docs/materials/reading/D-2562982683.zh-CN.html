近期 AI Agent 趋势

一、核心要点

1.近期，微软、谷歌、Anthropic 等公司扎堆推出 AI Agent 及相关功能，使用 AI Agent 自主操控计算机、手机等智能设备成为趋势。

2.随着 LLM 等技术的进一步发展，AI Agent 的研究方向逐渐从用于处理耗费人类时间和精力的日常任务，转向能够自主监控和管理系统的下一个级别的 AI Agent。

3.但实现 AI Agent 的自主性、通用泛化能力的突破仍有距离。受限于现有 AI Agent 执行能力的局限，以及各家科技巨头、大厂的业务对于 RPA（机器人流程自动化）的需求，近期微软、Anthropic 等推出的 AI Agent 更偏向于 RPA Agent。「UI+API 自动化」成为目前阶段大幅提升 AI Agent 执行能力的重要落地方向。

4.近段时间，各家 AI 头部机构或实验室公开发布的针对 AI Agent 通用性能力突破的研究有限，主要集中在多模态模型应用于操作系统中，其在屏幕解析方面的能力。目前，自主图形用户界面（GUI）Agent 方面的研究主要分为两个方向：一是直接训练端到端模型来预测用户界面中的下一个动作；另一是利用现有的如 GPT-4V 等多模态模型来执行用户任务。以上提到的各家机构近期的相关进展基本上都属于后一种。

5.从目前各家大厂发布的用于自主操控计算机、手机等智能设备的 AI Agent 效果来看，离真正的通用性，实际能用还有一段距离。关于 AI Agent 的研究仍在早期探索中，处于 GPT-2 阶段。

二、AI Agent 的下一个方向：用 AI 操控计算机

推进自主 AI Agent 的发展是今年人工智能领域公司最重要的技术趋势之一。Gartner 预测，到 2028 年，至少 15% 的日常工作决策将通过 AI Agent 完成。微软、谷歌、Anthropic 等公司近期陆续推出 AI Agent 及相关功能，使用 AI Agent 帮助用户自主操控计算机、手机等智能设备。

① 微软近期在 Dynamics 365 业务线应用程序中推出了 10 款用于销售、运营和服务的 AI Agent，可以自动执行任务，如筛选潜在客户、监控供应商表现、管理客户意图和知识库等；同时，11 月还将在 Copilot Studio 中开启自主创建 Agent 的功能，客户可以根据自己的需求自主构建 Agent，用于处理客户查询、识别销售线索和管理库存等。

② Anthropic 近期推出了升级版的 Claude 3.5 Sonnet，该模型支持计算机使用功能，能够根据用户指令移动光标、点击相应位置以及通过虚拟键盘输入信息，模仿人类与计算机的交互方式。

③ 据 The Information 报道，谷歌也将开发可控制计算机的 AI 系统「Project Jarvis」，通过截取和解释屏幕截图，然后点击按钮或输入文本，帮助人们「自动执行日常的基于网络的任务」。

④ 此外，智谱发布了应用 AutoGLM，能让 AI 像人类一样操作电脑和手机的成果。用户可以通过简单的指令让 AutoGLM 自动完成多种任务，如阅读网页信息、电商购物、点外卖、订酒店、社交媒体互动。

使用 AI Agent 来自主操控计算机等智能设备正在成为近期科技巨头、头部创企们发力的重点方向。除了上述提到的进展，微软也推出了 Copilot Vision，可让用户与 Agent 讨论正在浏览的网页；苹果推出的 Apple Intelligence 系统将在明年实现用 Agent 了解屏幕内容并为用户跨应用程序执行操作；OpenAI 被曝正在测试可以使用 Windows 电脑的 Agent。

随着 LLM 等技术的进一步发展，AI Agent 的研究方向逐渐从用于处理耗费人类时间和精力的日常任务，转向能够自主监控和管理系统的下一个级别的 AI Agent。

① 微软研究院负责人、资深计算机科学家 Peter Lee认为，目前自主 AI Agent 的研究发展方向为能够规划和执行复杂任务、与其他 AI Agent 协作并从他们的行为中学习。需要解决的核心问题是实现 AI Agent 的自主性和协作性。

② 根据吴恩达提出的四种 AI Agent 设计模式，现有的大厂、创企推出的 AI Agent 相关落地应用或功能主要集中在工具使用方面，即 Agent 利用外部工具，如网络搜索、代码执行等，来帮助收集信息、采取行动或处理数据。

但实现 AI Agent 的自主性、通用泛化能力的突破仍有距离。受限于现有 AI Agent 执行能力的局限，以及各家科技巨头、大厂的业务对于 RPA（机器人流程自动化）的需求，近期微软、Anthropic 等推出的 AI Agent 更偏向于 RPA Agent。「UI+API 自动化」成为目前阶段大幅提升 AI Agent 执行能力的重要落地方向。

① 传统的 RPA 与 AI Agent 的主要区别：从任务类型角度来看，传统的 RPA 用于帮助使用者处理如数据输入、发票处理等自动化重复任务，AI Agent 在此基础之上，能够处理更加复杂、不可预测的认知任务；从灵活性和适应性角度来看，RPA 通常涉及预定义的工作流程，明确定义的程序或步骤，AI Agent 则是通用性，能够学习和适应新的任务或环境。

② 随着 AI 技术的发展，RPA 与 AI Agent 技术的融合成为 RPA 厂商或巨头大厂们的趋势。据 Gartner 发布的《2024 机器人流程自动化（RPA）魔力象限》报告，预计到 2025 年，90%的 RPA 供应商将整合生成式 AI 技术，进一步提升自动化的智能化水平。基于 AI Agent 技术，RPA 不是简单地遵循预定义的规则和工作流程，而是可以从数据中学习、识别模式并做出决策，能够自动执行更复杂的认知任务。

三、重点公司近期在 AI Agent 方面的动态

不管是微软、谷歌等科技巨头，还是 OpenAI、Anthropic 等 AI 创企，各家公司在 AI Agent 方面的相关研究及布局，均是为其已有或重点业务方向所服务。

不完全统计美 AI 头部公司近期在 AI Agent 方面的相关动作

①微软：面向企业客户，服务于生产力和业务流程业务板块

1）微软推出的 AI Agent 应用于其 Dynamics 365 业务线应用程序，用于销售、运营和服务，主要为企业客户服务。

2）同时，推出的 AI Agent 基于 Microsoft 365 Copilot 平台，还可以连接到多个数据源，如 Microsoft 365 Graph、Systems of Record、Dataverse、Fabric 等。

3）此外，微软的 Copilot Studio 还将在 11 月上线新功能，包括：

·自主触发器功能：让 Agent 自动响应整个企业的信号并启动任务，使其为对事件或触发器做出反应，这些事件或触发器来自各种工具、系统和数据库，可以安排为每小时、每天、每周或每月运行一次。

·动态 Agent 计划功能：让 Agent 灵活创建动态计划来处理和完成任务，每个业务流程可以有不同路径。

·活动概览功能：让 Agent 创建者访问遗忘 Agent 运行的完整日志，包括进度跟踪、区块识别、趋势分析和早期决策的审查。

由此可见，微软推出的 AI Agent 旨在服务于其生产力和业务流程业务板块，包括 Office 生产力软件、LinkedIn 和 Dynamics 等，用于帮助客户或个人简化或自动化业务流程。

同时，微软也是在 RPA 收入增长方面是最快的供应商。微软推出的低代码自动化平台 Power Automate 面向企业客户，构建在 Azure 平台之上，支持云优先、API 优先的自动化，并提供桌面自动化、IDP、任务和流程挖掘、光学字符识别（OCR）和 AI 功能。Power Automate 与微软的 Microsoft 365、Dynamics、Power Apps、Power BI 和 Edge 等生态产品高度集成，使用 Microsoft 产品的企业能够充分利用其自动化功能。

②谷歌：面向普通消费者用户，服务于搜索核心业务

1）谷歌计划开发可控制计算机的 AI 系统「Project Jarvis」，旨在通过截取和解释屏幕截图，然后点击按钮或输入文本，帮助人们「自动执行日常的基于网络的任务」，如搜索网页、购物和预订航班等。

2）但于其他家推出的跨程序、跨应用的通用性 AI Agent 不同，谷歌的「Project Jarvis」只用于 Chrome 浏览器控制，且目标用户是普通消费者，而不是开发人员和办公室职员。

3）搜索是谷歌的核心业务，「Project Jarvis」也是应用其 Chrome 浏览器。与此同时，谷歌此前在 AI 方面的进展也多是微软其搜索业务和 Android 操作系统相关。如谷歌推出的 AI 搜索服务 AI Overview，允许用户通过简化语言或更详细地调整搜索结果概述；推出的 AI 语言助手 Gemini Live 是可以在 Android 上实现双向流畅的 AI 对话体。

③Anthropic：面向开发人员/研究者，服务于聊天机器人 Claude

1）Anthropic 推出的 Claude 3.5 Sonnet 支持计算机使用功能，能够根据用户指令移动光标、点击相应位置以及通过虚拟键盘输入信息，模仿人类与计算机的交互方式。

2）Anthropic 首席产品官 Mike Krieger 表示，「预计 Claude 3.5 Sonnet 对于开展在线研究、执行重复性流程（如测试新软件）以及自动执行复杂的多步骤任务等任务特别有用。随着技术的成熟，可以用于增强数据分析、可视化和用户界面交互，从而有可能提高可访问性。」Claude 3.5 Sonnet 的计算机使用功能主要面向开发人员、研究者，利用此功能来创建新的工具和工作流程。

3）Anthropic 推出的 Claude 3.5 Sonnet 操控计算机使用功能，主要服务于其聊天机器人 Claude，通过与 AI Agent 的协作，来完成任务。官方将其形容为「一个能够‘自我推理’的自由研究员工」

④OpenAI：被曝正在测试可以使用 Windows 电脑的 Agent

OpenAI 被曝正在测试可以使用 Windows 电脑的 Agent。同时，OpenAI 研究科学家 Noam Brown 也在活动中透露，「正在 OpenAI 组建多智能体团队」。

⑤苹果：面向普通消费者用户，服务于苹果生态系统

1）苹果在 2024 WWDC 上发布了人工智能系统 Apple Intelligence，通过与苹果自有的生态系统进行深度整合，围绕语言、图像、动作，结合用户个人语境，根据用户需求将其变成 Action（动作）。

2）同时，苹果对其语音助手 Siri 进行升级，可以处理更为复杂的查询或任务。语音助手 Siri 作为 Apple Intelligence 的一大主要入口，支持文本和语音输入，同时具备了屏幕感知能力，能够分析用户当前屏幕上显示的内容，从而进一步提升其对用户个人语境的理解。

⑥亚马逊：面向企业和普通消费者，服务于 Amazon Bedrock

1）亚马逊持续在生成式 AI 方面发力，一方面是针对于其亚马逊云的完全托管服务 Amazon Bedrock，推出了 Agents for Amazon Bedrock 预览版，包含两个功能，分别为：

·一是「Memory retention for Agents」，可以在多次交互中保留记忆。Agent 可以保留与每个用户的对话摘要，并提供流畅、自适应的体验。对于预定航班或处理保险索赔等复杂的多步骤任务，可以自动化高效地处理。

·二是「Code interpretation for Agents」，允许 Agent 在安全的沙盒环境中动态生成并运行代码片段，高效地解决数据分析、数据可视化、文本处理、求解方程等复杂用例。

2）另一方面是针对于其 Amazon 移动应用，推出了名为 Rufus 的 AI 购物助手，专门针对购物场景进行了训练，能够理解并回答有关产品的各种问题。

四、AI Agent 能力突破有限：近期研究主要集中在屏幕解析方面

近段时间，各家 AI 头部机构或实验室公开发布的针对 AI Agent 通用性能力突破的研究有限，主要集中在多模态模型应用于操作系统中，其在屏幕解析方面的能力。

目前，自主图形用户界面（GUI）Agent 方面的研究主要分为两个方向：一是直接训练端到端模型来预测用户界面中的下一个动作；另一是利用现有的如 GPT-4V 等多模态模型来执行用户任务。以上提到的各家机构近期的相关进展基本上都属于后一种。

近期推出的 Claude 3.5 Sonnet、「Project Jarvis」 均是通过截取和解释屏幕截图的方式转换成结构化的元素，准确地将预期动作与屏幕上的相应区域关联起来，从而实现 AI Agent 理解并执行不同任务。

根据微软发布的 OmniParser 的技术论文，将多模态模型应用于操作系统中，实现自主操控计算机，需要屏幕解析能力。实现屏幕解析，包含两个核心能力，一是能准确地识别用户界面中的可交互图标；二是要能理解屏幕截图中各种元素的语义，并准确将预期动作与屏幕上的相应区域关联起来。

现有的方法通常依赖于能够获取屏幕元素的 DOM 信息或视图层次结构，但这种方法在执行跨平台和跨应用程序的任务时存在局限性。

OmniParser 工作的研究方向为旨在开发通用性方法，不依赖于特定平台的 API、HTML 结构或视图层次结构等额外信息，而是直接从屏幕截图中提取必要的信息以理解和预测用户界面上的动作。

此外，苹果的研究者也提出过类似研究。早前，苹果提出多模态大型语言模型「Ferret-UI」，专门针对移动用户界面（UI）的理解进行了优化，可实现对屏幕信息更好的理解与交互。

Ferret-UI 基于苹果此前开发的 Ferret 模型构建。为了适应 UI 屏幕的特点，该工作提出了「任意分辨率」（any resolution）的概念，通过对屏幕进行水平或垂直分割来放大细节，并利用增强的视觉特征。此外，研究者还收集了广泛的基础 UI 任务训练样本，如图标识别、文本查找和小部件列表等，并对这些样本进行了格式化，以便于模型进行精确的引用和定位。
