大模型行业周趋势：OpenAI动作频繁，DeepSeek热度不减，阿里、字节、腾讯齐发力

一、周趋势及市场信息

1.近期阿里将25年的资本开支上调至1000亿左右，这两天又有传闻，阿里的资本开支进一步上调到1000-1200亿；同时，阿里最近在大规模储备算力，从H20到H200，甚至B卡，基本上有多少进多少。

2.此前豆包和DeepSeek都用极快的速度达到了几千万DAU给了腾讯很大压力，但DeepSeek充分证明了后发有多“省力、省资源”，这对腾讯这种把持入口善于守株待兔做超级应用的公司是个很大机会**。在国内场景下，大厂们面向应用再去投入模型训练、推理，资本开支的利用效率、投资回报率，甚至可能还远高于北美**；同时，在腾讯元宝接入DeepSeek后，模型能力已经看齐豆包了，这对自研的混元模型团队压力也很大。

3.近期Top 3模型公司（Google、OpenAI、Anthropic）都有下一代模型的官方或者非官方新闻，DeepSeek的压力让他们罕见地同时发布了自己的下一步技术路径。

4.随着预训练的数据瓶颈愈发明显，RL+reasoning成为了新的主战场，海外Top3都投入了巨大的算力资源。下一步，为了验证多模态+合成数据+可泛化的self-play RL，势必需要更大的B卡集群，来进行足够多的实验，大量的idea都需要巨量的算力来试错。

5.短期的NV需求，实际上和DeepSeek的模型发布与否，是否采用了稀疏MoE，是否没有采用NVlink，实际上是没有特别大的关系。长期来看，NV的需求关键在于能否继续scaling law，而这一点，只有足够的算力才能够充分验证。

6.目前大模型下一步发展，主要有以下几个大的问题：

  • 合成数据能否取得突破；
  • RL能否实现真正的self-play和泛化；
  • 多模态能否对语言能力真正产生帮助；
  • 10万B卡能否带来模型训练的惊喜；
  • 模型持续1年10x以上的降本，能否带来更繁荣的应用生态。

7.推理模型成本大幅下降直接催化了Agent生态的成熟，加速国内端侧AI Agent产业进展。以智谱与三星的合作为例，Galaxy S25系列搭载的Agentic GLM正是基于类似的模型轻量化思路，这使其得以支持"实时语音视频通话AI字幕生成"、"锁屏界面长按启动AI搜索"等需要瞬时响应的Agent功能。今年“端侧小模型干大事”的逻辑会持续演绎（现在出了DeepSeek，后面可能也会有其他模型），且开源的DeepSeek使得“AI平权”，当技术代差被抹平，拥有场景理解优势的本土模型厂商将掌握定义Agent体验的话语权。

8.据说DeepSeek下一代模型也会提升不少coding的能力，看看到时候和Anthropic到底谁才是coding第一的模型。

二、海外

1.Top 3厂商下一代模型动态

**公司** **下一代模型**
**OpenAI** - **GPT-4.5：**代号为“Orion”，是OpenAI最后一个“非思维链模型”，预计将在未来几周内发布。它在数学、物理等领域表现更可靠，上下文窗口扩展至256k tokens，知识截止日期延长至2024年6月，速度和准确性全面超越GPT-4。**Orion最初被认为是可以达到GPT5的模型，但是多次预训练不达预期，最后还是当做GPT4.5发布。Orion已经用上了o1/o3产生的合成数据，不过目前还处在比较早的阶段，还没能把模型带到下一代。**
- **GPT-5：**将在未来几个月内发布，整合了包括推理模型o3在内的多项技术，具备语音、画布、搜索、深度研究等功能。它将成为一个集成模型，支持广泛任务场景，并能自主判断何时需要长时间思考。**OpenAI下一代的核心模型将是基座模型+o3的整合。不过，这个所谓的GPT5，看起来更像是多种技术的融合， Agents + GPT-4.5 + O3-Full = GPT5。**
**Google** - :[color]{rgb(0, 0, 0)}Google正在加速推进其下一代AI模型Gemini的开发，目标是超越OpenAI的GPT-4.5和GPT-5。[/color]
- :[color]{rgb(0, 0, 0)}Gemini将整合多模态能力（如文本、图像、音频和视频处理），并专注于提升推理scaling能力和上下文理解。[/color]
- :[color]{rgb(0, 0, 0)}Google计划在未来几个月内发布Gemini的升级版本，以应对OpenAI的技术竞争。[/color]
- :[color]{rgb(0, 0, 0)}Google正在研发新一代TPU5，专门为训练和运行大规模AI模型优化，将显著提升计算效率，降低能耗，并支持更大规模的模型训练。[/color]
- **单个数据中心已经不够了，Gemini已经在跨多个大城市的数据中心异步训练。Gemini 1.5已经开始使用多个大城市的计算资源，通过高速的网络连接将不同数据中心中的计算结果同步，成功实现了超大规模的训练。**
- Google正在将其AI技术深度整合到搜索引擎中，以提供更智能的搜索结果和交互体验。
**Anthropic** - **是一种“混合型”大型语言模型，同时具备“高推理模式”和“普通模式”。**
- 当面对复杂问题时，会投入更多计算资源进行推理。
- 而对简单任务则无需高推理，像传统语言模型一样快速响应。
- 尤其在coding领域，Anthropic的下一代模型被认为会是SOTA。
