类 o1 推理模型技术思路

一、核心要点

1.近期，国内大厂、AI 创企陆续发布类 o1 推理模型，DeepSeek 推出 R1-Lite 推理模型；Kimi（月之暗面）推出的主打数学能力的推理能力强化模型 k0-math；阿里先后推出 Marco-o1、QwQ 两款推理模型；昆仑万维推出 Skywork o1 推理模型。高校方面，北大、鹏城实验室发布能够自主进行多阶段推理的视觉语言模型模型 LLaVA-o1；上交大 GAIR 研究组发布 o1 复现项目。

2.o1 模型的推出将 Scaling Laws 范式从预训练带向了推理层，模型推理层的开发和规模增长也成为大模型厂商们当下的关注重点。o1 模型在数学、代码和长远规划等方面的能力取得了大幅的提升。根据其官方博客，o1 深度思考和复杂推理能力的提升归功于采用了自我对弈强化学习（Self-play RL）、思维链（CoT）等技术。但 OpenAI 并没有公开 o1 模型的具体技术细节，从各高校、研究机构的 o1 模型复现研究来看，o1 的主要技术路线为「搜索+强化学习」，即对思维链进行搜索，然后用强化学习去学习搜索的过程。

3.国内几家大厂、AI 创企陆续推出或开源了自家的推理模型。尽管部分模型称效果大幅超越/领先 o1-preview、GPT-4o，但在具体的实测中，各有优劣。
DeepSeek 的 R1-Lite 模型在 Reddit 等社交平台用户的实测中，在近期一众推出的推理模型里被认为是最接近 o1 的一个。

4.目前来看，大部分推理模型均存在的一个问题是「过度推理」。同时，并不是所有任务都有必要采用长思考或者强推理来解决。

二、类 o1 推理模型对比

近期，国内大厂、AI 创企陆续发布类 o1 推理模型，DeepSeek 推出 R1-Lite 推理模型；Kimi（月之暗面）推出的主打数学能力的推理能力强化模型 k0-math；阿里先后推出 Marco-o1、QwQ 两款推理模型；昆仑万维推出 Skywork o1 推理模型。高校方面，北大、鹏城实验室发布能够自主进行多阶段推理的视觉语言模型模型 LLaVA-o1；上交大 GAIR 研究组发布 o1 复现项目。其中，部分公司称其推理模型的效果大幅超越/领先了 OpenAI 的 o1-preview、GPT-4o 模型。

旧生成摘要（未重写，未核实）

OpenAI o1模型将Scaling Laws从预训练阶段延伸至推理层，在数学、代码和长远规划任务上实现显著突破，其核心技术路线为"搜索+强化学习"，融合自我对弈强化学习（Self-play RL）与思维链（CoT）。由于OpenAI未公开具体技术细节，目前所有复现工作均来自外部机构推断还原。

从基准测试数据来看，o1在MATH上得分85.5、Codeforces评分1428、综合末项指标73.3，全面领先GPT-4o（MATH 76.6，Codeforces 759）。DeepSeek发布的R1-Lite-Preview在首项指标上以52.5分超过o1的44.6，被用户实测认定为目前国内最接近o1的推理模型。

国内推理模型呈现多点开花态势。月之暗面的k0-math（50B参数）在MATH基准上以93.8分领跑；阿里国际MarcoPolo团队推出Marco-o1-CoT，多项指标暂未公开；阿里通义团队的QwQ-32B（32B参数）AIME得分50、MATH得分90.6、编程得分65.2，综合表现突出；昆仑万维的Skywork-o1-Open-8B体量较小，AIME得分13.3、MATH得分78.1，整体弱于QwQ-32B。此外，北京大学与鹏城实验室联合发布LLaVA-o1，上海交通大学GAIR研究组也推出了o1复现项目。

值得注意的是，当前推理模型普遍存在"过度推理"问题，长思考与强推理机制并非适用于所有任务场景，如何在推理深度与效率之间取得平衡，仍是该领域亟待解决的核心挑战。
