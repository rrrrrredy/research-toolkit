近期大模型行业重要信息202412-1

一、国外

1.Runway 推出图像生成模型 Frames

Runway 推出了他们的最新图像生成基础模型 Frames，在风格控制和视觉保真度方面实现了巨大提升。Runway 在官方博客中写道，Frames 擅长保持风格的一致性，同时允许进行广泛的创意探索。有了 Frames，你可以立即设计代表特定观点和美学特征的世界，精确地设计你想要创建的世界的外观、感觉和氛围。据介绍，Frames 将在 Gen-3 Alpha 内逐步开放访问权限。

2.谷歌云推出商用 AI Agent 生态系统计划

在微软发布 10 多个商用 AI Agent 后，谷歌近日也宣布全力推广商用 AI Agent，发布一系列激励活动和产品。谷歌云推出 AI Agent 生态系统计划，为合作伙伴提供产品支持、营销推广和联合销售机会，帮助他们更快地将 AI Agent 解决方案推向市场，覆盖更多客户并发展业务。

此外，谷歌云市场推出 AI Agent Space，简化客户选择和部署 AI Agent 的流程，同时还提供了免费试用的机会，新客户可以获得 300 美元的免费信用额度，来体验选中的产品。

3.Lightricks 发布开源视频生成模型 LTX Video

近日，AI 视频初创公司 Lightricks 发布开源、社区驱动的视频生成模型 LTX Video。据介绍，LTX Video 是第一个基于 DiT 的视频生成模型，可在 RTX 4090 等消费级 GPU 上本地运行，只需要4秒就能生成5秒时长的 24FPS 视频，分辨率 768x512。目前用户可在 GitHub Hugging Face 和 fal.ai 上获取预览模型。完整版发布后将免费供个人和商业使用，并将很快集成到 LTX Studio 中。

4.Cursor 更新 0.43 版本，推出 Composer Agent 功能

新版本最大亮点之一是推出了 Composer Agent 功能，其具有完整的项目理解 / 编辑能力。启用 Composer Agent 有两种方法：

  1. 在 Composer 聊天窗口中启用；

  2. 在 Settings > Editor > Chat & Composer 中设置「Enable Tools」选项。

除了 Composer Agent，Bug Finder 功能也是大家比较关注的， 目的是通过检测潜在的问题，帮助开发者尽早在开发过程中修复代码问题。 据了解，该功能会分析你当前分支和远程代码库中主分支之间的代码变更。官方建议是在将代码从功能分支合并到主分支之前使用此功能，以便在开发初期发现潜在问题。 目前，这一功能还处于 Beta 实验阶段 ，并且不是免费的，官方也说明了 Bug 检测仍处于试验阶段，可能无法发现代码中的所有问题，可能会损失用户金钱，却得不到任何有效漏洞，请自行承担使用风险，看来大家还是慎用此功能。

此外，Cursor 0.43 还有几项改进，包括：

  • 语义搜索：使用户可以更轻松地使用几个字符找到所需的文件，和 VS Code 的搜索方式一致；
  • image drop；
  • File pill recommendations。

5.Meta 发布多轮多语言基准 Multi-IF：覆盖 8 种语言，超 4500 种任务

近期，Meta GenAI 团队发布了一个全新基准 Multi-IF，专门用于评估 LLM 在多轮对话和多语言指令遵循(instruction following)中的表现，包含了 4501 个三轮对话的多语言指令任务，覆盖英语、中文、法语、俄语等八种语言，以全面测试模型在多轮、跨语言场景下的指令执行能力。

实验结果表明，多数 LLM 在多轮对话中表现出显著的性能衰减。例如，表现最佳的 o1-preview 模型在第一轮指令的平均准确率为 87.7%，但到第三轮下降至 70.7% 此外，非拉丁文字语言（如印地语、俄语和中文）的错误率明显更高，反映出模型在多语言任务中的局限性。这些发现展示了当前 LLM 在处理复杂多轮和多语言指令任务上的挑战和改进空间。

6.微软将开源 LazyGraphRAG

近期微软研究院发布了 GraphRAG 迭代版本——LazyGraphRAG。这个 RAG 的最大亮点之一就是成本非常低，数据索引成本只有完整版 GraphRAG 的 0.1%，同时采用了全新混合数据搜索方法，生成结果的准确率、效率等却更好，很快发布开源版本并加入到 GraphRAG 库中。

7.三星发布多模态大模型——Gauss2

近期，三星发布了最新多模态大模型 Gauss2。该模型共有三种不同的版本：Compact、Balanced 和 Supreme，能够同时处理语言、代码和图像等多种数据类型。

Compact 是一个小型模型，专为在计算资源有限的环境中而设计，例如，平板、手机、笔记本等。Balanced 模型则专注于在性能、速度和效率之间实现平衡，为多样化的任务提供一致的性能。

而 Supreme 模型则通过在 Balanced 模型之上利用专家混合技术，在训练和推理过程中显著降低计算成本，同时保持高性能和效率。

Balanced 和 Supreme 模型在生成包括英语和韩语在内的各种语言的响应以及编码能力方面，与目前可用的领先开源生成性 AI 模型相比，提供了相同或更优越的性能。此外，它们的处理速度每小时快 1.5 到 3 倍，这使得 AI 响应生成更快，减少了用户的等待时间，并更有效地处理任务。

应用场景方面，Gauss2 除了为用户提供服务之外，还为三星内部员工提供服务。包括内部编码助手“code.i”得到了升级，并被设备体验（DX）部门和海外研究所的业务部门使用。

自去年 12 月推出以来，“code.i”的月使用量增加了四倍，DX 部门约 60% 的软件开发人员现在都在使用它。

此外，三星 Gauss 门户是一个由三星 Gauss2 提供支持的会话 AI 服务，主要协助 DX 部门的员工处理各种办公任务，如文档摘要、翻译和电子邮件撰写。该服务已于 4 月扩展到海外子公司。Gauss2 还为呼叫中心员工自动分类和总结客户电话。三星表示，未来将继续扩大 Gauss2 的应用场景，几乎会覆盖所有应用领域提升用户体验和工作效率。

8.Luma 推出全新 Dream Machine 创意平台

近日，Luma 发布全新 Dream Machine 创意平台，整合图像生成模型和视频生成模型，无需输入提示词，用户可以使用自然语言与 AI 交互，进行对话式创作。官方称，全新 Dream Machine 创意平台是帮助用户把想法变为现实的“视觉思维伙伴”。该平台以Board（项目管理）和 Idea（内容生成）两大主界面为核心，提供了风格参考、角色创建、首尾帧和工作流分享等功能。

9.Anthropic 推出「模型上下文协议」MCP

近日，Anthropic 推出了「模型上下文协议」（Model Context Protocol，MCP）。

这个名为 MCP 的开放协议，目标是实现 LLM 应用程序与外部数据源和工具之间的无缝集成。因为允许 LLM 访问和利用外部资源，它的功能性和实用性都会大大增强。无论是构建 AI 驱动的 IDE、聊天界面，还是创建自定义的 AI 工作流，MCP 都提供了一种标准化的方式，来连接 LLM 与它们所需的上下文。
