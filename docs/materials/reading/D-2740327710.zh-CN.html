12月第3周：海外 Agent 平台化加速，国内入口与工作流迅速落地

一、周趋势总结

1.海外：从 “模型发布周” 转向 “Agent 平台化周”，并同时补齐三件事：开源底座、内容可信、端侧可用

NVIDIA：开源不再是 “社区姿态”，而是 “生态主权”

英伟达一边发布 Nemotron 3 系列开源模型（Nano/Super/Ultra，面向 agentic AI 与多智能体场景），一边收购 Slurm 背后的 SchedMD，把数据中心调度这一层关键基础设施也纳入自己生态版图。它的逻辑不是 “我也做模型”，而是用开源模型 + 开源调度 + CUDA 软件标准把训练 / 推理的 “操作系统层” 锁定在自家硬件最擅长的轨道上。

OpenAI：ChatGPT 正在变成 “工作流入口 + 应用商店 + 多模态创作套件”

这一周 OpenAI 的动作非常 “产品化”：

  • 图像侧推出 GPT Image 1.5，并强化“可控编辑”（添加 / 移除 / 组合 / 移位）与文本渲染，直接把 ChatGPT 变成“随身修图工作室”；
  • 分发侧推进 “应用目录 / 应用商店”，开放开发者提交应用，强调对话内完成订购、转 PPT、找房等动作，且开始探索变现路径；
  • 交互侧把 “对话分支” 扩展到移动端，让对话成为 “多线程思考 / 多工作流并行” 的容器；
  • 工具侧 Codex 支持 Agent Skills，并 “接入 Anthropic 主导的全行业标准规范”，提供技能创建 / 安装工具与官方 Skill 库。

Google：用“更便宜更快的可用模型” 把 AI 从“对话” 推到“生产系统”

Google Gemini 3 Flash 的叙事非常清晰：用更低价格、更高速度把推理能力下放并进入搜索体系，同时配套工作流构建器（Workflow Builder）把门槛继续拉低。并且 Google 在做两条“补课线”：

  • 可信与溯源：用 SynthID 做视频水印检测，并给出细化报告（检测音轨 / 视觉轨道）；
  • 端侧可用：推出 FunctionGemma（Gemma 3 270M 微调）把函数调用能力带到手机 / 边缘设备。

多模态：从 “生成” 转向 “编辑与一致性”，并开始触及 “世界 / 3D”

  • Apple 开源 SHARP：单张 2D 照片一秒转 3D 场景，强调近乎实时与空间计算想象力；
  • Luma Ray3 Modify：强调 “保留演员表演细节” 前提下的一键换装 / 换场景 / 镜头过渡，本质是把视频 AIGC 从 “重拍” 变成 “后期”；
  • Meta 开源 SAM Audio（音频分割一切声音），并预告 2026 上半年 Mango/Avocado，提到探索 “世界模型”。

2.国内：入口（微信 / 地图）+ 企业工作流（飞书 / MCP）+ 多模态（世界模型 / 视频）三线并进，全面 “Agent 化”

超级入口开始 “轻 Agent 化”：从聊天机器人到“帮你记事、帮你出行、帮你办事”

  • 微信元宝用 “一句话设置提醒”，把 agent 的第一步落在高频、低门槛、强粘性的任务（提醒 / 待办）上，且以 “好友形态” 嵌入微信对话流；
  • 千问 App 接入高德地图，直接把 “导航 + 生活服务检索 + 顺路筛选 + 新能源补能 / 限行” 做成一体化对话体验；

国内的 agent 更像 “入口改造 ”—— 不急着展示复杂推理，而是先把 AI 变成用户每天都要用的 “流程按钮”。

企业场景进入 “任务模式 + 标准化接入” 的阶段：MCP 变成组织能力的接口

飞书 aily 上线任务模式，支持定时任务、跨模块联动、企业自定义 MCP 接入，并把产出沉淀在文档 / 知识库 / 多维表格中。这不是简单 “加一个智能助手”，而是在做企业内部的Agent 编排层 ：可触达数据、可写回系统、可定时运行、可被审计（至少可追踪）。企业 AI 的胜负手越来越像 “能不能接进你的系统、跑进你的流程”。

国内多模态竞争开始 “抬升天花板”：世界模型与音画生成并行推进

  • 腾讯混元发布实时世界模型 1.5，强调可交互探索、记忆三维结构、24FPS 720P 实时生成，并开源全链路框架（数据 / 训练 / 流式推理部署）；
  • 字节发布 Seedance 1.5 pro 音视频联合生成，强调多语言方言、口型对齐、电影级运镜、15 秒长视频。

国内多模态的主战场正在从 “能生成” 转向 “能互动 / 能叙事 / 能对齐”。世界模型是更长期的方向，但短期商业化更可能先在 “可控短视频生产、广告、短剧工业化” 上兑现。

模型侧的 “效率叙事” 明显升温：快、便宜、开源、为 Agent 优化

小米 MiMo-V2-Flash 309B（激活 15B）MoE，强调 Hybrid 注意力 + 多层 MTP 加速、长上下文、面向 agent 基准、MIT 开源与低价 API。国内厂商越来越清楚：在 agent 时代，“聪明” 不够，推理吞吐、时延、成本曲线会直接决定能否进入真实业务。

3.上周行业重点：三场 “合流” 正在发生（Agent 平台化 × 多模态编辑化 × 基础设施 / 治理工程化）

Agent 的 “平台化” 开始进入实战形态

  • 海外：ChatGPT 应用生态（提交应用 / 目录）+ Skills + 多线程对话，让 agent 从 “单次任务” 变成 “可复用能力库”；
  • 国内：飞书任务模式 + MCP，把 agent 变成 “能跑在组织系统里的自动化”。

2026 年可能会出现越来越清晰的分层**：** 入口（分发）— 编排（工作流 / 技能 / MCP）— 模型（推理 / 多模态）— 执行（系统权限 / 数据写回）。谁能把这四层闭环，谁就会形成 “平台型” 壁垒。

多模态进入 “编辑与一致性” 时代，而非 “纯生成”

OpenAI 强调可控编辑与文字渲染，Luma 强调保留表演细节的改造，阿里 / 腾讯 / 字节都在推进叙事 / 交互 / 对齐。下一阶段的核心 KPI 会变成 “可控度 / 一致性 / 可迭代编辑成本”，而不仅是视觉质量。

AI 正在被迫 “工程化与治理化”

  • 内容可信：Google 用 SynthID 检测视频水印；
  • 未成年人安全：OpenAI 更新规范并强调青少年安全优先；
  • 基础设施：NVIDIA 通过 Slurm 这种关键组件补齐栈底。

AI 正从“能力竞赛” 进入 “ 可部署、可追责、可审计、可运维” 的阶段。很多产品竞争会输在治理与工程细节，而不是模型分数。
