Meta 提出的无需 Tokenizer 新架构与多模态对齐、融合的新工作

一、核心要点

1.来自 Meta 、芝加哥大学等机构的研究者近期提出了一种新型字节级大型语言模型架构 Byte Latent Transformer （BLT） ，摒弃了传统的 tokenizer 架构，直接建模原始字节流。业界评价，BLT 架构对于解决多模态模型训练中不同模态对齐、融合问题具有极大的潜在价值。

2.文本、图像、视频和音频等不同模态类型的数据呈指数级增长，而多个模态的集成可以通过利用不同模态间的互补信息，提高模型的准确性及理解复杂现实世界场景的能力。不同模态间的差异使得有效集成和利用多模态数据存在模态对齐和融合两大技术挑战。

3.在模态对齐之后，模态融合则是将对齐后的多模态信息整合到统一预测中，利用每个模态的优势来提高整体模型性能。多模态融合策略主要分为两类：模型无关和基于模型的融合。

4.模态对齐旨在解决不同模态间语义的一致性和匹配问题，建立不同模态间的语义关系，确保每个模态的表示在共同空间内对齐。

5.在模态对齐之后，模态融合则是将对齐后的多模态信息整合到统一预测中，利用每个模态的优势来提高整体模型性能。多模态融合策略主要分为两类：模型无关和基于模型的融合。

二、Meta 新工作提出无需 Tokenizer 的架构

近日，来自 Meta 、芝加哥大学等机构的新工作《Byte Latent Transformer: Patches Scale Better Than Tokens》引发了广泛关注。该研究工作提出了一种名为 Byte Latent Transformer （BLT） 的新型字节级大型语言模型（LLM）架构，通过将字节编码成动态大小的块（patches）来进行处理，patches 作为主要的计算单元。与基于标记化（tokenization）的模型相比，BLT 在保持规模的同时首次实现了性能匹配，同时在推理效率和稳健性上取得了显著提升。

BLT 无需 tokenizer 架构，通过直接建模原始字节流的方式引发了网友的热议。尤其是在社交平台Reddit 上，多位网友探讨了该架构对多模态模型训练、推理的影响。多模态模型的预训练中，对齐处理图像、视频、声音等不同模态的数据是一大难题。BLT 将字节编码成动态大小的 patches 作为计算单元，而不同模态的数据最终都能以字节的形式表现，字节级模型将在多模态数据处理方面有很大的潜力。

三、不同模态对齐、融合的难题

文本、图像、视频和音频等不同模态类型的数据呈指数级增长，而多个模态的集成可以通过利用不同模态间的互补信息，提高模型的准确性及理解复杂现实世界场景的能力。不同模态间的差异使得有效集成和利用多模态数据存在模态对齐和融合两大技术挑战。

由于不同模态往往来自不同的传感器，数据的形成方式和内部结构有很大的区别，不同模态间存在差异。因此，在大模型训练前，首先要先将文本、图像等模态转换成统一的向量形式。

① Tokenization 将文本分割成模型可以处理的 token 或子词的过程，Embedding 则将这些 token 映射到多维空间中的向量，捕捉其语义含义，使得模型能在神经网络中处理离散的 token，并学习单词间的复杂关系。

② 图像转 Emdedding 一般采用 Vision Transformer 模型进行处理，首先将图像分割成固定大小的 patches，类似于文本的 Tokenization，然后通过线性变换得到 patch embeddings。

③ 由于不同模态的向量是在不同的向量空间中学习并形成的，各自对事物的理解存在差异。由此，在多模态预训练中的目标即实现不同模态的对齐。通过训练输入和输出投影器（IP 和 OP）来实现不同模态之间的对齐，以便 LLM 主干能够有效地处理多模态输入。

模态对齐旨在解决不同模态间语义的一致性和匹配问题，建立不同模态间的语义关系，确保每个模态的表示在共同空间内对齐。

① 为了使不同的模态具有相同的语义表示，需要测量这些模态之间的相似性，同时考虑潜在的长距离依赖性和歧义。即对齐的目标是构建一个映射，将一个模态的表示与另一个共享相同语义的模态的对应表示对齐。

② 对齐分为两种类型：隐式和显式。显式对齐通常涉及使用相似性矩阵直接测量相似性，而隐式对齐通常是翻译或预测等任务的中间步骤。

③ 显式对齐直接测量不同模态之间的关系，通常使用相似性矩阵来直接测量模态间的相似性。其优点为提供了一个清晰的框架来测量相似性和建立对应关系，适用于需要明确对齐的场景，缺点是可能无法捕捉到模态间复杂的非线性关系，且在模态间存在冲突信息时可能不够灵活。

④ 隐式对齐不直接对不同模态的数据进行对齐，而是通过学习一个共享的潜在空间来改善主要任务的性能。这种方法在执行主要任务的过程中作为中间步骤，通常以潜在的方式进行。其优点是能够适应更广泛的情境，特别是涉及复杂或模糊数据关系的情况。允许模型在执行特定任务时自然地学习对齐，而不是依赖于显式的相似性测量。缺点是不如显式对齐直接和精确，不适用于在需要明确对应关系的场景。

⑤ 目前，多模态对齐面临的主要挑战包括模态特征对齐、计算效率、数据质量和训练数据集规模等。其中，如何准确对齐视觉和语言特征是一个关键任务。早期模型依赖于预训练的对象检测模型来提取视觉特征，这些特征并不专门为多模态任务设计，导致与文本特征的对齐存在困难。这种模态间的语义差异是知识转移和有效对齐的主要障碍。其次，高质量、大规模的多模态数据集获取也是一个难题，例如现有的从互联网中获取的多模态数据往往不是精确的多模态多模，常常包含不匹配或与文本无关的内容。

在模态对齐之后，模态融合则是将对齐后的多模态信息整合到统一预测中，利用每个模态的优势来提高整体模型性能。多模态融合策略主要分为两类：模型无关和基于模型的融合。

① 模型无关的融合策略包括：在模型的浅层（或输入层）将多个模态的特征拼接起来的前融合、独立训练多个模型，在预测层（最后一层）进行融合的后融合、同时结合前融合和后融合，以及在模型中间层进行特征交互的混合融合；

② 基于模型的融合策略包括多核学习和基于概率图模型的方法。多核学习作为 SVM 的扩展，通过为每个模态找到最适合的核函数来处理多模态特征，而基于概率图模型的方法则利用隐马尔可夫模型或贝叶斯网络来建模数据的联合或条件概率分布，实现模态间的融合。此外，基于神经网络的融合策略通过使用 LSTM、卷积层、注意力层等结构来设计序列数据或图像数据的复杂交互，进一步增强模型的融合能力。

③ 多模态融合是依赖于任务和数据的，现有工作中常常是多种融合手段的堆积，神经网络是目前处理多模态融合的主流方式。但多模态融合面临着诸多挑战，包括：不同模态的序列信息可能没有对齐、信号间的关联可能只是补充（仅提高鲁棒性而无法增大信息量）而不是互补、不同数据可能存在不同程度的噪声等等。

四、有关不同模态对齐、融合的新工作

1.Chameleon

① 今年 5 月，Meta 团队推出混合多模态基座模型 Chameleon，提出了一种新的单一 Transformer 架构，它可以根据下一个 token 的预测目标，对由离散图像和文本 token 组成的混合模态序列进行建模，从而在不同模态之间进行无缝推理和生成。

② Chameleon 设计为从一开始就混合模型，使用统一的架构从头开始训练，处理所有模态的交错混合，即图像、文本和代码。Chameleon 使用了完全基于 token 的表示方法，将图像和文本都量化为离散的令牌。类似于文本中的单词，允许应用相同的变换器架构来处理图像和文本令牌序列，无需单独的图像/文本编码器或特定领域的解码器。研究者将早期融合方法从开始就将所有模态投影到共享的表示空间中，允许跨模态的无缝推理和生成。

③ 此外，为了应对多模态训练中的技术挑战，Meta 团队引入了包括 QK 归一化和 Zloss 正则化在内的一系列架构创新和训练技术。

④ 在约 10 万亿混合模态 token 上完成预训练之后，Chameleon 表现出了适应广泛的视觉和语言能力，能很好地处理多种不同的下游任务。Chameleon 在生成混合模态长回答任务的表现优于 Gemini 1.0 Pro、GPT-4V 等商用模型。

2.MoMa

① 今年 8 月，在 Chameleon 的早期融合方法的基础之上，Meta 团队又提出了一种新颖的模态感知混合专家（MoE）架构 MoMa（Modality-aware mixture-of-experts），旨在解决混合模态早期融合基础模型在扩展到更大容量时面临的计算问题。

② MoMa 通过在模型架构中引入模态感知的稀疏性，有效地提高了混合模态早期融合语言模型的预训练效率。MoMa 通过引入模态感知模块来优化统一的早期融合架构，使模型能够更好地捕捉每种模态特有的特征，同时通过部分参数共享和注意力机制保持跨模态的整合。同时，研究者还提出了一种宽度扩展方法，将模态感知型模块稀疏性集成到前向模块中，从而扩展标准混合专家（MoE）架构。

③ 在 1 万亿个标记的训练预算下，MoMa 1.4B 模型（具有 4 个文本专家和 4 个图像专家）与计算等效的密集型基线相比，在预训练损失上实现了 3.7 倍的 FLOPs 节省，其中文本处理节省了 2.6 倍，图像处理节省了 5.2 倍。

3.Transfusion

① 今年 8 月，来自 Meta、Waymo 等机构的研究者提出了结合语言模型损失和扩散机制的 Transfusion 训练方法，可在单一 transformer 上无缝生成离散文本和连续图像，实现两种模态的完全集成，且不会丢失任何信息。

② Transfusion 方法结合了语言建模损失函数（下一个 token 预测）和扩散过程来训练单个 Transformer 模型，使其能够处理混合模态序列。

③ 基于该方法训练的 Transfusion 模型的主要参数属于一个单一的 Transformer，该模型处理所有序列，无论模态如何。模型采用解码算法在 LM 模式和扩散模式之间切换，以实现文本和图像的生成。在 LM 模式下，模型按标准方式从预测分布中采样 token；当采样到 BOI token 时，切换到扩散模式，按扩散模型的解码过程进行去噪，直到生成 EOI token 后切换回 LM 模式。

④ 实验表明，Transfusion 的扩展能力显著优于将图像量化并在离散图像 token 上训练语言模型的方法。通过引入特定于模态的编码和解码层，该研究证明可以进一步提高 Transfusion 模型的性能，并且甚至可以将每张图像压缩到仅 16 个 patch。

4.Zipper

① 今年 6 月，谷歌 DeepMind 团队提出了一种名为 Zipper 的新型多模态架构，由多个单模态预训练解码器模型组成，能够实现多模态生成能力。

② 相比于纯解码器生成模型能够通过预测下一个 token 生成多种模态的新序列，同时生成多模态输出的多模态模型通常通过词汇扩展实现，但存在灵活性不足和对大量跨模态数据的依赖问题。Zipper 架构可以实现在单一模态中预训练强大的纯解码器模型，然后利用交叉注意力将多个这样的预训练解码器「压缩」在一起，并利用有限的跨模态数据进行微调，实现多模态生成能力。预训练的纯解码器模型可以在新的多模态组合中灵活地重复使用和再利用。

③ Zipper 架构由两个自回归解码器 tower（或主干）组成，通过门控交叉注意力层「压缩」在一起。每个骨干使用下一个 token 预测功能分别对单个模态进行训练。Zipper 采用了模块化设计，易于扩展，可以灵活地将任意数量的单模态解码器模型组合在一起。每个单模态解码器使用自回归方式，基于下一个 token 预测功能进行训练。预训练的单模态解码器模型在 Zipper 中可以被重复使用和再利用，降低了开发新模态应用的成本。Zipper 利用交叉注意力层将不同模态的表征融合在一起。

④ 研究者通过语音到文本生成和文本到语音（TTS）生成的自动语音识别（ASR）任务测试了 Zipper 的能力。结果显示，Zipper 在处理对齐数据量有限的任务时表现出色，尤其是在 TTS 任务上，相比单解码器模型有显著的性能提升。

5.Uni-MoE

① 今年 5 月，来自哈工大、港科大等机构的研究者提出了一种基于 MoE 架构的统一 MLLM，称为 Uni-MoE，可以处理多种模态。Uni-MoE 通过特定于模态的编码器和连接器实现了统一的多模态表示，并且通过模态级数据并行和专家级模型并行实现了高效的训练和推理。

② Uni-MoE 可以利用稀疏 MoE 熟练地管理和解释多种模态。首先，使用模态特定编码器来获得不同模态的编码，并通过设计的各种连接器将它们映射到 LLM 的语言表示空间中；然后，在密集 LLM 的内部块中引入一个稀疏 MoE 层。每个基于 MoE 的块都具有一个适用于所有模态的共享自注意层、基于前馈网络 （FFN） 的多样化专家以及用于分配 token 级专业知识的稀疏路由器。通过以上方式，Uni-MoE 可以理解多种模态，例如音频、语音、图像、视频和文本，在推理中只激活部分参数。

③ 此外，为了增强 Uni-MoE 的多专家协作和泛化，研究者提出了一种渐进式训练策略，包括使用不同跨模态数据的连接器进行跨模态对齐，使用跨模态指令数据训练特定模态专家以激活专家的偏好，以及利用 LoRA（Low-Rank Adaptation）在混合多模态指令数据上调整 Uni-MoE 框架。

④ 在一组全面的多模态数据集上评估了经过指令调优后的 Uni-MoE，结果表明 Uni-MoE 在主要优势上表现出色，尤其是在多模态任务中。
