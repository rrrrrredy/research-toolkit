AI行业月度观察202512

一、整体趋势

1.12 月关键里程碑

1.1.模型/技术

  • 在公开的推理类 Benchmark 测试中，DeepSeek-V3.2 达到了 GPT-5 的水平，仅略低于 Gemini-3.0-Pro；
  • V3.2-Speciale 模型成功斩获 IMO 2025（国际数学奥林匹克）、CMO 2025（中国数学奥林匹克）、ICPC World Finals 2025（国际大学生程序设计竞赛全球总决赛）及 IOI 2025（国际信息学奥林匹克）金牌。其中，ICPC 与 IOI 成绩分别达到了人类选手第二名与第十名的水平；
  • 在 Artificial Analysis 的 Video Arena 排行榜中，Runway 的 Gen-4.5 位居第一；
  • OpenRouter 和 a16z 联合发布报告，基于 100 万亿 Token 元数据显示开源模型流量占比达 30%，中国开源模型从 1.2% 飙升至近 30%；
  • GPT-5.2 在众多基准测试中均刷新了最新的 SOTA 水平；
  • GPT-5.2 API 上线首日调用量破万亿；
  • 截至 2025 年 12 月，豆包大模型日均 token 使用量突破 50 万亿，较去年同期增长超过 10 倍；目前已有超过 100 家企业客户累计 token 使用量超过 1 万亿；
  • Gemini 3 Flash 在 SWE-Bench Verified 测试中获得 78% 分数，超越 Pro 版的 76.2%，且速度是 2.5 Pro 的 3 倍，Token 消耗量减少 30%；

1.2.产品/用户/收入

  • 灵光上线两周创纪录，闪应用数量突破 330 万；
  • 智谱模型销售年经常性收入已超 1 亿元；
  • OpenAI：ChatGPT 目前每周为超过 8 亿用户提供服务；
  • 千问公测 23 天，月活突破 3000 万；
  • ChatGPT 登顶 2025 年美国 iPhone 免费应用榜首；
  • 蚂蚁阿福下载量飙升，冲上苹果 App Store 总榜第三；
  • Manus 达 1 亿美元 ARR 里程碑；
  • 豆包日活用户数突破 1 亿；
  • 灵光闪应用创建量突破 1200 万。

2.12 月行业趋势

2.1.海外：从“更强模型”全面转向“可执行的 Agent 系统”，协议化与工程化一起加速

12 月海外最核心的变化，是竞争焦点从“模型能力领先”转向“Agent 化产品 + 工具连接标准 + 推理系统工程”的组合战。

第一，Agent 正在从产品形态升级为“平台能力”，而平台的关键不再是 UI，而是“工具接入与治理”。
Google 明确把平台做成 “agent-ready”：通过托管 MCP 服务器，把 Maps、BigQuery、Kubernetes 等变成智能体可直接调用的工具端点，并且把 IAM 权限、审计日志、注入防护等治理能力一起打包上来——这意味着企业做 Agent 的门槛正在从“写连接器”变成“接入受控端点”。与此同时，Linux 基金会牵头的 Agentic AI Foundation（AAIF）把 MCP、AGENTS.md 等基础组件纳入中立组织，传递的信号是：智能体基础设施正在走向“协议化/标准化”，避免被少数平台锁死。海外的“护城河”不再只是更强的模型，而是“标准 + 工具市场 + 治理体系”。未来企业采购的不一定是某个模型 API，而是能否买到一套可审计、可控、可复用的 Agent 基建栈。

第二，“推理”进入成本与体验约束：长思考不再无脑堆，低延迟与能效成为硬指标。
一条线是模型侧对推理能力的继续拉升（更强 reasoning、更复杂任务），另一条线是对“思考长度/响应时间/Token 成本”的反向约束——12 月很多动作都在告诉市场：推理不是越长越好，而是要在可靠性与成本之间找到工程最优解。对应到硬件与系统层面，AWS 推 Trainium3 强调性能与能效、并向更大规模集群推进；NVIDIA 引入 Groq 的低延迟推理能力，指向“实时推理负载”的系统补齐。2026 的主战场大概率是“推理时代的 AI 工厂”：吞吐、时延、成本、调度、可观测性会像云计算时代的 SRE 一样，成为决定体验与利润的关键变量。

第三，多模态（尤其视频）从“能生成”进入“可控叙事与工业化生产”。
Runway 等强调物理规律、动作、镜头控制与一致性，国内外都在往“可用素材”逼近：这意味着视频生成正在从 demo 走向生产链路，竞争维度也从“画质”变成“可控性 + 工作流适配”。内容生成赛道的下一轮赢家，往往不是“最会画”的，而是“最能融入制作流程”的：一致性、分层编辑、镜头语言、资产管理、版权与溯源，会决定是否能进影视/广告/电商真正的生产体系。

第四，开发者侧进入“多 Agent 协作工具链”阶段。
12 月海外出现明显趋势：代码与生产力工具从“一个 Copilot”演进为“一个能编排多个角色的协作环境”（IDE/插件/任务模式/Artifacts 归档），并且越来越强调权限、回滚、审计、可重复执行。AI 编程的终局不只是更会写代码，而是把研发流程产品化：需求分解、代码生成、测试、Review、发布、回滚、合规，都会被纳入同一套 Agent 化流水线。

2.2.国内：超级入口与产业落地提速，“Agent OS + 行业智能体规模化”成为主旋律
12 月国内的主线是：一边争夺“入口/操作系统”，一边把智能体推到真实组织与业务指标里。
第一，入口竞争升级：从 App 竞争走向“OS 级/平台级”竞争。
阿里成立千问 C 端事业群，把千问、夸克、AI 硬件、UC 等整合，目标非常明确：做超级 App，并把生活服务与多终端覆盖接进来；钉钉发布 Agent OS + DingTalk Real，把企业智能体从“软件功能”推向“可部署的工作智能系统”（甚至给出“从卖功能到卖结果/按效果定价”的商业信号）。腾讯则在组织层面强化大模型与 Infra/数据/计算平台的耦合，并把关键角色直连最高决策层，说明大厂在把“模型”当作公司级基础设施来建设。国内的优势路径更像“超级入口驱动的应用规模化”。谁能把“用户触达 + 工具调用 + 数据闭环 + 权限治理”做到一体化，谁就更容易把智能体变成稳定留存与可计费的生产力。
第二，模型侧的关键词是“推理 + 工具调用 + Agent 训练方法”。
DeepSeek V3.2 强化 Agent 能力并把“思考推理”融入工具使用，强调在复杂任务上既要强推理，也要可执行；腾讯混元 2.0、字节（Vidi2、机器人 RL）等也都在沿着“推理/工具/执行”链路持续加码。国内模型竞争正在从“通用能力”转向“端到端可用性”：能否稳定调用工具、能否在多环境中泛化、能否在成本可控下完成任务，正在变成比单点 benchmark 更重要的指标。
第三，多模态与视频在国内进入“平台化供给”：不仅要生成，还要剪辑、理解、结构化。
字节 Vidi2 把视频理解、检索、脚本生成与剪辑能力往“内容生产工具”方向推；阿里万相持续迭代并在产品侧接入；快手、生数、商汤等也在各自生态里把生成能力产品化。国内内容生态强、场景密集，视频模型更容易走出“端到端闭环”：模型不止输出视频，而是输出可直接上架/投放/分发的内容资产。
第四，产业落地出现“规模化运营指标”，智能体开始被当成组织资产管理。
典型如零售企业构建数百个智能体覆盖多部门、数万员工使用、百万级对话——这类数据意味着企业侧正在从“试点”进入“运营阶段”：要开始算 ROI、算覆盖率、算渗透率、算流程缩短与人效提升。To B 的胜负手会从“模型效果”转向“组织落地能力”：流程重构、数据治理、权限与审计、交付与运维，决定能否从项目走向规模化续费。
第五，生态摩擦在 12 月显性化：当 Agent 试图“跨 App 执行”，平台边界会迅速收紧。
豆包手机助手工程机展示跨 App 操作后，出现部分应用拒绝登录/触发风控提示的现象，银行金融类 App 也对屏幕共享/助手能力更敏感。国内 Agent 落地的隐形门槛不是“能不能做”，而是“生态允不允许”。未来跨 App Agent 必然走向：更严格的系统级权限、更细粒度的动作沙箱、更标准化的调用接口，否则就会不断撞上平台风控与合规红线。
