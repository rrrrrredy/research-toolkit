1 月第 5 周：海外平台级 Agent 生态卡位，国产开源反攻与工业化落地并进

一、周趋势总结

1.海外：AI Agent 从 "对话层" 下沉至 "执行层"，平台主权争夺与商业化阵痛并存

本周海外产业呈现出 "Agent 操作系统化" 的关键转向。Google 与 Anthropic 正将 AI Agent 从应用层锚点转变为基础设施层：Chrome"自动浏览" 功能标志着浏览器从信息检索工具进化为可执行复杂在线任务的代理操作系统，而 Claude 通过 MCP 协议深度集成 Slack、Figma 等生产工具，实质是在构建跨应用的 "Agent 中间件标准"。这种趋势揭示了一个深层洞察 —— 下一代计算平台的控制权争夺已从移动端转向 AI Agent 的调度中枢， whoever controls the agent, controls the workflow。

Meta 的策略更具侵略性，其 20 亿美元收购 Manus 并计划植入 Instagram/WhatsApp，配合高达 1350 亿美元的年度 AI 资本开支，显示出社交巨头试图通过 "超级应用 + 垂直 Agent" 的组合拳，将 AI 能力转化为平台垄断的加固材料。值得注意的是，Meta 在意大利监管压力下被迫对第三方 AI 机器人开放 WhatsApp API，但设置的 0.069 美元 / 条消息的计费门槛，实质是以合规成本为名的平台税，这种 "伪开放" 策略可能成为全球平台治理的模板。

更深层的结构性信号来自人才与资本的极化流动：特斯拉向 xAI 注资 20 亿美元，而苹果 AI 团队却出现向 Meta、Google 的离职潮，表明在基础模型军备竞赛中，算力承诺与模型迭代速度已成为人才择校的核心指标。与此同时，OpenAI Sora App 连续两月下载量下滑（1 月环比 - 45%）暴露出纯生成式 AI 工具的消费级瓶颈 —— 当 IP 限制收紧、社交属性缺失时，用户留存率急剧衰减，这迫使 OpenAI 加速推进迪士尼合作等版权外交，也验证了 "工具属性易获客，网络效应难建立" 的残酷现实。

科研与高阶自动化则成为技术溢出的新出口：OpenAI Prism 整合 LaTeX 科研工作流，斯坦福 TTT-Discover 提出测试时强化学习替代传统搜索，显示头部实验室正将竞争维度从 "模型参数 Scaling" 转向 "推理时计算范式的革新"。

2.国内：开源生态爆发与具身智能数据层竞争并行，端侧商业化进入兑现期

本周国内 AI 产业呈现 "开源集群反攻 + 具身智能基建 + 端侧规模落地" 的三重奏。

开源大模型系统性突围：月之暗面 Kimi K2.5 登顶全球开源榜单，海外收入首次超越国内；阿里开源 Qwen3-ASR、推出 Qwen3-Max-Thinking 对标 GPT-5.2；商汤开源 SenseNova-MARS 超越 Gemini-3-Pro；蚂蚁灵波一周内连发 LingBot-Depth、LingBot-World、LingBot-VA 三款具身智能模型。这标志着国内厂商正通过开放权重 + 垂直场景深度优化的策略，挑战海外闭源模型的技术霸权。

具身智能进入 "数据层" 竞争：蚂蚁灵波不仅开源模型，更计划开放 200 万组真实世界深度数据；宇树科技开源 UnifoLM-VLA-0 视觉语言动作模型。这种"模型 + 数据" 双开源的模式，旨在建立具身智能时代的 Android 生态，通过降低开发者数据获取门槛来抢占行业标准制定权。

端侧 AI 商业化进入兑现期 **：**阶跃星辰完成 50 亿融资并宣布终端装机量突破 4200 万台，日均服务 2000 万人次；小米 AI 眼镜深度集成支付宝无感支付。这些数据显示， 国内 AI 应用已完成从 "技术演示" 到 "规模变现" 的跨越，特别是在移动终端和可穿戴设备的本土化场景渗透上形成差异化优势。

3.上周行业重点：Agent 基础设施标准化与多模态生成工业化

Agent 基础设施标准化是本周最显著的行业级事件。开源项目 Moltbot（原 Clawdbot）获得现象级关注（GitHub 76.5k stars），阿里云、火山引擎迅速推出全套云服务适配，MiniMax M2.1 与 Clawdbot 深度绑定。这预示着AI Agent 正从单点工具向分布式操作系统演进，通过 IM（即时通讯）作为交互入口，实现 "对话即服务"（CaaS）的新范式。相比海外依赖单一平台（如 ChatGPT Apps 或 Claude 集成），国内通过开源生态快速形成去中心化的 Agent 网络，可能催生出更灵活的 B 端自动化市场。

多模态生成进入 "工业化生产" 阶段 **：**生数科技 Vidu Q3 实现 16 秒音视频直出、多镜头自动切换；快手可灵 3.0 引入智能分镜系统；腾讯混元图像 3.0 引入思维链机制实现 "先思考后修图"。这些产品的共同点是从 "生成单张图片 / 片段" 转向 "生产完整叙事内容"，支持多角色、多机位、声音同步的复杂影视工业化流程。这标志着 AI 视频生成开始从玩具级应用向专业影视工作流渗透，对传统影视后期制作链条的替代效应将加速显现。
