# Showcase assets

These visuals use the historical AI customer-service report preserved at commit `d08dc2d488fb7f00c173d3388cd0841fca1fa09e`. The underlying diagnostic files are unchanged.

- `readme-preview.*.png`: typeset previews with shortened, labeled report excerpts.
- `research-method.*.png`: captures of the method section on the showcase page.
- `case-walkthrough.mp4` and `.gif`: a recording of the actual case browser, not a recording of an agent completing research.
- `social-preview.png`: 1280 x 640 image for link previews. The Pages Open Graph metadata points to it. Setting GitHub's repository social preview is a separate repository setting.
- `case-study.json`: source paragraphs, pinned line links, bilingual excerpts, and explanations.
- `starter-prompts.json`: bilingual requests adapted from the case brief.

English report excerpts are translated and shortened. Chinese excerpts are shortened where labeled. This case illustrates review and revision; it is not evidence of a measured toolkit-versus-baseline improvement.
