# Showcase assets

These visuals use the historical office-agents report from September 2026. The case archive retains the complete original Chinese draft and revised report, with artifact provenance, source records, and a review summary.

- readme-preview.*.png: the project wordmark and an excerpt from the revised office-agents report. Desktop composition: 840 px; mobile composition: 360 px. Each language has light and dark variants, exported at 2x.
- research-method.*.png: the five-stage method outline. Linked historical artifacts illustrate the method without implying that the case used the current MCP implementation.
- case-walkthrough.mp4 and .gif: English recordings of actual case-browser interactions. The .zh-CN variants show the Chinese page. They begin with real prose and structure edits, then show product questions, the three interpretation views, and copying a research request. The recording does not show an agent conducting a new study.
- social-preview.png: a 1280 x 640 preview with the project identity, toolkit positioning, and translated office-agents report excerpt. Pages Open Graph metadata uses this image; GitHub's repository social preview is a separate setting.
- case-study.json: four bilingual revision examples: prose, process narration, product lineage, and model supply with original Chinese excerpts (translated and labeled in English), change descriptions, reasoning, and decisions from retained author checks and adjudications. Links point to source passages and retained intermediate extracts. Decorative ordinals are omitted.
- starter-prompts.json: bilingual requests adapted from the case scope.

Information cutoff: September 9, 2026. Some dynamic documents were checked on September 10. The complete English report is a translation of historical research. The report contains no installed-product testing, and the revision record is not a controlled toolkit/baseline experiment or evidence of a measured general quality improvement.
