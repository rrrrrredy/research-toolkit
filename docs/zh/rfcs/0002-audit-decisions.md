# 重复意见怎样裁定

[设计决定](README.md) · [English](../../en/rfcs/0002-audit-decisions.md)

四位评审可以同时发现一个遗漏，也可以对同一个日期作出同样的误判。工具给每条意见保留编号和位置，审计 Agent 对照原文决定哪些可以合并。一组只写一次判断、理由和依据，每条原意见仍可追踪。

审计脚手架预填身份、稿件版本和应答项，判断留给 Agent。最终复查先独立阅读改稿。影响结论且仍有分歧的问题可另派独立核查。复查通过便交付。
