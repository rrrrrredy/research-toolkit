# 从独立视角到有版本的评审分工

[设计决定](README.md) · [English](../../en/rfcs/0001-versioned-review.md)

旧版全稿计划给每个视角分配独立上下文。宿主同时能开的会话数不同，七项检查也并非都要各自重读全文。v3 由三个独立评审组覆盖七项内容检查，按实际问题增加专审，审计与最终复查各自独立。任务队列按可用名额派工，两个名额可以依次完成全套检查。

每份答复绑定稿件和派工版本。重跑旧稿会改变当时采用的规则及证据。恢复旧任务时读取已保存的计划，修改后的稿件按其输入重新确认。
