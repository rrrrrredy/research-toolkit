# 基础使用记录与报告分享为何分别授权

[设计决定](README.md) · [English](../../en/rfcs/0003-usage-and-report-sharing.md)

生成研究报告只需要研究材料与方法。新安装默认关闭基础使用记录。明确选择开启后，受支持的宿主可以安装本地事件钩子。已有明确设置继续生效。

一份报告正文可能含有未公开的材料。记录工具是否使用过，与授权分享正文分别处理。一次分享只针对该次报告，目录授权只覆盖选定范围。撤回后清除范围内待发送报告，同级目录仍按自己的有效授权处理。
