# 版本与兼容性约定

[English](compatibility.md) | [简体中文](compatibility.zh-CN.md)

Research Toolkit 1.0.0 确立 Skill、CLI、MCP 服务与打包插件的公开兼容性基线。本版沿用 v0.2.7 的运行行为；从 v0.2.7 升级，无需迁移任务数据或重新执行模型评测。

## 1.x 内的兼容性

- **公开接口**：[使用指南](usage-modes.zh-CN.md)记载的 CLI 操作、MCP 工具及其公开参数、配置变量、返回字段和退出码含义保持兼容。可以新增可选输入、工具和返回字段；客户端应忽略不认识的可选返回字段。删除或重命名受支持接口、改变已有字段类型或含义、新增必填输入，均属于不兼容变更。
- **已有任务**：受支持的任务目录、已保存的档位／评审选择及带版本的记录，继续按记录中的契约读取和使用。升级保留报告、评审和执行历史；任务输入改变时，已有的新鲜度与修订规则继续适用。以后若有不兼容的数据变化，应随主版本发布迁移说明。
- **安装环境**：1.x 保留 CLI 和本地 MCP 服务对 Python 3.10 的支持、`research-toolkit` Skill 名称和文档中的软件包入口。提高最低 Python 版本或移除受支持入口，属于不兼容变更。宿主应用和模型服务仍有各自的兼容要求。

内部 Python 辅助函数和诊断文案可以调整。研究方法、案例及来源材料可以持续改进，同时遵守上述公开接口和任务数据约定。修复可以拒绝文档契约原本就不允许的输入。分工、评审输入或验收变化时，针对受影响部分复验；仅调整版本号无需新增模型运行。

## 版本号与更新

采用[语义化版本](https://semver.org/lang/zh-CN/)：

| 版本 | 变化 |
| --- | --- |
| `1.0.1` | 兼容的问题修复、说明澄清和打包修正 |
| `1.1.0` | 兼容的新增功能；已标记弃用的接口在整个 1.x 内继续支持 |
| `2.0.0` | 与上述约定不兼容的变化，说明受影响接口及迁移步骤 |

更新完整软件包并保留本地任务数据。根目录 `VERSION`、两份插件清单、插件内版本、中英文更新记录与发布说明须一致。发布前执行已有发布检查和 CI。已发布标签及历史评测记录保留原有版本身份。`agent-trajectory-data` 仓库沿用自己的发布序列；Toolkit 1.0.0 不重新编号数据集。
