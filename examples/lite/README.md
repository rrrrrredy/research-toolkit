# A first Lite report: choose a helpdesk trial

[English](README.md) · [简体中文](README.zh-CN.md)

Use two fictional plan notes to recommend a trial for a six-person support team: a $35 monthly subscription ceiling, weekly CSV export (manual is acceptable), and optional single sign-on. No topic selection, live search or reviewer account is needed.

| File | Purpose |
| --- | --- |
| [start.en.json](start.en.json) | Complete English brief; requests a 350–500 word report. |
| [sources.md](sources.md) | Two fictional source notes for that brief. |
| [start.zh.json](start.zh.json) | Equivalent Chinese brief; requests 600–900 Chinese characters. |
| [sources.zh-CN.md](sources.zh-CN.md) | Chinese source notes. |

Copy the request in the [Lite quickstart](../../docs/quickstart-lite.md). The agent reads `SKILL.md`, uses `profile=lite`, registers sources and claims, drafts sections and completes the six-item checklist. Allow about 5–15 minutes with your agent ready.

Keep the report, source/claim records and checklist separate. With local workflow tools, save them in the task folder outside the toolkit; the quickstart provides the CLI commands. In chat, return those three parts separately and export them for reuse.

The recommendation must respect the budget, explain six-seat arithmetic, and retain unknown CSV fields and other limitations. These are fictional teaching materials, not vendor facts or evaluation results.

For a complete report using public sources, see [APIs or browsers for AI agents](../../docs/case-study/api-or-browser/README.md) in native English or the [office agents case](../../docs/case-study/office-agents/README.md) in Chinese.
