# Research example: choose a helpdesk trial

[English](README.md) · [简体中文](README.zh-CN.md)

Use two fictional plan notes to recommend a trial for a six-person support team: a $35 monthly subscription ceiling, weekly CSV export (manual is acceptable), and optional single sign-on. This bounded example uses the shared research methods; its short length follows this brief, not a separate research mode. The directory name is retained for existing links.

| File | Purpose |
| --- | --- |
| [start.en.json](start.en.json) | Complete English brief; requests a 350–500 word report. |
| [sources.md](sources.md) | Two fictional source notes for that brief. |
| [start.zh.json](start.zh.json) | Equivalent Chinese brief; requests 600–900 Chinese characters. |
| [sources.zh-CN.md](sources.zh-CN.md) | Chinese source notes. |

Use the [research quickstart](../../docs/quickstart.md) with the supplied start request. The agent reads `SKILL.md` and the methods relevant to the question, develops the comparison and follows the shared review and delivery instructions. The request does not select a research profile.

Keep the report separate from source, claim and review records. With local workflow tools, save them in the task folder outside the toolkit; the quickstart provides the CLI commands. In chat, retain the report and supporting records separately for reuse.

The recommendation must respect the budget, explain six-seat arithmetic, and retain unknown CSV fields and other limitations. These are fictional teaching materials, not vendor facts or evaluation results.

For a complete report using public sources, see [APIs or browsers for AI agents](../../docs/case-study/api-or-browser/README.md) in native English or the [office agents case](../../docs/case-study/office-agents/README.md) in Chinese.
