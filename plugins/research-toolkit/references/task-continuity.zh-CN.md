# 接续已有研究任务

[English](task-continuity.md) | [简体中文](task-continuity.zh-CN.md)

新材料、变更指令、比较或修订到来时，沿用已有任务。另存报告不代表重新研究。保留原件，继续受影响的工作。

## 项目入口

从原始请求与当前有效要求、提纲和稿件、相关来源、完整研究成果及未完成工作恢复。纯 Skill 使用已有宿主对话和文件，工具管理任务通过 `status` 取得这些信息。完成摘要不能证明现稿满足需求。

新指令替换冲突的旧指令，未取消的目标继续有效。已标为满足的要求仍约束后续分析和改稿。范围变更保留用户实际决定；接受反馈不等于已修好报告。

要求明确只适用于指定研究单元时，在该要求的可选 `unit_ids` 中保留归属；未填或空列表表示全局要求。全部有效要求仍可读，单元版本只绑定全局要求及适用于本单元或实际上游的要求，使局部变更不影响无关分支。不能根据措辞、执行者或本次选读哪些要求推断适用范围。

## 恢复与保存

工具管理任务的 `research_status.current_work` 包括有效要求、未完工作、范围决定、显式选定主稿、已登记成果和上次交付引用。`status.work` 为当前任务准备相关原件与输入版本，使用返回文件和记录，不按最新文件名猜测。

通过 `research_save` 更新受影响字段和记录。`brief` 局部更新保留规格中手工增加的章节，并一致更新已保存需求。稳定要求编号连接补充指令与已有工作。直接编辑与已存需求冲突时，核对该冲突再保存，不覆盖无关内容。

指定主稿写入者用 `draft.main=true` 登记报告，其他研究者保存独立成果。`complete=true` 只标记完整草稿，不是整项交付。成果保留输入、依赖、真实宿主身份和简短交接；修订时保留此前内容。来源或要求变化时检查实际依赖的论证，不自动重写所有分支。

来源／主张记录与本地完整原件继续可读，包括反证。记录版本帮助确定实际变化。摘要不能替代必需原文阅读，也不能替代支撑判断的完整分析。

## 交接与上下文压缩

交接包括不同 Agent 之间，也包括同一 Agent 的阶段切换。当前上下文已有必要内容时直接复用；交接或压缩时保留：

- 实际问题、有效指令与工作提纲。
- 完整成果、成立的判断与条件、原始来源位置。
- 当前稿件／版本、依赖、未决问题及下一项具体动作。
- 原始评审、必要修正、独立处置及真实宿主执行引用。

这些信息可以随现有成果以简短说明保存，不是第二套台账。完整文件和原始回复继续保留。接收者在使用前阅读相关完整成果，需要理解或修订判断时打开原始来源。

重要变化明确发给受影响的宿主 Agent；启动快照不会自动包含后续消息。宿主支持时接续原任务，否则把完整可复用产物与新输入交给后续上下文。宿主负责通知和运行恢复，Toolkit 保持研究输入与成果的关联。

## 选择复核范围

全文比较须阅读两份当前文档的指定范围，摘要差异只是线索。有效基线上的局部修订须查看完整 diff、改动及上下文、受影响来源和要求、未结发现。评审者取得当前完整成果和具体变化范围；局部复核不能改称新的全文审阅。缺失的基线覆盖须实际补读。

独立审阅使用分开的宿主原生上下文。所有生产身份与七项基础视角、领域专审、审计者和最终验收者分离。导入宿主结果时保留真实执行身份、原始回复和具体任务，不编造历史执行细节，不把旧 PASS 复制到新版本。

原独立评审者核查受影响变化；审计者核查争议、重要不修改决定和修正；最终验收阅读当前全文。职责按[角色方法](subagents-and-review-loop.zh-CN.md)执行。协调者或作者不能仅更新状态就关闭必要发现。

## 删改时保留分析

删除重复时保留日期、预测性质、实验条件、主体和来源限制；有用比较、计算、机制与反证进入改文。要求变化只改变依赖它的判断，其他有效结论继续保留。事实、推断和建议在段落、表格与结论中保持一致。

使用用户实际要求的形式与风格。决策研究保留选择、理由与改判条件，解释性研究保留使解释成立的关系。不把每次修订都变成建议，也不套通用报告模板。

## 恢复手工或历史项目

阅读现有请求、有效变更、完整成果和未结反馈。按内容与用户决定解决矛盾引用，不按文件时间判断。显式选择主稿，只修复继续工作所需记录并保留原件。不推断未观察到的来源阅读，不补造旧执行回执。

已完成旧任务保留原成果、标签和完成依据。继续研究时复用有效材料，补齐当前独立审阅、审计和验收责任；旧作者清单仍是作者清单。参见[历史任务兼容](../docs/usage-modes.zh-CN.md#历史任务兼容)。
