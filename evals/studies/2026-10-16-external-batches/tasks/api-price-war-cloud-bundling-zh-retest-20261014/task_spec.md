# Research brief

## question

大模型 API 降价潮下，云厂商捆绑销售对独立模型公司毛利的挤压到了何种程度？商业战略上应如何应对？

## audience

独立模型公司与云生态的商业战略负责人，需要可执行判断而非市场八卦。

## scope

仅用任务附带合成来源包（披露为合成）；覆盖 2024–2026 价格战与捆绑条款、毛利与分销渠道证据；不做实时联网；不复用仓库原「模型价格战」case 题面原文。

## output

final.md，约 2500–4500 非空白中文字符长文：判断、机制、证据边界、反证、战略选项与改变判断的条件；来源/判断台账与六项 checklist 单列。

## depth

Lite 长文战略分析（复测价格战方向深度），解释捆绑对毛利的传导，不做产品选型小品。

## evidence_standard

只用合成来源包；区分核实事实、来源说法与建议；披露合成材料与未做独立评审；关键数字保留单位与日期。

## outline

1. 核心判断：挤压程度与传导机制
2. 价格战 vs 捆绑：拆分毛利下降原因
3. 渠道结构证据与边界
4. 反证与仍存在的直销窗口
5. 战略选项与改变判断的条件
6. 局限与未做独立评审
