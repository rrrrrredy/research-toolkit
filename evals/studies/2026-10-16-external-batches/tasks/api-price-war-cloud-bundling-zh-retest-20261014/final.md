# 大模型 API 降价潮下，云捆绑如何挤压独立模型公司毛利

读者是独立模型公司与云生态的商业战略负责人。基于本任务合成来源包（凌波毛利备忘、青云峰会笔记、三家渠道对照表），**核心判断是：当前毛利压力不能单用「公开价下降」解释；云市场占比上升叠加捆绑条款与渠道分成，正在把独立公司的实收与毛利率系统性压向「获客渠道」而非「利润中心」。** 战略上应显式拆分直销/私有化与云市场两本账，并审计最惠客户、迁出惩罚与遥测不对称条款。以下材料均为评测用合成证据，未做独立评审。

## 1. 挤压程度：从公开价到实收与毛利

凌波备忘给出可核对的传导链条。旗舰 chat 在 2025-07 的公开价为输入 $0.80、输出 $2.40 / 百万 token；云厂商将「同档能力」模型打进托管包后，对外标价可低至公开价的 35%–55%，但附带最低消费、同云存储与 GPU 配额等捆绑。对凌波而言，经云市场转售、扣渠道分成后的实收约为公开价的 48%–62%，直销大客户则约 70%–85%。同一备忘的管理报表口径显示：云市场订单占比从 2024Q4 的 22% 升至 2026Q1 的 41%；云市场毛利率比直销低 18–26 个百分点；推理成本占收入比从 31% 升至 44%，其中降价大约解释 8 个百分点，其余来自利用率与预留错配。

据此，**「降价潮」是可见表层，捆绑与渠道结构才是把表层价格传到毛利的齿轮。** 若战略讨论只盯公开价对标，会高估价格战的单独解释力，低估合同与渠道的结构性抽取。

## 2. 捆绑条款如何提高切换成本并压实收

备忘摘录的合成合同片段指出三类机制。其一，采购「AI 推理包」须保持对象存储与消息队列等同云原厂 SKU，否则单价上浮 20%——把模型选择绑进更宽的云账单。其二，合同期内若迁出超过 30% 推理流量，已享折扣按差价追回——直接惩罚多云或回迁直销。其三，调用日志默认进入云方可分析的遥测管道，独立模型公司只获聚合用量、不获原始样本——削弱其用真实流量改进产品与证明差异化的能力。法务还提示云市场标准条款含最惠客户与审计权，限制单独给直销更优价。这些条款并不出现在「每百万 token 降了多少」的公关稿里，却决定实收上限。

青云峰会笔记从买方侧印证互补叙事：纳入「青云智算包」后，中小客户采购决策时间从约 9 周缩到 3 周，因为「一张账单、合规问卷复用云主合同」。客户用更低摩擦换取更低单价与更强锁定；云厂商未披露对终端的真实毛利，也未披露自研与第三方模型的交叉补贴。对独立公司，这意味着**云市场的量增长可能与单位经济恶化同时发生**，不能把 GMV 当作利润质量的代理指标。

## 3. 渠道结构的有限对照与证据边界

三家匿名对照表（2026Q1，n=3）显示：云市场收入占比越高的公司，表内综合毛利印象越差（例如 C 的云市场占比 52%、云市场毛利率 22%；B 因私有化授权直销占比更高）。必须强调：这是**表内相关，不是对全行业的因果证明**；B 的私有化交付成本未计入表内毛利；样本不可外推。它的用处是提出可检验假说——「云市场依赖度—毛利」关系——并要求各公司用审计级分渠道账本自证，而不是停留在合成对照。

证据边界还包括：凌波毛利为管理报表非 GAAP；「同档能力」由销售自评、无独立盲测；峰会笔记不是合同；截止材料日期约 2026-06。任何把上述数字写成「行业平均被挤压 X 个点」的表述都会超出来源。

## 4. 反证：直销与私有化窗口并未关闭

青云笔记中的反证线索值得保留：部分政企标书仍要求模型权重可私有化部署，云托管包无法满足，直销仍有窗口——但该说法无书面纪要，可信度未核实。对照表中 B 的私有化授权线对应更高直销占比与相对更好的直销毛利，暗示**差异化驻留形态**仍可能支撑溢价。若未来盲测证明产品无差异，直销溢价将难守；反之，若延迟、合规驻留或行业微调可被独立验证，则应把资源从「跟进云市场折扣」转向「可证明的不可替代差」。

## 5. 战略选项与改变判断的条件

在合成证据下，可执行选项包括：（1）**两本账**：云市场考核获客与覆盖，利润 KPI 主要挂直销/私有化/OEM；（2）**合同审计**：列出最惠、迁出惩罚、遥测与审计权，能改则改，不能改则在定价中显式计提「渠道税」；（3）**差异化证据投资**：把评测预算花在可公开的盲测与驻留方案，而非只跟公开价；（4）**有限多云**：对迁出惩罚高的合同，预设合规的流量上限与客户沟通话术，避免续约时被动。

改变上述「云市场偏获客、毛利承压」判断的条件应当具体：云市场实收回升到接近直销带；捆绑迁出条款显著软化；独立盲测显示产品差足够支撑溢价；或审计后证明成本上升几乎全由利用率工程改善可逆转。若出现相反证据——例如客户在盲测中视模型为完全可替代商品——则应更快接受模型层商品化，把利润池定义迁到工具链与数据驻留。

## 6. 局限

本文仅基于合成来源包，未联网、未做独立评审，亦未复用仓库原「模型价格战」case 题面原文。数字保留来源中的单位与日期；管理报表与峰会笔记的强度低于审计后财报与正式合同。读者应用自身合同与分渠道毛利复算后再做预算承诺。
## 附录式展开：如何把「渠道税」算进定价决策

战略团队若接受「云市场偏获客」的判断，下一步不是道德指责云厂商，而是把可观测的抽取项变成定价与签约检查清单。结合凌波备忘，最少应单列五类抽取：渠道分成点差、捆绑导致的同云 SKU 溢价或强制用量、迁出追回条款的期望损失、最惠客户条款对直销议价的封顶效应、以及因遥测不对称而损失的产品改进与证明材料价值（后者难货币化，但应在路线图里单列「证据成本」）。

一个可操作的内部算法是：对每一笔云市场订单，计算「若同客户走直销大客户带」的反事实实收，差额记为渠道税；连续两个季度渠道税占云市场收入超过公司设定阈值（例如 35%）时，触发产品与法务联合复审，而不是只让销售加折扣。对照表里 C 的高云市场依赖与低毛利，可作为「阈值失守」的反面教材，尽管 n=3 不能外推。

同时，青云笔记揭示的采购摩擦下降是真实买方价值，独立公司若只有「我们更贵但更好」而没有可验证的驻留、延迟或评测差，很难要求客户离开一张账单的便利。因此资源分配应偏向：**可对外演示的差异化评测、私有化/专有云交付剧本、以及与云市场条款对等的直销合规问卷模板**，降低直销摩擦，而不是用公开价硬刚托管包标价。

若公司已深陷单一云（类似对照表 C），改变判断前还需证明多云迁移的工程与法务成本低于继续缴纳渠道税；否则短期正确动作可能是「接受获客定位、砍掉对云市场的利润预期」，而非 simultaneous 降价+扩招销售。上述算法与阈值是对合成证据的战术化，仍须用审计后分渠道账本校准。
