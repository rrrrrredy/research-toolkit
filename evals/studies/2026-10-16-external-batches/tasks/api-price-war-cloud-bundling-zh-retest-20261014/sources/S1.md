# 合成备忘：独立模型公司「凌波」2025H2–2026Q2 API 毛利与渠道拆分（合成测试材料）

> 披露：本文为评测用合成材料，数字与主体均为虚构，不代表真实市场。

## 1. 公开价与实收价

- 2025-07 起，凌波公开价：输入 $0.80 / 百万 token，输出 $2.40 / 百万 token（旗舰 chat）。
- 同期三家主流云厂商将「同档能力」模型嵌入其托管套餐，对外标价可低至凌波公开价的 35%–55%，但合同附带最低消费、同云存储与 GPU 配额捆绑。
- 凌波通过云市场转售的实收（扣渠道分成后）约为公开价的 48%–62%，视区域与授权层级而定。直销大客户实收约公开价的 70%–85%。

## 2. 毛利压缩机制（财务口径）

财务 BP 笔记（2026-04 内审草稿，合成）：
1. 云市场订单占比从 2024Q4 的 22% 升至 2026Q1 的 41%。
2. 渠道分成 + 捆绑优惠折让合计使云市场毛利率比直销低 18–26 个百分点。
3. 推理成本（含闲置预留）在降价后占收入比从 31% 升至 44%；降价本身解释约 8 个百分点，其余来自利用率与预留错配。
4. 销售称「不进云市场会丢标」；法务指出云市场标准条款含最惠客户与审计权，限制单独给直销更优价。

## 3. 捆绑条款摘录（合成合同片段）

- 条款 4.2：买方采购「AI 推理包」须同时保持对象存储与消息队列同云原厂 SKU，否则单价上浮 20%。
- 条款 7.1：若买方在合同期内将超过 30% 推理流量迁出该云，已享折扣需按差价追回。
- 附录 B：模型调用日志默认写入云方可分析的遥测管道；独立模型公司仅获聚合用量，不获原始 prompt 样本。

## 4. 局限

- 未含竞争对手完整成本账；毛利为公司管理报表口径，非审计后 GAAP。
- 「同档能力」由销售自评，无独立盲测。
- 截止 2026-06-30。
