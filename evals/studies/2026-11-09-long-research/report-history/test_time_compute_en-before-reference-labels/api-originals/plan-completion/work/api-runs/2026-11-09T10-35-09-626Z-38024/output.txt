何时采样，何时加深，何时验证？\nH2：收益取决于模型对当前任务的成功概率、错误答案集中程度、验证器的题内排序及高分尾部表现。最难任务不一定值得最多预算；有限次失败也不能证明成功概率为零。独立抽样仍可能反复产生同一系统性错误，不能仅据答案相似就认定随机变量不独立。\n\n### Q3. 顺序推理的提升来自训练还是推理分配？\nH3：训练改变了使用修订历史和额外 token 的能力。TTC001 的修订模型经过专项微调；TTC002 的 s1 与未微调 Qwen 比较同时改变了训练。必须分开同 checkpoint 预算曲线与跨 checkpoint 系统比较。\n\n### Q4. 为什么饱和或倒退？\n分别检验覆盖不足、共同盲点、验证器误判、奖励投机、错误剪枝、覆盖正确答案、上下文上限、强制续写干预和工具故障。自然长回答更容易错误，不足以证明长度造成错误。允许不用完预算的理论最优值可以不下降，而某个具体策略的实测曲线仍可下降。\n\n### Q5. 自适应节约是否包含识别和控制成本？\nH4：难度估计、预热、验证及退出信号可能吃掉标称节约。TTC001 未计每题2,048次采样的难度估计；TTC007 的 oracle 使用完整测量曲线，成本轴主要计保留的 thinking tokens。离线丢弃已生成内容不等于在线节省计算。\n\n### Q6. 可检查任务的结果能否迁移到 agents？\nH5：执行、检索和环境观察可能增加信息，而不仅是增加内部计算。离线可评分不等于部署时可验证；可重置沙箱不等于不可逆真实环境。必须检查延迟反馈、部分可观察性、工具错误与行动错误累积。\n\n### Q7. Verifier-free 是否等于无反馈、无训练？\nTTC005 不用目标题验证器训练，但用合成题执行奖励并更新两套 LoRA。H6：其结果属于目标条件化测试时适配，不能并入固定权重、完全无反馈的推理曲线。\n\n### Q8. 何时不追加计算？\n比较直接回答、确定性程序、一次执行、升级基座、请求澄清、人工接管与弃答。停止依据应是增量效用、错误后果、延迟和预算，而非默认用满预算或盲信单个置信分数。\n\n## 4. 最终英文报告的论证结构\n### 1. Decision context and evidence contract\n定义单次正确率、候选覆盖率 pass@N、实际提交正确率、重复可靠性 pass^k、任务效用及错误损失。明确 benchmark grading、部署验证和 oracle 诊断的权限差异；说明研究选择原则和版本边界。\n\n### 2. Where additional computation enters the system\n建立生成→状态保留→评估→选择/剪枝/修订→停止→提交的机制图，另画工具反馈和参数更新分支。比较独立采样、self-consistency、普通/加权 best-of-N、完整答案修订、单轨迹延长、前缀搜索与环境搜索。\n**产物 A：Method-and-evidence matrix。** 列出生成器与验证器版本、训练前提、候选单位、保留状态、评估器可见信息、停止规则、数据与指标、比较层级、成本边界、反证和阅读状态。待补原件不得冒充已完成证据行。\n\n### 3. Sampling and selection: finding an answer is not submitting it\n解释覆盖与选择的分离；推导条件独立下的覆盖公式，并区分题间难度异质性、跨模型共同盲点、题内候选依赖和同候选重复判断相关。以 TTC003、TTC008 为现有核心，self-consistency、Large Language Monkeys 和重采样局限原件为明确待补。\n\n### 4. Sequential reasoning, revision, and the training that enables them\n拆分 s1 的 SFT 与同 checkpoint 的 budget forcing，比较训练过的修订、未经训练自我批评及外部反馈修订。分析保留旧答案再选择与直接返回最后一稿的区别。测试时参数更新只作边界案例，不扩展成一般 TTA 综述。\n\n### 5. Search over intermediate states and investment in verification\n比较 best-of-N、beam、best-first、lookahead 和 MCTS 类方法。区分过程正确性、未来完成价值、过程优势、自然语言批评和程序执行结果。检验搜索引起的分布迁移、错误剪枝与评估器投机；计入前缀评分、rollout、废弃分支及最终选择。\n\n### 6.
