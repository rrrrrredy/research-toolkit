# AI Agent 市场格局：从模型竞争到可交付的工作流

## 一、核心判断

**AI Agent 的竞争正在从模型能力延伸到任务执行、工具连接、业务入口与治理能力的组合。** 对战略与产品负责人而言，关键不是谁宣称拥有更自主的智能体，而是谁能在明确权限和成本边界内，持续完成可验收的任务。

第一，平台型玩家的潜在优势来自模型、分发与工具体系的协同，而非单项评测领先。OpenAI、Anthropic 与既有办公、搜索平台的竞争位置不同；DeepSeek 则更适合从模型供给和效率竞争角度观察，不能直接据此认定其企业 Agent 平台地位。

第二，近期更值得优先验证的是有边界的工作流。编程、企业业务流程和跨应用消费任务都有自动化空间，但结果是否可核验、失败是否可回退、人工接管是否方便，决定了技术能力能否转化为经营价值。这是本文的部署判断，而非对通用自主代理技术上限的断言。

第三，开放模型、MCP 与多模态可能扩大产品供给，却不自动带来利润。连接更容易、界面更容易识别之后，企业仍需承担数据准备、授权、复核和异常处置成本。工作流产品的商业价值，要用完整交付成本而非 Token 单价衡量。

## 二、范围与证据

本文聚焦国内外软件型 AI Agent：系统围绕目标规划步骤，利用上下文或记忆调用工具，并根据执行反馈继续行动。规划、记忆、工具使用的框架见《AI Agent研究报告》；将执行闭环作为分析边界，是为避免把所有聊天产品都归入同一市场。机器人及自动驾驶不作展开。

证据来自四篇研究与行业观察摘要，涉及时间主要为2024年至2026年2月，不构成截至2026年10月的完整市场快照。摘要缺少可追溯的原始链接、作者信息、部分发布日期及测试细节，适合识别竞争方向，不足以核定当前产品可用性、市场份额、收入或客户收益。下文保留产品与趋势描述的归属，将商业机制与战略建议作为分析判断；不同月份的产品动态也不视为同一时点的完整清单。

## 三、竞争格局

### 平台型玩家：模型、入口与工具的组合

**OpenAI 与 Anthropic 代表模型能力向执行工具延伸的路径，但现有证据不足以判定谁拥有更强的商业护城河。**《近期 AI Agent 趋势》描述了 Anthropic 面向开发者开放计算机操控能力，以及 OpenAI 测试电脑操作 Agent 的动向；《AI行业月度观察202602》进一步涉及 Codex、Claude Code 和 GitHub 的模型集成。竞争对象由回答质量扩展到代码修改、工具操作和任务推进，但评测成绩与工具集成仍不能替代付费留存和交付收益。

两者的观察重点有所不同：OpenAI 的 ChatGPT 消费入口见于《AI行业月度观察202512》，值得跟踪其能否将广泛使用转化为任务委托；Anthropic 在上述摘要中的开发者工具与计算机操控布局，则适合观察专业任务的执行深度。这里是产品布局的差异，不是排他定位，更不能把聊天用户数量直接折算为 Agent 客户。

**微软与谷歌提示了另一种竞争逻辑：既有业务入口可能比独立 Agent 品牌更重要。**《近期 AI Agent 趋势》将微软 Dynamics 365、Copilot Studio 与企业流程自动化联系起来，将谷歌的浏览器代理探索与网页任务联系起来；2025年12月月报又提及 Workspace Studio。由此推断，嵌入既有办公环境可能减少用户切换和组织采购阻力，但接近业务数据不等于已经取得跨系统授权，套件覆盖广也不保证复杂任务交付可靠。

国内布局同样涉及不同入口：AutoGLM 的描述集中于手机操作，千问涉及消费入口，钉钉 Agent OS 涉及企业协作环境。相关摘要支持这些方向的存在，却不足以比较其规模与收益。DeepSeek 应与这些应用入口区分：两篇月报主要讨论其推理表现与架构效率。模型供给改善可能增加下游选择，但不能据此认定它已建立业务流程、工具市场或客户交付优势。

### 工作流产品：围绕可验收任务竞争

工作流产品不宜只按是否冠以 Agent 名称比较。更有意义的是看任务如何触发、系统可以修改什么、谁验收结果、异常如何处理。Copilot Studio 的自主触发器、动态计划和活动概览，为这类比较提供了产品线索；它们并不证明所有企业治理问题都已解决。（《近期 AI Agent 趋势》）

本文据此区分三类交付逻辑。**编程工作流**能够围绕代码变更、测试与人工审查组织验收，但代码生成成功不等于满足业务需求；审查和返工可能抵消部分效率收益。**企业流程工作流**可以围绕业务记录和审批节点限定动作，但需要处理数据口径、权限和责任分配。**跨应用消费任务**更接近购物、预订等直观需求，却要面对不同应用的规则与访问限制，完成界面操作也未必等于交易正确。

这些差异解释了垂直产品仍可能拥有空间：它们可以竞争业务规则、异常处理和结果验收，而非仅包装一次模型调用。不过，这种优势必须通过客户持续使用和完整成本证明；标准化程度高的简单任务，也可能被平台套件吸收。

### 协议与生态：MCP 与多模态的作用边界

MCP 所代表的工具连接标准化，是《AI行业月度观察202512》提出的重要方向。其潜在经济意义在于提高连接复用、减少重复适配，但这是机制推断；现有摘要没有规范细节、接入规模或互操作测试，不能认定这一收益已普遍实现。

协议、工具供给和治理应分别判断。接口能够连接，不代表工具可靠，也不代表调用者拥有正确权限。标准化还可能产生双向影响：平台能更快扩充工具，客户也可能更容易替换模型或平台。因此，MCP 不必然强化某一家公司的控制力，生态优势仍取决于工具质量、运维能力和使用关系。

多模态解决的是另一层问题。《近期 AI Agent 趋势》描述了通过截图解析和屏幕理解执行 GUI 操作的路径，使缺乏适用 API 的任务也可能被自动化。但识别按钮不等于理解业务后果，视觉判断错误还可能传递到后续动作。UI 与 API 的组合扩大了可执行范围；只有再加上授权、结果校验和失败恢复，才可能形成可靠的工作流。这也是从产品演示走向商业交付的关键分界。

## 四、商业化路径：从调用收入到任务价值

商业化可分为四条候选路径，但以下是经营分析，不是已核实的厂商价目表。**平台按调用量收费**，买方为开发者和应用企业，收入随使用增长，却未必与任务成功绑定。**工作流订阅或增购**面向业务团队，出售持续可用的能力；难点是证明相较原有软件新增了多少价值，而非增加一个交互入口。

**集成交付**向企业收取连接、流程配置与运维费用，能回应数据和权限差异，但定制越重，复制扩张越困难。**按结果收费**更贴近买方目标，却要求双方先定义合格结果、失败责任和争议处理；当结果还受客户数据与人工决策影响时，价值归因尤其困难。

因此，建议以“每个验收合格任务的完整成本”比较方案：分子包括推理、连接维护、失败重试、人工复核及错误处置，分母不能只计算尝试次数。再与原有人工或自动化流程比较质量和耗时。多智能体调用成本与企业流程治理负担，分别见《AI Agent研究报告》和2025年12月月报；目前没有足够数据计算上述路径的毛利或回收期。

## 五、采用阻力与失败模式

企业采用首先是组织问题：数据能否用于任务、谁能授权动作、谁验收结果、出错由谁处理。2025年12月月报提及流程重构、数据治理、权限审计，以及手机助手跨应用操作受到风控响应。后者既可能构成入口摩擦，也可能源于合理的安全限制，不能一概归因为平台排斥竞争。

从执行链看，本文判断有三类风险值得优先验证。其一，界面误读、业务对象匹配错误或计划偏离，可能让后续步骤围绕错误目标继续执行；局部操作成功不代表整体交付正确。其二，权限不足、接口变化或工具失败可能引发反复重试，甚至重复提交。其三，多智能体分工增加交接和上下文需求，可能使定位错误更困难。这些是机制推断，不是已测得的行业事故率。

防护本身也有成本：全部交给人工复核，会削弱节省工时的收益；取消复核，又可能放大高影响错误。更合理的做法是按动作后果分级授权，对不可逆动作保留审批，对失败保留停止、回退和接管路径。产品若只能展示顺利完成的任务，而不能解释异常处置，就尚未证明生产价值。

## 六、反证与不确定性

**有边界的部署不等于能力停滞。**《近期 AI Agent 趋势》转述 Claude 3.5 Sonnet 的 OSWorld 成绩为14.9%，2026年2月月报则转述 GPT-5.3-Codex 为64%。模型、时间和测试设置不同，不能计算为同口径提升，更不能等同业务成功率；但后续进展足以提醒决策者，不应以早期表现冻结判断。

同样，不能把采用阻力解释为市场只有演示。2025年12月月报描述部分零售企业已部署数百个智能体，这构成部署迹象，却没有回答持续活跃、节省工时和续费情况。月报中的用户、调用与购物规模也不能直接折算成 Agent 收入。

平台胜出并非唯一结局：开放模型和标准连接可能降低替换成本，垂直产品可能凭业务规则与交付能力保留价值。反过来，如果平台把常见工作流纳入套件，独立产品也可能失去收费空间。缺少迁移成本、客户留存和工具市场收入数据，目前无法判断哪种力量占优。

## 七、战略建议

优先选择高频、结果可核验、失败可回退的任务试点，同时保留原流程作为基线。记录完成质量、端到端耗时、完整成本及人工介入原因，纳入失败和放弃的任务，避免只展示成功样本；不以减少人工接管次数作为单独目标。

扩大投入的条件，应是代表性业务测试中质量达到原有服务要求、完整成本改善，并且异常可定位、责任可承担。具体门槛由任务风险和基线校准，不宜套用统一成功率。若长期任务在这些条件下持续成立，可以扩大授权；若低模型价格仍被复核和维护成本抵消，则应缩小任务边界，或继续采用传统自动化。

采购前最需要补齐的不是另一张模型榜单，而是实际合同与价格、客户续费、生产环境失败记录，以及同任务的成本收益对照。战略投入应随这些证据调整，而不是随自主性宣传调整。
