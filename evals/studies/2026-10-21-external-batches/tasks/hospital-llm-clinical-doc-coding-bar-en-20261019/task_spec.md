# Research brief

## question

Before a regional hospital system allows LLM-drafted clinical documentation into coding / billing workflows, what evidence bar and human-override controls are required so outputs can support medical-necessity / coding consistency claims—and when must “AI documentation acceleration” marketing be treated as assistive-only?

## audience

Hospital clinical ops, HIM/coding, compliance, and payer liaison.

## scope

Synthetic source pack only; work-product tiers (draft assist vs coding claim); override/audit evidence; counter-evidence (silent omission of contraindications or acuity); kill criteria through 2027. No live web.

## output

final.md, ≥1500 whitespace words (suggested 1500–2500): tiers, override/audit, counter-evidence, kill criteria. Registries and checklist separate.

## depth

Lite long-form healthcare ops/compliance memo; not an EHR feature bake-off.

## evidence_standard

Synthetic sources disclosed; do not treat draft acceleration as coding-consistency proof; disclose no independent review.
