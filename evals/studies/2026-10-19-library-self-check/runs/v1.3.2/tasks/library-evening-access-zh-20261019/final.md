# 公共图书馆是否适合通过自助开放延长晚间服务？

自助开放适合作为晚间借还、阅读和自习服务的补充，前提是当地主要需求能够自助完成，且准入、安全、求助和维护安排已经落实。建议保留既有人工服务，在具备条件的馆先行试点。现有公开材料展示了人工值守与自助延时的组合，但没有给出拟实施图书馆的夜间需求、改造成本和故障记录，因此还不足以决定全面铺开或削减人员。

## 一、延长的是哪些服务

North Somerset Council 的公开页面列出晚间 17:15—20:00 的延时服务。满足准入条件并完成入门说明的读者，可以刷借阅卡、输入 PIN 入馆，使用自助借还、电脑、打印和阅读空间。页面同时说明，延时期间没有工作人员在场，厕所不开放，公共电脑在闭馆前 10—15 分钟自动退出。因此，延时开放的服务范围和实际使用时长需要分别告知读者。[North Somerset：Extended access，Benefits 与 Using extended access](https://n-somerset.gov.uk/my-services/libraries-leisure-open-spaces/libraries/find-library/extended-access)

| 选择 | 能解决的主要问题 | 必须承担的工作 |
|---|---|---|
| 增加有人值守的晚间开放 | 晚间借还、自习，以及咨询、设备帮助等需要即时支持的需求 | 安排值班及相应预算；现有资料未提供当地成本 |
| 在现有人工服务外增加自助开放 | 已能自行使用设备的读者，需要更灵活地借还、阅读和自习 | 准入说明、门禁、求助渠道、设备维护和闭馆安排 |
| 保持现状 | 暂不增加延时开放的建设和运行支出 | 承担可能未满足的晚间需求；其规模仍需当地资料判断 |

后两列是依据服务差异作出的管理分析，不是已测得的成本或效率比较。

## 二、人员要求不会随门禁自动消失

North Somerset 要求先参加约 20—30 分钟的免费说明，并提供非值守时段的紧急求助电话；一般设备问题仅在特定时间可通过电话联系馆员。需要照护者陪伴的读者，其照护者也要注册并参加说明。这些安排意味着仍需承担培训和远程支持工作，不能据此认定总工作量减少。该页面也设有年龄和陪同条件，因此自助时段并非对所有读者都同等可用。[North Somerset：Booking a briefing、Using extended access 与 Accessibility](https://n-somerset.gov.uk/my-services/libraries-leisure-open-spaces/libraries/find-library/extended-access)

Norfolk 的电脑预约页面说明，Open Libraries 某些时段没有工作人员，16 岁及以上读者可刷借阅卡进入；页面列出的客户服务电话时间为工作日 9:00—17:00。这个页面不足以确定晚间故障的完整响应安排，也不能据此断定晚间完全没有支持。实施馆需要明确谁处理门禁失败和设备故障，以及可提供支持的时段。[Norfolk：电脑预约及 Open Libraries 说明](https://pcbookings.norfolk.gov.uk/Account/LogOn)

## 三、什么时候不应优先采用自助开放

如果新增晚间需求主要来自需要咨询帮助的读者、无法独立操作设备的人，或受准入条件限制的未成年人，单纯延长自助时段可能增加名义开放时数，却没有覆盖主要需求。此时应优先比较有人值守的晚间时段，或保留两种服务的组合。这个反例不能用总进馆量增长抵消。

建筑条件也会限制可用性。例如 North Somerset 的 Clevedon 馆有一处紧急出口仅宽 79 厘米，页面提示轮椅或代步车使用者可能无法通过，需在入门说明时商定替代安排。拟实施馆应逐馆核实疏散与无障碍条件，不能因安装门禁就默认适合无人值守。[North Somerset：Safety information，Clevedon Library](https://n-somerset.gov.uk/my-services/libraries-leisure-open-spaces/libraries/find-library/extended-access)

2017 年政府指南中的 Peterborough 案例提到，2014 年咨询中，受问者有 75% 认为正常开放时间之外的使用机会重要；当地随后采用人工值守加自助开放的组合。这能说明一种需求调查与服务设计路径，不能证明今天另一座城市也有相同比例需求，更不是实施后新增访问量或满意度的统计。[Libraries Taskforce：规划指南，第 6.2 节](https://www.gov.uk/government/publications/longer-term-evidence-based-sustainable-planning-toolkit/longer-term-evidence-based-sustainable-planning-toolkit)

## 四、下一步如何决定

先确认当地人晚间需要完成什么。2017 年指南强调听取一线员工、现有使用者和非使用者意见，并就多种方案开展有实际影响的咨询。建议据此比较三种选择，了解未使用图书馆者是否受到时间、准入或求助条件限制。[Libraries Taskforce：规划指南，第 6 节参与及第 6.2 节咨询](https://www.gov.uk/government/publications/longer-term-evidence-based-sustainable-planning-toolkit/longer-term-evidence-based-sustainable-planning-toolkit)

再明确既有人工服务如何保留、门禁与消防及无障碍条件是否满足、晚间求助和维护由谁负责，并把一次性改造与包含培训、故障处理的持续运行支出分别列出。若主要需求确实能够自助完成，且这些安排和预算可落实，可先在一个具备条件的馆增加晚间自助时段。若需求尚不明确，或安全、求助安排尚未落实，应暂缓新增自助时段，保留现有服务；若需求主要依赖现场帮助，则优先评估增加人工晚间服务。

建议试点前记录既有晚间服务情况，试点中记录实际使用、未解决的求助、无法使用服务的人群，以及现场或远程人员投入和实际支出，再决定是否扩大。安全或紧急求助安排失效时，应暂停受影响的自助时段并修复；核心需求仍依赖现场帮助时，应调整人员与时段。现有资料不足以设定节省比例、回本期限或统一推广阈值，具体目标需结合当地需求与试点记录确定。

本报告依据访问日期记为 2026-10-19 的两地公开页面摘录，以及 2017 年规划指南的相关摘录。前两页未注明内容发布日期；访问日期不代表政策生效日期，历史案例也不代表当前实施效果。资料未提供拟实施馆的客流、事故或支出数据，所以上述建议仅支持有条件的方案选择，尚不足以作出某座图书馆的建设或裁员决定。
