# 评审校准对照

[English](README.md) · [简体中文](README.zh-CN.md)

2026-10-12 更新：[v3 材料包](../judge-calibration-v3/README.zh-CN.md)引用这里未改动的算术输入，另增中文因果／归属及英文约束对照，共四题族、12 份输入。下文保留 v2 初始范围；其中待设计部分由新包补充，但仍没有真实校准结果。

三个合成评审包检查一个算术缺陷和有效对照，与开发任务分开，目前没有真实评审结果。协调上下文才可读取 `coordinator-key.json`；将 `judge-inputs/` 中每个文件单独交给新的评审上下文，配合冻结的评审指令。不要向评审开放本目录、仓库、本说明或答案密钥。

数值对照的两个版本按空白分词具有相同词数，仅相对降幅的报告不同；另一个包互换标签，平局包则重复同一份正确报告。既要求偏好正确，也要求定位并解释证据；猜中 A/B 不足以通过。记录全部首轮判断、失败、用量和耗时，调用前冻结模型与这些材料。不能静默替换失败对照，也不能反复用同一组调试评审后再声称留出验证。

答案密钥给出预期偏好、证据和局限。维度加总或最小篇幅不能代替解释核查。互换与平局不构成三个独立任务。一个英文算术例不能校准五个维度，独立的中文、因果、来源归属和决策约束对照仍待设计。这些材料使校准方案可检查，不证明评审可靠或 Toolkit 有效。
