这些简短 JSON 回显请求检验接入与请求配置，不检验报告质量。[清单](summary.json)保留全部首轮失败及另行冻结的诊断补测，没有自动付费重试。

| 请求模型 | 首轮 | 另行诊断后的补测 |
| --- | --- | --- |
| `deepseek-flash` | 预期 JSON，返回名称一致 | 无 |
| `kimi-k2.6` | 预期 JSON，返回名称一致 | 无 |
| `glm-5.3` | HTTP 400：该模型不允许关闭思考 | 开启思考、low 强度后返回预期 JSON，名称一致 |
| `LongCat-2.0` | 预期 JSON，返回名称一致 | 无 |
| Codex 中请求 `gpt-6-astra` | 本地配置错误：不能覆盖保留的 `openai` provider，未发出模型请求 | 独立 provider、HTTP／流重试均为零，CLI 完整轮次返回预期 JSON |

实际有 **六次网络请求**，包括 GLM 被拒绝的请求，另有**一次本地预检失败**；五次生成完成。四份成功 API 返回合计报告 243 token。成功 Codex 轮次报告输入 5,185、输出 13 token，但事件不认证实际返回的模型名称。原先五次生成上限未增加；保留诊断失败后，另冻结了最多两次生成的补测计划。这些调用不进入质量分数或校准计数。

公开副本移除本机可执行文件／工作目录／指令路径及用户目录引用。`summary.json` 记录原件和公开副本哈希以及转换范围；从未保存 API 认证头或密钥，本地原始证据不变。来源是原创合成接入提示，不包含对真实组织的事实主张。证据日期为 2026-10-12，不保证今后的服务可用性或模型别名稳定。

这两个失败促成了可选显式思考参数，以及原生评审使用独立 provider 的配置。[离线对照](../../../scripts/check_live_execution.py)覆盖请求设置、隔离、原始失败保留、不重试和冻结代码变更拒绝。[原生评审的限制与复现](../../../docs/native-judge.zh-CN.md)区分软件检查、接入检查和另行冻结的校准。
