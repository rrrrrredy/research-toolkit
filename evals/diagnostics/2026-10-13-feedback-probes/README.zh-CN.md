## 改动与冻结范围

[10 月 12 日证据](../../studies/2026-10-12-lite-four-models/README.zh-CN.md)及 [LongCat 格式探针](../2026-10-12-longcat-format/README.zh-CN.md)定位了提示／schema 不一致、生产状态泄漏、结构过度展开、约束应用错误及来源信息漂移。本批：

1. 新的纯指令评测注入实际 Lite 阶段指南，替换 Full 流程参考。
2. 明确 JSON 的 `report`／`notes` 都是字符串且须转义，保留原有严格解析器。两组共同的末尾格式提醒将生产状态留在 notes，并保留题目要求的篇幅和引用。
3. 更新中英文 Lite／写作指南：短说明采用紧凑表达，先满足当前硬约束再比较偏好，预测与当前是否可选分开，测量结果须保留样本、日期及处理状态。插件同步同一套指南。

[计划](plan.json)、[承诺哈希](commitment.json)、代码归档和[原清单](manifest.json)均在调用前冻结。基础提交为 `7e80b91cea2903673f0b433319c62192b1ce87d2`，**同时纳入了未提交的工作区改动**，因此基础提交本身不能标识实际执行指令。保留完整注入文本／哈希和执行器字节。公开 driver 归档把一个本地 Git 程序路径替换为 `<GIT_EXECUTABLE>`；[公开清单](public-manifest.json)分别记录原始／公开归档及解码源码哈希，不能称公开 driver 与实际执行字节完全相同。

两个独立任务分别是英文受约束存储选择和中文用水比较，在 `deepseek-flash`、`LongCat-2.0` 上各运行有／无 Toolkit，调用次序预先交叉平衡。共八次，无评审、重试或见结果后追加；两组除 Toolkit 方法文本外设置一致。关闭思考，4,096 completion／32,768 总 token，180 秒，text response mode，`json_object_v1`，允许整个输出的 JSON 围栏。总 token／时间返回后检查，不保证计费硬上限。

这两个任务是独立任务，八次调用是真实执行。任务、模型及输入变化使其不能作为受控前后效果估计，也不能将变化归因于单项修改。实施助手已知分组的来源核查不是独立验证。以前的缺失配对和评分保持不变。

## 结果与残余缺陷

| 作者／任务 | 无 Toolkit 篇幅 | 有 Toolkit 篇幅 | 要求 |
| --- | ---: | ---: | --- |
| DeepSeek／存储 | 144 ✓ | 118 ✗ | 120—170 个空白分隔词 |
| LongCat／存储 | 150 ✓ | 198 ✗ | 120—170 个空白分隔词 |
| DeepSeek／用水 | 244 ✓ | 283 ✗ | 180—260 个非空白 Unicode 字符 |
| LongCat／用水 | 711 ✗ | 626 ✗ | 180—260 个非空白 Unicode 字符 |

计数包含全文、标题、标记和引文。八篇均可解析，固定字面扫描没有检出生产状态词项；这不证明格式普遍可靠、盲法成功或语义质量。尤其要保留：本次小诊断中，**四篇 Toolkit 报告全部篇幅不达标**。

[来源复核](adjudication.json)保留关键反例：DeepSeek 的 Toolkit 存储稿先推荐 A、随后排除它，再以“14 TB 小于所需 12 TB”为由称无方案可行；实际 C 满足当前约束。若干用水稿仍把未记录的七月污渍构成写成确定变化，一篇篇幅达标的无 Toolkit 稿也有该错误。解析成功和实际字数不能认证推荐或来源解释正确。

[分析](analysis.json)保留各提供商报告的 token 和本地耗时之和。notes 与原始输出保存在 `attempts/`，未替换任何稿件。[两篇编辑对照](editorial-controls.json)由实施助手在**结果出现后**编写，分别为 126 英文词和 250 中文字符，用于示范有来源支持的紧凑答案及检查软件门槛；它们不是新增模型生成、预先声明的对照或替代分数。

## 产品验证与处置

`python scripts/check_feedback_probes.py --self-test` 只读重建证据，再用临时工具任务运行**两个测试方法、覆盖七个稿件用例**。五篇真实篇幅失败稿即使配上虚假的“全部通过”checklist，仍全部被拒绝，不生成 Lite 凭证、不授予完成状态；两篇编辑对照通过现有篇幅检查。这只验证被测软件行为，研究 Agent 仍须登记约定约束并修正语义缺陷。

采用具体的提示／schema 和指南修正。**不把仅靠提示的自检当作完成保证，不声称 LongCat 普遍可靠，不声称研究质量提升。** 本固定队列没有追加付费样本。继续使用已有任务修复具体问题，并由 Astra 复查；不要求外部任务或额外评审面板。
