# Astra development-judge calibration, 2026-10-12

[English](README.md) · [简体中文](README.zh-CN.md)

Twelve fresh Codex calls requested `gpt-6-astra` with low reasoning effort, no tools, no retries and the separately frozen [settings and inputs](coordinator/frozen.json). All returned valid five-dimension JSON. All 12 preferences matched the predeclared controls: four defect pairs, their four swaps and four identical-valid ties. These are **four families**, not 12 independent tasks.

[Source adjudication](adjudication.json) confirms the located arithmetic, causal, attribution and hard-budget errors in both orientations. The implementation assistant performed this source comparison after the first-attempt lock and had prior access to the controls; it is not independent human adjudication. Valid ties stayed tied. Three dimension scores changed by one point under swapping, across the budget and causation families. The raw scores remain unchanged. This supports admitting Astra to the bounded exposed-development pilot for source-checked pairwise preferences; it does not validate stable five-dimension scoring or general Toolkit efficacy.

The CLI reports 77,227 input tokens, 17,393 output tokens and a separate 726 reasoning-output-token field; retain these native fields without summing reasoning again. Summed local request time was 596.189 seconds. Events do not attest the returned model ID. Completion/token ceilings are post-return checks, and local timeout is not proof of remote cancellation. [Transport and isolation limits](../../../docs/native-judge.md) apply.

Every packet, request, raw event stream, stderr, parsed reply, execution record and original first-attempt lock is retained. Public copies remove local home-directory references and normalize text newlines; `public-manifest.json` records public hashes and transformations. `original-bundle-manifest.json` refers to local originals. Exact frozen source bytes, including original newlines, are base64-archived under `code/`; they are evidence, not the current executable entry point. The original runner computed preference matches in coordinator memory during the fixed nonadaptive sequence, then wrote results after the lock; the current runner also delays that computation until after the lock. No requests or labels were changed.

`results.json` retains its original pending-adjudication marker; the later `adjudication.json` is an addition. Run `python scripts/check_live_diagnostics.py` to check public integrity, original code hashes, request/packet separation, native-to-parsed correspondence and derived observations without model calls or file writes. This check cannot automatically certify the semantic adjudication. The cases are original public synthetic controls; no private factual data was submitted.
