# 历史评测量表

[English](README.md) | [简体中文](README.zh-CN.md)

本目录两份 JSON 保留早期七维量表的权重、措辞与例子引用，用于解释历史研究。

新报告评测使用[现行标准](../../docs/report-evaluation-standard.zh-CN.md)：五个维度，0—4 分或 `not_assessed`，严重错误另记，语义评审由 LLM 承担。旧 `research_quality.json` 中的人工评审表述仅适用于旧研究，不是当前验收要求。不要将旧加权结果与当前尺度混合。

日期化材料保留原评审人数、预算、失败和修订历史，不产生当前必须修稿或返评的义务。原量表与证据字节不改写；示例用于开发，不能当作标准答案或产品效果证明。
