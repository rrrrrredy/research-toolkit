# Cursor 接入

[English](cursor.md) | [简体中文](cursor.zh-CN.md)

适用于 Cursor 工作区中的研究任务。

## 使用方式

将仓库作为文件夹、子模块或指令副本加入工作区：

```text
本次研究使用 research-toolkit/SKILL.md。
起草前在任务目录创建 state/task_spec.md 与 state/progress.json。
来源、主张和不确定性表保存在 data/。
完成前使用 references/quality-gates.md 检查。
```

## 执行要点

可并排编辑状态、草稿与登记表。普通研究期间工具箱保持只读，成果放在 `research/<task-name>/` 等独立目录。通过差异检查成稿是否仍含过程语言或内部编号，避免研究任务污染方法包。
