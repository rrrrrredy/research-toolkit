# Grok Bot: use the complete research methods

[English](grok-bot.md) | [简体中文](grok-bot.zh-CN.md)

Use a private Grok Bot conversation for the [research request](../docs/quickstart.md). The request contains the repository URL, `SKILL.md` entry, a complete research request. If the Bot cannot open repository files, provide their text and the required references through the [general input guide](README.md#use-without-installation).

Provide the research question, audience, scope and existing material. Deliver the complete report at the requested depth with usable citations; save working records separately.

## Use the toolkit

Send:

```text
Read the supplied research-toolkit/SKILL.md and load complete methods as needed.
Research question: [Question, audience and purpose.]
Scope and depth: [Coverage, information cutoff and length requirements.]
Existing material: [Sources or an existing report.]
Develop evidence, comparisons, explanations and synthesis. Deliver the complete
report with usable citations. Identify inaccessible required material without
inventing its contents.
```

## Reuse the method

After a successful task, ask the Bot to save the research method as a private skill called `research-toolkit`, preserving the complete reference methods. Recheck file access when reusing it.

The [official Grok Bot guide](https://docs.x.ai/grok-bot/skills-routines-and-automations) documents saved skills and the desktop `/` selector. It does not establish that a raw Git clone into another tool's skill directory registers a Grok Bot skill. If a saved skill is missing, check **Marketplace → Your plugins → Manage plugins and skills → Private skills**.
