# 聊天型 Agent 使用方式

[English](chatgpt.md) | [简体中文](chatgpt.zh-CN.md)

适用于能够接收文件或文本指令的 Agent。宿主支持时，也可另外配置原生 Skill 或执行工具。

## 使用方式

提供仓库链接或上传 `SKILL.md`。附件受限时先提供主文件，再按需补充参考文件。

```text
使用附件中的研究工具箱 SKILL.md 和本次任务需要的方法。
研究问题或修改要求：[填写读者与用途。]
要求与材料：[填写范围、格式、来源及已有报告。]
结合对话和材料直接推进，只询问无法自行解决的重要取舍。
交付有实质分析、引用可用的研究成果；修订时附简短变化说明。
```

## 执行要点

研究组织、相关方法读取、完整材料保留、任务接续和独立审阅、审计、验收由 Agent 负责。将用户要求落实到实际报告，执行记录留在正文之外，用户无需逐步提醒。

界面不能保存文件时，由 Agent 将有用的工作笔记与报告分开，并在需要接续时准备摘要。宿主不能跨会话携带材料时，用户可能需要保存或重新附上材料。这类宿主限制见[纯聊天使用方式](README.zh-CN.md#只能在聊天中使用时)。
