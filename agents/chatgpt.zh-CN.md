# ChatGPT / 通用 agent 接入

[English](chatgpt.md) | [简体中文](chatgpt.zh-CN.md)

适用于不能安装技能，但可以读取粘贴指令或附件的工具。

## 使用方式

提供仓库链接或上传 `SKILL.md`。附件受限时先提供主文件，再按需补充参考文件。

```text
使用附件中的研究工具箱 SKILL.md 作为研究规范。
需求关键项明确前，不开始大范围收集。
如果不能写文件，在对话中分别维护 task_spec、progress、来源表、主张表、
不确定性表和评审记录。
除非我要求审计附录，不把后台记录放入最终报告。
```

## 执行要点

开始前简要复述范围。长任务分节写作；上下文变长时按工具箱字段总结状态。交付前检查完成条件并删除正文中的执行记录。

纯聊天记录是能力受限时的替代方式，不能证明持久文件恢复或基于实际文件的交付检查。长任务请保存记录并在继续时重新提供，详见[纯聊天使用边界](README.zh-CN.md#只能在聊天中使用时)。
