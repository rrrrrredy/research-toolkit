# Reviewing changes to Research Toolkit

| Change affects | Check the corresponding evidence |
| --- | --- |
| Research roles or delivery | [Review contract](docs/review-completion.md), [delivery rules](docs/delivery-verification.md), [saved-task support](release/upgrade-support.json) |
| Host or installation claims | [Capability inventory](integrations/capabilities.toml), the linked host guide and its supporting record |
| Public cases or evaluation claims | [Manuscripts, comparisons, denominators and limitations](docs/evaluation-status.md). Identify replays, seeded inputs and historical versions at the point of use. |
| Packaged copies or published documents | Run the [repository check](CONTRIBUTING.md). Check the user-visible entry and Markdown link when changing a public page. |

The [English](docs/en/rfcs/README.md) and [Chinese](docs/zh/rfcs/README.md) design decisions explain why the current contracts exist.
